## 목표

세컨드 브레인이 **보이게** 만드는 것. 노트가 폴더 안에만 있으면 결국 안 열어 보게 됩니다.

## 구조

```
사이트에서 "브레인덤프" 클릭
  → GitHub 이슈 생성 (브라우저에 토큰 0개)
  → Actions가 라벨을 보고 스킬 라우팅
  → Claude Code가 OAuth 토큰으로 실행, .md 커밋
  → push가 Pages 빌드 트리거
  → 사이트에 새 노트 반영
```

정적 호스팅의 제약을 우회하는 지점: **브라우저는 아무 비밀도 들지 않습니다.** 트리거는 이슈 생성이고, 실제 실행은 시크릿을 가진 Actions 러너에서 일어납니다.

## 결정한 것

- 인증은 GitHub 로그인에 얹는다 — 사이트가 자체 계정을 갖지 않음
- 저장소 소유자가 연 이슈만 워크플로가 실행 (공개 저장소이므로 필수)
- 사이트는 정적 산출물만 — 런타임에 LLM을 부르지 않음
