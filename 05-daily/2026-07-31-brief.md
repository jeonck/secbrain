## 오늘 하나만 본다면

Anthropic이 2026-07-24 Claude Opus 5를 출시했고, 같은 날 Claude Code v2.1.219가 이를 기본 Opus 모델로 채택했습니다. [[secbrain-site]]의 온디맨드 파이프라인이 Claude Code로 커밋을 실행하므로, 이번 브리프 자체를 포함해 vault에 들어오는 모든 자동 커밋의 품질·비용 특성이 이미 바뀌었을 가능성이 높습니다.

## anthropic

### Claude Opus 5 출시
Frontier-Bench 성능이 Opus 4.8 대비 2배 이상, ARC-AGI 3에서 3배 향상. 가격은 Opus 4.8과 동일하게 입력 $5/출력 $25 (백만 토큰당) 유지, Fast 모드는 기본가의 2배로 2.5배 빠름. 유기화학·단백질 예측 등 과학 작업과 자체 검증·반복 작업에서 개선이 두드러진다고 발표.

- 출처: [Introducing Claude Opus 5 · Anthropic](https://www.anthropic.com/news/claude-opus-5) · 2026-07-24
- 신뢰도: 높음
- 왜 중요한가: [[secbrain-site]] 파이프라인이 실행하는 모델의 세대 교체. 3일 검증 기간(~2026-08-03) 중 발생한 변화라 검증 결과 해석 시 참고할 것.

### Claude Code v2.1.219~220 업데이트
v2.1.219가 Opus 5를 기본 Opus 모델로 추가(1M 컨텍스트, Fast 모드 $10/$50 per Mtok)했고, MCP 서버 오류 보고와 중첩 서브에이전트 포워딩을 개선. v2.1.220은 안정성 위주 버그 수정.

- 출처: [Claude Code CHANGELOG.md](https://raw.githubusercontent.com/anthropics/claude-code/main/CHANGELOG.md) · 2026-07-24~25
- 신뢰도: 높음
- 왜 중요한가: 이 vault의 이슈→Actions→Claude Code 파이프라인이 정확히 이 버전을 씀. [[secbrain-site]]

## devtools

### Hydra — 로컬 모델 자동 라우팅
기기에 있는 CLI 에이전트·API 키·로컬 서버의 모델을 모두 찾아내 작업마다 "목표 신뢰도를 만족하는 가장 저렴한 모델"로 자동 라우팅하는 로컬퍼스트 도구. LoFi/39(2026-07-28) 커뮤니티 밋업에서 소개됨.

- 출처: [Local-First News 2026-07-30](https://www.localfirstnews.com/2026-07-30/) · 2026-07-30 (도구 자체 링크: [hydra.uvansa.com](https://hydra.uvansa.com/?ref=localfirstnews.com))
- 신뢰도: 중간 (뉴스레터가 제품 자체 설명을 인용, 제3자 검증 없음)
- 왜 중요한가: [[cog-architecture]]의 "비싼 모델=판단, 싼 모델=I/O" 비용 패턴을 도구로 구현한 사례.

## agents

### 저가 라우터 + 프리미엄 합성 패턴 (구자료)
에이전트 호출의 상당수가 도구 선택 같은 단순 결정이라는 전제 아래, 라우팅 결정은 저가 모델에 위임하고 요약·문안 작성 같은 합성 작업만 프리미엄 모델에 맡기는 2단 구조를 설명. 사례로 든 B2B 영업 에이전트는 비용을 월 $290에서 $65로 절감했다고 주장(제3자 검증 없음).

- 출처: [Cheap Router, Premium Synthesis · roborhythms](https://www.roborhythms.com/cheap-router-premium-synthesis-ai-agent/) · 2026-05-19 (7일 신선도 기준 초과 — 구자료)
- 신뢰도: 낮음 (단일 블로그, 비용 절감 수치 미검증)
- 왜 중요한가: [[cog-architecture]]의 "더 모을 자료" 요청에 대한 직접 답. 다만 날짜가 오래됐고 수치가 검증되지 않아 그대로 인용하지 말 것.
