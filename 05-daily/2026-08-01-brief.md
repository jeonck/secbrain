## 오늘 하나만 본다면

Model Context Protocol이 2026-07-28에 새 스펙(`2026-07-28`)을 정식(stable) 릴리스했습니다. 핵심은 프로토콜 계층을 완전히 무상태로 바꾼 것 — `initialize` 핸드셰이크와 `Mcp-Session-Id`가 사라지고, 서버가 sticky session이나 공유 세션 스토어 없이 평범한 라운드로빈 로드밸런서 뒤에서 돌 수 있게 됩니다. Roots·Sampling·Logging 기능은 12개월 유예 기간을 두고 폐기(deprecated) 수순에 들어갔습니다. Claude Code를 비롯한 에이전트 툴 생태계가 MCP 위에서 돌아가므로, 커스텀 MCP 서버를 쓰는 경우 이번 스펙 변경의 breaking change 목록(에러 코드 `-32002`→`-32602` 등)을 확인할 가치가 있습니다.

## AI 에이전트 아키텍처

### MCP 2026-07-28 스펙 정식 릴리스
무상태 프로토콜 코어, Extensions 프레임워크(리버스 DNS 식별자로 독립 버전 관리되는 확장, 공식 확장으로 MCP Apps·Tasks 포함), OAuth 2.0/OIDC 정합성을 높인 인가 강화, Active/Deprecated/Removed 3단계의 공식 폐기 정책이 도입됐습니다. Python·TypeScript·Go·C# SDK가 이미 베타로 지원 중입니다.

- 출처: [The 2026-07-28 MCP Specification Release Candidate · MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) · [GitHub Releases](https://github.com/modelcontextprotocol/modelcontextprotocol/releases) (정식 릴리스 태그 `2026-07-28`, 2026-07-28)
- 신뢰도: 높음 (프로토콜 공식 블로그 + 공식 저장소 릴리스)
- 왜 중요한가: [[secbrain-site]]의 온디맨드 파이프라인이 Claude Code로 커밋을 실행 — MCP는 그 에이전트 툴 생태계의 표준 통신 규격입니다. 이 vault 자체가 커스텀 MCP 서버를 쓰진 않지만, Claude Code가 의존하는 기반 프로토콜의 세대 교체라 추적해둘 가치가 있습니다.

## 지식 관리 · PKM

### Octarine 0.49.0 — 노트 공개 웹페이지 공유 추가
로컬 우선 마크다운 노트 앱 Octarine이 0.49.0(2026-07-30)에서 노트를 공개 웹페이지로 공유하는 기능, 개선된 커맨드바, 워크스페이스 접근성 개선을 추가했습니다. 직전 0.48.1(2026-07-25)에서는 Chat·Inbox 탭을 전체 워크스페이스 탭으로 승격하고 Pinned Views를 도입했습니다.

- 출처: [Octarine Releases](https://octarine.app/releases) · [Octarine Changelog](https://octarine.app/changelog) · 2026-07-30, 2026-07-25
- 신뢰도: 높음 (제품 공식 릴리스 페이지)
- 왜 중요한가: 마크다운 우선·로컬 우선 노트 도구라는 점에서 이 vault의 "마크다운+Git" 접근과 철학이 겹칩니다. "노트를 공개 웹페이지로" 기능은 [[secbrain-site]]가 정적 사이트 빌드로 풀고 있는 문제(노트를 보이게 만들기)를 앱 차원에서 해결하려는 접근이라 비교해볼 만합니다.

## 개발자 도구 · 로컬퍼스트

### Kind Local Pro — 완전 온디바이스 AI 분석 도구
전 Amii(Alberta Machine Intelligence Institute) 공동창립자 Jonathan Schaeffer가 창업한 Synsira Software가 Kind Local Pro(KLP)를 출시했습니다. 문서·영상·이미지·오디오·이메일을 드래그해 넣으면 클라우드 업로드 없이 로컬에서만 AI가 분석하며, Synsira 서버와의 유일한 통신은 주기적 라이선스 검증뿐이라고 설명합니다. 법률·지식재산·학계 등 데이터 민감 업종을 타깃으로 합니다.

- 출처: [Former Amii founder launches privacy-first AI that keeps user data local · BetaKit](https://betakit.com/former-amii-founder-launches-privacy-first-ai-that-keeps-user-data-local/) · 2026-07-28
- 신뢰도: 중간 (신뢰할 만한 매체가 창업자 인터뷰를 직접 인용 — 제품 자체에 대한 독립적 벤치마크는 없음)
- 왜 중요한가: "서버도 데이터베이스도 없다"는 이 vault의 지향점과 같은 방향의 상업적 사례. 다만 라이선스 검증을 위한 서버 통신은 남아 있어 완전한 로컬퍼스트는 아님.
