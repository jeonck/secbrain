## 오늘 하나만 본다면

Google의 Gemini CLI가 v0.53.0(2026-07-28)에서 무한 ReAct 루프와 프롬프트 인젝션 취약점을 완화하고, 워크스페이스 신뢰(workspace trust) 강제를 강화해 원격 코드 실행(RCE) 경로를 차단했습니다. Claude Code도 최근 몇 주간 auto mode에 파괴적 git 명령 차단, transcript 변조 방지 같은 유사한 방어 계층을 계속 추가해왔습니다 — 에이전틱 CLI 도구 전반이 "도구 실행 권한을 어디까지 자동화할 것인가"를 놓고 같은 문제를 각자 풀고 있다는 신호입니다.

## 개발자 도구 · CLI

### Gemini CLI v0.53.0 — 프롬프트 인젝션·RCE 완화
무한 ReAct 루프 방지, 워크스페이스 신뢰 검증 강화(RCE 방지), `GOOGLE_APPLICATION_CREDENTIALS` 자격증명 폴백의 순차 검증, 취소된 도구 응답 처리 개선이 포함됐습니다. 후속 프리뷰(v0.54.0-preview, 2026-07-28/31)는 자격증명 제공자에 HTTPS를 강제하고 키체인 검증을 보강했습니다.

- 출처: [gemini-cli Releases · GitHub](https://github.com/google-gemini/gemini-cli/releases) · 2026-07-28~07-31
- 신뢰도: 높음 (공식 GitHub 릴리스 노트)
- 왜 중요한가: [[secbrain-site]]는 Claude Code를 온디맨드로 실행해 vault에 커밋하는 파이프라인입니다. 에이전트 CLI가 자동으로 명령을 실행하는 구조에서 프롬프트 인젝션·권한 우회가 어떻게 다뤄지는지는 이 파이프라인의 위협 모델과 직결됩니다.

## 지식 관리 · PKM

### Obsidian 1.13 — 설정 패널 전면 개편
Desktop 1.13(2026-07-30)이 검색 가능한 설정 패널과 키보드 내비게이션, 현재 파일 내 이미지를 전체화면으로 넘겨보는 이미지 뷰어를 추가했습니다. Mobile 1.13은 iOS 공유 시트 개선과 탭 재정렬, 태블릿 분할 화면 제스처를 더했습니다.

- 출처: [Obsidian Changelog](https://obsidian.md/changelog/) · 2026-07-30
- 신뢰도: 높음 (제품 공식 체인지로그)
- 왜 중요한가: 로컬 우선·마크다운 기반이라는 점에서 이 vault와 같은 계열의 도구입니다. 기능 자체는 이 저장소의 정적 사이트 접근과 직접 겹치진 않지만, PKM 도구가 "설정 발견성"에 투자하는 방향은 [[secbrain-site]]가 노트를 "보이게" 만들려는 목표와 결이 비슷합니다.

## 확인하지 못한 것

**Claude · Anthropic 제품/API 변경사항** — Claude Platform 릴리스 노트, Claude Code changelog, Anthropic 뉴스룸을 모두 확인했으나 2026-07-26~08-02 사이 새 제품·API 항목이 없습니다. Claude Code v2.1.220(버그 수정)이 가장 최근이지만 정확한 날짜가 불명확하고 내용도 경미해 제외. Anthropic 뉴스룸의 최근 글(사이버보안 평가 레드팀 포스트 7/30, 오픈 웨이트 모델 입장문 7/27, Cognizant 파트너십 7/27)은 제품·API 변경이 아니라 정책·파트너십 성격이라 관심사 범위 밖으로 판단해 제외.

**AI 에이전트 아키텍처 / 멀티 에이전트 오케스트레이션** — LangGraph·CrewAI·Microsoft Agent Framework·A2A를 확인했으나 이번 주 신선한 1차 발표가 없습니다. 검색된 "에이전트 오케스트레이션" 관련 발표 다수(Abrigo APX, Fenergo Fen-AI 등)는 특정 업종 대상 상업 플랫폼 출시로 사용자의 실제 작업과 무관해 제외했습니다.
