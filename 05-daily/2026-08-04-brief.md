## 오늘 하나만 본다면

Claude Code v2.1.221(2026-08-04)이 리눅스·WSL 샌드박스에 자격증명 파일 마스킹 모드(`mode: "mask"`)를 추가했습니다. 샌드박스 안에서 실행되는 명령은 자격증명 파일의 센티널(가짜값) 복사본만 읽고, 실제 값은 샌드박스 프록시가 egress 시점에만 치환합니다 — 즉 샌드박스 내부 코드나 명령이 실제 토큰 값을 직접 볼 수 없습니다. [[secbrain-site]]는 GitHub Actions 러너에서 Claude Code가 OAuth 토큰으로 실행되는 구조라, 어제 브리프([[2026-08-03-brief]])에서 다룬 "환경 격리 오판" 사고와 맞물려 바로 검토해볼 가치가 있습니다.

## anthropic

### Claude Code v2.1.221 — Focus view, 샌드박스 자격증명 마스킹
Focus view는 턴별 도구 활동을 접힌 요약 뒤로 숨기고 실시간 실행 표시기만 보여주는 UI 토글(`Ctrl+Alt+F`)입니다. 더 중요한 것은 샌드박스 자격증명 마스킹으로, 리눅스/WSL에서 지정한 자격증명 파일(전체 또는 정규식으로 지정한 범위)을 센티널 값으로 대체해 샌드박스 안에서 실행되는 명령이 실제 값을 읽지 못하게 하고, 실제 값은 프록시가 아웃바운드 요청에만 주입합니다. macOS는 아직 `deny`(차단)로 폴백됩니다.

- 출처: [Claude Code changelog · code.claude.com](https://code.claude.com/docs/en/changelog) · 2026-08-04
- 신뢰도: 높음 (공식 문서)
- 왜 중요한가: [[secbrain-site]]의 온디맨드 워크플로는 GitHub Actions 러너에서 Claude Code가 OAuth 토큰을 들고 실행됩니다. 지금 구조에서 이 토큰이 실행 중인 명령(예: 임의 셸 호출)에 평문으로 노출되는지 확인하고, 노출된다면 이 마스킹 모드 적용을 검토할 근거입니다. 단, 현재 환경이 macOS 러너가 아닌 Linux 러너인지부터 확인이 필요합니다.
