## 오늘 하나만 본다면

Claude Opus 4.1(`claude-opus-4-1-20250805`)이 2026-08-05부로 Claude API에서 완전히 은퇴했습니다. 이 모델로 가는 요청은 이제 에러를 반환합니다. `.github/workflows/scheduled.yml`을 확인한 결과 이 vault의 예약 파이프라인은 이미 `claude-sonnet-5`를 쓰고 있어 직접 영향은 없지만, 하드코딩된 모델 ID를 쓰는 다른 프로젝트가 있다면 오늘부로 즉시 장애가 날 수 있는 항목이라 한 줄로 짚어둡니다.

## anthropic

### Claude Opus 4.1 API 은퇴 (2026-08-05)
2026-06-05에 폐기 예고됐던 Claude Opus 4.1이 오늘 은퇴 처리됐습니다. 해당 모델 ID로의 모든 요청은 에러를 반환하며, Anthropic은 Claude Opus 5로의 이전을 권장합니다. 연구 목적이면 External Researcher Access Program을 통해 접근을 요청할 수 있습니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · [Model deprecations](https://platform.claude.com/docs/en/about-claude/model-deprecations) · 2026-08-05
- 신뢰도: 높음 (공식 문서)
- 왜 중요한가: 이 저장소의 예약 파이프라인(`.github/workflows/scheduled.yml`)은 `claude-sonnet-5`를 사용해 직접 영향은 없음을 확인했습니다. 다만 사용자가 다른 곳에서 Opus 4.1 모델 ID를 하드코딩해뒀다면 오늘부터 실패하니 확인이 필요합니다.

### Claude Enterprise용 Inference hooks 베타
같은 날 발표된 기능으로, 조직의 AI 보안 서버를 Claude에 연결해 claude.ai·Cowork·Claude Code 전반의 거버넌스 대상 프롬프트를 추론 전에 허용/거부 판정받게 합니다. 요청은 서명되고 실패 처리 방식을 설정할 수 있으며, 모든 거부는 컴플라이언스 Activity Feed에 기록됩니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-05
- 신뢰도: 높음 (공식 문서)
- 왜 중요한가: Enterprise 전용 기능이라 개인 vault엔 해당하지 않지만, [[2026-08-04-brief]]에서 다룬 샌드박스 자격증명 마스킹과 같은 방향(에이전트 실행을 서버 측에서 통제)의 거버넌스 트렌드라 흐름 파악용으로 기록.

## 확인하지 못한 것

**agents** — Microsoft Agent Framework Harness/Hosted Agents GA 소식을 찾았으나 실제 공식 발표일은 2026-07-22로 7일 신선도 기준을 벗어나 제외했습니다. 그 외 LangGraph, CrewAI, Google ADK에서 이번 창(07-29~08-05) 안의 신선한 1차 발표를 찾지 못했습니다.

**devtools** — GitHub Copilot CLI v1.0.78(2026-08-03)은 [[2026-08-04-brief]]에서 이미 다뤘고, Gemini CLI v0.53.0(2026-07-28)은 신선도 창 경계 밖입니다. Zed, Warp, Ghostty, 로컬 우선 sync engine(Automerge, PowerSync 등) 쪽에서 이번 주 신규 발표를 찾지 못했습니다.

**pkm** — Obsidian 1.13.5(2026-08-05)가 나왔지만 탭 종료 애니메이션·설정창 Escape 키 지원 등 사소한 패치 범위라 항목화하지 않았습니다. Logseq DB 버전은 여전히 베타 상태로 이번 주 새 소식 없음. 디지털 가든 관련 신선한 1차 발표도 찾지 못했습니다.
