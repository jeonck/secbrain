## 오늘 하나만 본다면

Claude Code가 나흘 사이 보안 관련 수정 세 건을 연달아 냈습니다. v2.1.222(2026-08-04)는 worktree로 격리된 세션과 그 서브에이전트가 메인 체크아웃에 대해 파괴적 git 명령을 실행할 수 있던 결함을 고쳐, 파일 편집과 Bash 실행 모두에 모든 세션 유형에서 격리가 적용되도록 했습니다. v2.1.223(2026-08-06)은 조작된 명령이 권한 승인 다이얼로그에서 자기 일부를 숨길 수 있던 Bash 권한 우회, 그리고 탭·비가시 유니코드로 패딩된 명령이 승인 창에서 일부를 숨기는 문제를 막았습니다. v2.1.224(2026-08-07)는 샌드박스 파일시스템의 거부 목록(deny-list)을 우회할 수 있던 취약점을 고쳤습니다 — 세 번째 릴리스가 연속으로 "격리·권한·샌드박스 경계를 실제로는 빠져나갈 수 있었다"는 종류의 결함을 다룬 셈입니다. [[2026-08-03-brief]]에서 다룬 Anthropic 자체 평가 사고(모델이 격리 경계를 오판)와 [[2026-08-04-brief]]의 샌드박스 자격증명 마스킹은 모두 "자율 실행 에이전트의 경계가 어디까지 지켜지는가"라는 같은 질문을 겨냥한 것이었고, 이번 세 건은 그 질문에 대한 Claude Code 자체의 실제 수정 사례입니다. 이 저장소의 예약 파이프라인이 worktree 격리 모드나 샌드박스 파일시스템 제한을 쓰는지는 워크플로 파일에서 명시적으로 확인되지 않았으나, GitHub Actions에서 사람 검토 없이 Claude Code를 실행해 vault에 쓰는 구조([[secbrain-site]]) 자체가 이 종류의 취약점 클래스에 해당하므로 v2.1.224로의 업그레이드 여부를 확인해둘 가치가 있습니다.

## anthropic

### Claude Code v2.1.222 — worktree 격리 우회, PreToolUse 훅 우회 수정
worktree로 격리된 세션과 서브에이전트가 메인 체크아웃에 파괴적 git 명령을 실행할 수 있던 버그를 고쳐, 파일 편집·Bash 실행 모두에 모든 세션 유형에서 격리가 적용되게 했습니다. 같은 릴리스에서 PreToolUse auto-allow 훅이 백그라운드 에이전트 작업(요약·압축·이름변경)에서 도구 제한을 우회하던 문제도 수정됐습니다.

- 출처: [Release v2.1.222 · anthropics/claude-code](https://github.com/anthropics/claude-code/releases/tag/v2.1.222) · 2026-08-04
- 신뢰도: 높음 (공식 GitHub 릴리스 노트)
- 왜 중요한가: worktree 격리가 깨지면 격리된 세션이 메인 체크아웃을 건드릴 수 있다는 뜻입니다. [[secbrain-site]]처럼 CLAUDE.md로 "vault 폴더 안에서만 쓰기"를 강제하는 구조에서, 이런 종류의 격리 우회 버그는 정책 자체가 아니라 정책을 강제하는 하부 메커니즘의 문제라 특히 주의 깊게 볼 항목입니다.

### Claude Code v2.1.223 — Bash 권한 승인 우회 수정
조작된 명령이 Bash 권한 검사에서 명령의 일부를 숨길 수 있던 우회와, 탭·비가시 유니코드로 패딩한 명령이 승인 다이얼로그에서 일부를 숨기던 문제를 고쳤습니다. 그 외 마켓플레이스 관리 설정에 `owner/*` 와일드카드 항목 추가, 서브에이전트 모델이 제한돼 상위 모델로 대체 실행될 때 경고 표시, 클라우드 세션에서 `claude --teleport`로 로컬에 이어받는 `/teleport` 힌트가 추가됐습니다.

- 출처: [Release v2.1.223 · anthropics/claude-code](https://github.com/anthropics/claude-code/releases/tag/v2.1.223) · 2026-08-06
- 신뢰도: 높음 (공식 GitHub 릴리스 노트)
- 왜 중요한가: Bash 권한 승인 다이얼로그를 신뢰하는 모든 워크플로(사람이 명령을 눈으로 확인하고 승인하는 구조)에 직접 영향. 이 저장소의 예약 실행은 사람 승인 없이 도는 구조라 승인 다이얼로그 우회 자체보다는, 같은 계열의 "권한 검사 우회" 버그가 반복적으로 발견되고 있다는 패턴으로 참고할 항목입니다.

### Claude Code v2.1.224 — 샌드박스 파일시스템 우회 수정, self-hosted-runner 추가
샌드박스 파일시스템의 거부 목록을 우회할 수 있던 취약점을 고쳤습니다. 같은 릴리스에서 `claude self-hosted-runner` 명령으로 자체 머신·컨테이너를 Team/Enterprise 플랜 세션 실행 환경으로 쓸 수 있게 됐고, git·npm 없이 HTTPS zip으로 플러그인을 설치하는 기능(선택적 SHA-256 핀닝), 세션 간 메시지를 주고받는 `SendMessage`/`ListAgents` 크로스 세션 메시징, 200개였던 서브에이전트 수 제한 제거가 추가됐습니다.

- 출처: [Release v2.1.224 · anthropics/claude-code](https://github.com/anthropics/claude-code/releases/tag/v2.1.224) · 2026-08-07, [CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md)
- 신뢰도: 높음 (공식 GitHub 릴리스 노트·CHANGELOG)
- 왜 중요한가: v2.1.222·v2.1.223에 이은 사흘 연속 세 번째 격리/권한 경계 수정. 이번엔 샌드박스 "파일시스템 접근을 막아야 할 목록"이 실제로는 새고 있었다는 것으로, 이 저장소처럼 CLAUDE.md의 "vault 폴더 안에서만 쓰기" 규칙을 샌드박스가 아니라 프롬프트 지시문에만 의존해 지키는 구조에서는 특히 참고할 항목입니다.

## devtools

### Zed 1.14.2 — 에이전트 terminal·fetch 도구 샌드박싱
이 릴리스의 핵심은 에이전트의 `terminal`·`fetch` 도구에 샌드박싱을 추가한 것으로, 에이전트가 실행할 수 있는 명령과 가져올 수 있는 웹 콘텐츠를 제한합니다. 그 외 Anthropic 호환 프로바이더용 reasoning effort 선택기, Agent Panel 폰트 커스터마이즈(`agent_ui_font_family` 등), Project Panel 파일 작업 undo/redo, 커밋 시 Skip Hooks 토글이 추가됐습니다.

- 출처: [Zed 1.14.2 Release Notes](https://zed.dev/releases/stable/latest) · 2026-08-05
- 신뢰도: 높음 (공식 릴리스 노트)
- 왜 중요한가: 에이전트가 임의 셸 명령·웹 fetch를 실행하기 전에 무엇을 샌드박싱할지는 위 Claude Code 격리 수정과 같은 문제의식입니다. 다른 벤더가 이 문제를 어떤 설정 표면(도구별 세분화된 샌드박스)으로 푸는지 비교해볼 만합니다.
