## 오늘 하나만 본다면

GitHub이 2026-08-07 주간 릴리스에서 Copilot CLI에 실험적 `/worktree` 명령(격리된 작업공간 생성)과 Git 의존성 없이 동작하는 `/rewind`를 추가했습니다. [[2026-08-07-brief]]에서 다룬 Claude Code v2.1.222(worktree 격리 우회 수정)와 Zed 1.14.2(에이전트 terminal·fetch 샌드박싱)에 이어, 이번엔 다른 벤더가 "에이전트가 건드리는 작업공간을 어떻게 격리할 것인가"라는 같은 문제를 CLI 기본 기능으로 채택한 사례입니다. 이 저장소처럼 사람 승인 없이 자동 실행되는 파이프라인([[secbrain-site]])에서 워크스페이스 격리가 프롬프트 지시문(CLAUDE.md)이 아니라 도구 자체의 메커니즘으로 얼마나 뒷받침되는지는 계속 지켜볼 만한 흐름입니다.

## 개발자 도구 · CLI · 로컬 우선 소프트웨어

### GitHub Copilot 주간 릴리스 — CLI `/worktree`·`/rewind`, 세션 사이드바
GitHub Copilot CLI에 여러 세션을 동시에 관리하는 Sessions 사이드바, 격리된 작업공간을 만드는 실험적 `/worktree` 명령, Git 없이도 동작하는 `/rewind` 명령, 도구 호출 소요 시간을 타임라인에 실시간 표시하는 기능이 추가됐습니다. 같은 릴리스에서 Copilot 앱은 Auto 모드가 어떤 모델이 요청을 처리했는지와 AI 크레딧·캐시 정보를 보여주게 됐고, VS Code 1.132는 `/btw`로 본 대화 맥락을 유지한 채 곁가지 질문을 던지는 기능과 통합 브라우저의 요소 단위 피드백을 추가했습니다.

- 출처: [GitHub Copilot weekly releases — August 3](https://github.blog/changelog/2026-08-07-github-copilot-weekly-releases-august-3/) · 2026-08-07
- 신뢰도: 높음 (공식 GitHub Changelog)
- 왜 중요한가: `/worktree`는 Claude Code가 이미 겪은 "격리된 세션이 메인 체크아웃을 건드릴 수 있는가"라는 문제([[2026-08-07-brief]])와 정확히 같은 설계 공간입니다. Git 없이 동작하는 `/rewind`는 이 vault처럼 커밋 단위로 상태를 관리하는 구조와는 다른 되돌리기 모델이라 비교해볼 만합니다.

## Claude · Anthropic

### Fable 5 생물학 안전 분류기 재조정 — 정상 질의 차단 85% 감소
Anthropic이 Fable 5의 생물학 관련 안전 분류기를 다시 훈련해, 이중용도(dual-use) 위험이 없는 정상적인 건강·교육 질의가 더 낮은 성능의 Opus 5로 넘어가던(fallback) 빈도를 전체 85% 줄였다고 발표했습니다. 플랫폼별로는 claude.ai 67%, Cowork 55%, Claude Code 17%, Claude Platform(API) 7% 감소했습니다. 바이러스학·독성학·분자 설계 같은 실제 이중용도 연구 영역에 대한 차단은 그대로 유지됩니다.

- 출처: [Improving Fable 5's biology safeguards \ Anthropic](https://www.anthropic.com/news/improving-fable-5-s-biology-safeguards) · 2026-08-07
- 신뢰도: 높음 (Anthropic 공식 발표)
- 왜 중요한가: 이 저장소가 쓰는 모델(Claude Sonnet 5)과는 직접 관련 없지만, 안전 분류기가 넓게 걸려 있으면 정상 요청도 더 약한 모델로 조용히 넘어갈 수 있다는 패턴은 다른 모델의 안전장치를 이해할 때도 참고할 사례입니다. Claude Code v2.1.225(2026-08-08, [[2026-08-08-brief]])까지 확인한 결과 이 vault의 예약 파이프라인에 영향을 주는 별도 변경은 없었습니다.
