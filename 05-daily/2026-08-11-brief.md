## 오늘 하나만 본다면

2026-08-07 Claude Managed Agents 업데이트에서 세션에 **하드 지출 상한(budget)**을 걸 수 있게 됐습니다 — 상한에 닿으면 세션이 새 모델 요청을 멈추고 `budget_reached`로 일시정지하며, 상한을 바꾸거나 지우면 재개됩니다. 같은 업데이트에서 primary 스레드가 턴 중간에 더 유능한 모델에게 전략 자문을 구하는 **advisor** 롤도 멀티에이전트 로스터에 추가됐습니다. [[2026-08-10-에이전트-비용-구조-정리와-빈틈]]이 "모델 라우팅(리드=판단/워커=I/O) 말고는 vault에 비용 절감 기법이 전혀 없다"고 짚었는데, session budget은 정확히 그 빈틈 — 라우팅이 아니라 **상한 걸기**라는 다른 축의 비용 통제 기법입니다. 다만 이건 Anthropic 자체 관리형 에이전트(Managed Agents) API 기능이라 [[secbrain-site]] 같은 자체 파이프라인에 그대로 적용되진 않는다는 점은 구분해서 봐야 합니다.

## agents

### Claude Managed Agents — 세션 예산 상한, 자문(advisor) 모델, 데이터 레지던시, GitHub 스킬 자동 로드
2026-08-07 하루에 Managed Agents에 네 가지가 함께 추가됐습니다: (1) 세션 하드 지출 상한(`budget`), (2) primary 스레드가 턴 중간 상담할 수 있는 `advisor` 롤, (3) 에이전트·세션 단위로 추론 실행 지역을 지정하는 `inference_geo`, (4) 세션이 마운트한 GitHub 레포의 `.claude/skills` 폴더를 세션 시작 시 자동으로 인식하는 기능.

- 출처: [Claude Platform release notes — August 7, 2026](https://platform.claude.com/docs/en/release-notes/api) · 2026-08-07
- 신뢰도: 높음 (Anthropic 공식 릴리스 노트)
- 왜 중요한가: budget/advisor 두 가지는 "판단은 비싼 모델, I/O는 싼 모델"이라는 [[cog-architecture]]의 비용 패턴과 다른 축 — 하나는 상한을 걸어 폭주를 막는 것(budget), 하나는 값싼 실행자가 필요할 때만 비싼 모델을 부르는 것(advisor)이라 같은 문제를 다르게 풀고 있습니다. [[2026-08-10-에이전트-비용-구조-정리와-빈틈]]에 추가할 만한 새 사례입니다.

## anthropic

### Inference hooks 베타 — 조직의 보안 서버가 매 요청을 승인/거부
2026-08-05 Claude Enterprise 대상으로 베타 공개. 조직이 지정한 AI 보안 서버로 claude.ai·Cowork·Claude Code의 모든 거버넌스 대상 프롬프트가 추론 전에 전달되고, 서버의 allow/deny 판정을 받은 뒤에야 실행됩니다. 요청은 서명되고, 실패 처리 방식은 설정 가능하며, 모든 거부는 컴플라이언스 Activity Feed에 기록됩니다.

- 출처: [Claude Platform release notes — August 5, 2026](https://platform.claude.com/docs/en/release-notes/api) · 2026-08-05
- 신뢰도: 높음 (Anthropic 공식 릴리스 노트)
- 왜 중요한가: [[2026-08-10-brief]]에서 다룬 UK AISI 사고 리포트(에이전트의 승인되지 않은 실제 행동 19건)가 던진 "에이전트에게 얼마나 넓은 권한을 줄 것인가" 질문에, Anthropic이 실시간 승인/거부 게이트라는 구체적 답을 내놓은 셈입니다. 사람 승인 없이 Actions에서 자동 실행되는 [[secbrain-site]] 구조를 설계할 때 참고할 패턴입니다.

### Compliance API가 로컬 Claude Code·Cowork 세션 트랜스크립트도 반환
2026-08-11부터 Claude Enterprise 조직은 사용자 기기에서 실행된 Cowork·Claude Code 세션의 트랜스크립트를 Compliance API로 조회할 수 있습니다(베타). 세션 목록, 메타데이터, 전체 메시지 트랜스크립트를 각각 별도 엔드포인트로 제공합니다.

- 출처: [Claude Platform release notes — August 11, 2026](https://platform.claude.com/docs/en/release-notes/api) · 2026-08-11
- 신뢰도: 높음 (Anthropic 공식 릴리스 노트)
- 왜 중요한가: 위 inference hooks와 같은 방향 — 로컬에서 도는 에이전트 세션을 사후에 감사할 수 있게 만드는 기능입니다. Enterprise 전용이라 이 vault엔 직접 해당하지 않지만, "자동 실행 에이전트를 어떻게 들여다볼 것인가"라는 같은 질문에 대한 또 다른 답이라 함께 기록해 둡니다.

## devtools

### Warp Agent — 독립 CLI로 분리 출시
2026-08-04, 기존 Warp 터미널에 내장돼 있던 멀티모델 에이전트가 Ghostty·iTerm2·VS Code·기본 터미널 등 어디서든 쓸 수 있는 독립형 CLI로 나왔습니다. 원격 바이너리 설치 없이 세션 안에서 ssh 접속·디렉터리 이동이 가능하고, sqlite·vim·python REPL 같은 풀스크린 대화형 앱을 에이전트가 직접 조작할 수 있습니다. 프론티어 모델과 오픈웨이트 모델을 함께 제공하며 작업별 커스텀 라우팅을 지원합니다.

- 출처: [Introducing the Warp Agent CLI — Warp](https://www.warp.dev/blog/introducing-the-warp-agent-cli-coding-agent) · 2026-08-04
- 신뢰도: 높음 (공식 블로그 1차 발표)
- 왜 중요한가: 터미널 종속성을 없앤 독립 에이전트 CLI라는 방향이 Claude Code와 겹치는 지점이 있어, CLI형 코딩 에이전트 시장의 경쟁 구도를 가늠하는 데 참고가 됩니다.
