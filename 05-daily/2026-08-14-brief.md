## 오늘 하나만 본다면

Claude Code v2.1.232(2026-08-13)가 `subagent_type: fork`로 띄운 서브에이전트가 부모의 전체 대화와 프롬프트 캐시를 그대로 상속하도록 기본값을 바꿨고, 대화형 세션에서 팀원이 아닌 스폰은 기본적으로 백그라운드로 돌게 했습니다. 프롬프트에 `@`를 입력해 이름으로 다른 Claude 세션을 참조하는 문법(`SendMessage` 경유)도 추가됐습니다. [[cog-architecture]]가 다루는 리드-워커 패턴과 [[2026-08-13-brief]]에서 짚은 워크플로 프리픽스 캐싱이 같은 방향(형제 에이전트 간 컨텍스트·비용 공유를 인프라가 대신 처리)으로 이어지는 변경이라, 이 vault가 Workflow 도구로 서브에이전트를 띄울 때 컨텍스트 상속 동작이 달라졌다는 점을 체감할 만합니다.

## agents

### Claude Code v2.1.232 — 서브에이전트 포크 기본값 전환, `@` 세션 참조 문법
`subagent_type: fork`로 생성한 서브에이전트가 이제 기본으로 부모의 전체 대화 기록과 프롬프트 캐시를 상속합니다. 대화형 세션에서 팀원(teammate)이 아닌 스폰은 기본적으로 백그라운드 실행으로 바뀌었고, 프롬프트에 `@`를 입력해 이름으로 다른 살아있는 Claude 세션을 참조하면 `SendMessage`가 자동으로 그 세션에 전달합니다.

- 출처: [anthropics/claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) (v2.1.232) · [Claude Code changelog](https://code.claude.com/docs/en/changelog) · 2026-08-13
- 신뢰도: 높음 (공식 리포지토리 CHANGELOG + 공식 문서, 1차 출처)
- 왜 중요한가: [[secbrain-site]]가 Workflow 도구로 여러 에이전트를 동시에 띄울 때, 포크된 서브에이전트가 이제 기본으로 부모 컨텍스트를 통째로 물려받습니다. [[2026-08-13-brief]]의 프리픽스 캐싱과 함께 보면, "형제 에이전트가 프롬프트를 다시 지불하지 않게" 하는 흐름이 옵트인에서 기본값으로 넘어가는 추세입니다.

## anthropic

### Claude Tag — 채널 전체 맥락으로 끼어들 때 판단, 정확도 30% 개선
Slack용 Claude Tag가 메시지 하나하나를 보던 가벼운 분류기 대신 채널 전체 맥락을 보고 끼어들지 말지를 판단하도록 바뀌었습니다. 답장 방식도 단순 응답/무응답이 아니라 "인라인 답장 / 스레드에서 깊게 작업 / 기존 작업 스트림으로 라우팅 / 침묵" 네 가지로 나뉘고, 메모리·standing instructions·채널 맥락을 함께 씁니다. 첫 응답 속도도 빨라졌고 추가 비용은 없습니다.

- 출처: [Claude Tag now reads even more of the room — Claude by Anthropic](https://claude.com/blog/claude-tag-now-reads-even-more-of-the-room) · 2026-08-13
- 신뢰도: 높음 (공식 제품 블로그, 1차 출처)
- 왜 중요한가: "언제 끼어들지"를 메시지 단위가 아니라 맥락 단위로 판단하게 한 설계는, 이 vault의 `ask`·`weekly-review` 같은 스킬이 언제 노트에 개입할지(예: 자동 트리거 여부)를 설계할 때 참고할 만한 패턴입니다.
