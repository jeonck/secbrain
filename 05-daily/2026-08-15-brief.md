## 오늘 하나만 본다면

Claude Agent SDK(Python) 0.2.137(2026-08-12)이 `UserMessage`·`ResultMessage`에 `origin: MessageOrigin` 필드를 추가해, 사람이 직접 보낸 프롬프트(`"human"`)와 백그라운드 작업·예약 트리거(`TaskNotificationOriginSubkind`)·형제 세션 메시지를 구분할 수 있게 했습니다. 이 커밋과 함께 들어온 `resume_session_at`/`resume_drops_turn` 옵션은 마지막 프롬프트 이전으로 안전하게 되감으면서도 관측되지 않은 메시지를 조용히 버리지 않도록 합니다. 이 브리프 자체가 "예약 실행"(daily-brief 스케줄러)으로 트리거되는 세션인데, SDK가 이제 그 트리거 종류를 메시지 단위로 구분할 수 있다는 점에서 [[secbrain-site]]가 스킬 실행 로그나 세션 관리를 짤 때 참고할 만합니다.

## agents

### Claude Agent SDK 0.2.137 — 메시지 origin 구분, 안전한 세션 되감기
`UserMessage`/`ResultMessage`에 `origin` 필드가 생겨 프롬프트가 사람이 직접 입력한 것인지, 백그라운드 작업·예약 트리거·형제 세션에서 온 것인지 구분됩니다(`MessageOrigin`, `MessageOriginKind`, `TaskNotificationOriginSubkind` export). 같은 릴리스에서 `ClaudeAgentOptions`에 `resume_session_at`/`resume_drops_turn`이 추가돼, 마지막 프롬프트 이전 시점으로 되감으면서도 관측되지 않은 메시지를 조용히 삭제하지 않는 재개 방식을 지원합니다. `ConversationResetMessage`도 새로 생겨 `/clear` 등으로 대화가 리셋되는 시점을 dataclass로 감지할 수 있습니다.

- 출처: [anthropics/claude-agent-sdk-python releases (v0.2.137)](https://github.com/anthropics/claude-agent-sdk-python/releases) · 2026-08-12
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 이 daily-brief 스킬 자체가 예약 트리거로 도는 세션입니다. `origin`이 예약 트리거를 구분해준다면, [[secbrain-site]]가 향후 어떤 스킬이 사람 입력인지 자동 실행인지를 SDK 레벨에서 구분해 로깅·재시도 정책을 다르게 짤 수 있습니다.

### Claude Code v2.1.233 — 대기 중 종료된 클라우드 세션 복구, Bash 메모리 상한
`claude agents` 뷰와 `--worktree` 플래그가 GitLab MR URL을 지원하게 됐고, Linux에서 Bash 도구 명령에 메모리 cgroup 상한(`CLAUDE_CODE_TOOL_MEMORY_LIMIT`)을 걸 수 있는 옵트인 기능이 추가됐습니다. 권한 프롬프트를 기다리던 중 환경이 종료돼 클라우드 세션이 "lost"로 잘못 표시되던 버그도 고쳐졌습니다.

- 출처: [anthropics/claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) (v2.1.233, 2026-08-14) · 2026-08-14
- 신뢰도: 높음 (공식 리포지토리 CHANGELOG, 1차 출처)
- 왜 중요한가: 이 저장소의 daily-brief·weekly-review 같은 스킬이 GitHub Actions 위에서 헤드리스로 도는 클라우드 세션에 가깝습니다. "권한 대기 중 종료 → lost 오표시" 버그 수정은 예약 실행이 중간에 끊길 때의 신뢰성과 직결됩니다.

## devtools

### Ollama v0.32.11 — DeepSeek Harness·Muse Code 런처 추가
`ollama launch dsh`로 DeepSeek의 오픈소스 에이전트 하니스를, `ollama launch muse`로 Meta Superintelligence Labs의 첫 공개 모델인 Muse Glimmer(30B, 에이전트 워크로드용 멀티모달)를 구동하는 Muse Code CLI를 로컬에서 띄울 수 있게 됐습니다. OpenAI 호환 Responses API에 웹 검색 지원도 추가됐습니다.

- 출처: [ollama/ollama releases (v0.32.11)](https://github.com/ollama/ollama/releases) · 2026-08-14
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 프론티어 벤더의 에이전트 하니스·코딩 CLI를 로컬 오픈웨이트 모델로 그대로 구동하는 사례가 늘고 있습니다. [[2026-08-11-brief]]의 Warp Agent CLI, [[2026-08-13-brief]]의 GitHub Copilot CLI kimi-k3 지원에 이어, 이번엔 Ollama가 벤더 하니스 자체(DeepSeek Harness, Muse Code)를 실행 대상으로 삼았다는 점이 다릅니다.
