## anthropic

### Claude 텍스트 워터마크 — EU AI Act 실행강령 대응
Claude가 토큰을 선택할 때 사용하는 난수 생성 방식을 암호화 키 기반으로 바꿔, 특정 키로 텍스트가 Claude에 의해 생성됐을 확률을 사후 검증할 수 있게 했습니다. 텍스트용 워터마크 검출 API가 곧 제공될 예정이며, 이미지·파일은 C2PA 콘텐츠 자격증명으로, 정확한 결과가 필요한 코드 등에는 워터마크를 적용하지 않습니다.

- 출처: [Anthropic — How Claude's text watermark works](https://www.anthropic.com/news/claude-text-watermark) · 2026-08-14
- 신뢰도: 높음 (공식 발표, 1차 출처)
- 왜 중요한가: 이 vault의 daily-brief·ask 스킬이 만드는 노트 본문도 Claude가 생성한 텍스트입니다. API로 검출 기능이 열리면 [[secbrain-site]]가 AI 생성 노트와 사람이 직접 쓴 노트를 구분해 표시하는 근거로 쓸 수 있습니다.

## devtools

### GitHub Copilot CLI v1.0.80 — Agent Host Protocol로 여러 터미널이 세션 공유
Agent Host Protocol(AHP)이 도입돼 여러 터미널·클라이언트가 같은 CLI 세션에 동시 접속할 수 있게 됐습니다(`/ahp start|stop|restart`, 쉼표로 구분한 다중 호스트 연결, 접속 시 "2 clients" 표시). 세션 탭에서 호스트별 실행 상태·연결 끊김을 모니터링하고 `h` 키로 호스트를 전환하며, `--ahp codespace <name>`으로 Codespace에도 연결됩니다. 샌드박스 쪽은 읽기 전용 경로가 파일 도구 쓰기를 실제로 차단하도록 강화됐습니다.

- 출처: [github/copilot-cli releases — v1.0.80-0](https://github.com/github/copilot-cli/releases/tag/v1.0.80-0) · 2026-08-13
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 같은 에이전트 세션을 여러 창·기기에서 공유하는 문제는 [[secbrain-site]]가 예약 실행(daily-brief)과 사용자의 직접 대화 세션을 함께 다룰 때 부딪히는 것과 같은 문제입니다. Claude Agent SDK가 어제자 브리프에서 다룬 `origin` 필드(사람 vs 예약 트리거 구분)와 마주 보는 접근 — Copilot CLI는 "여러 클라이언트가 같은 세션을 보는" 쪽을 택했습니다.
