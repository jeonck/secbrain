## 오늘 하나만 본다면

Claude Code v2.1.234(2026-08-17)에서 내장 스킬을 온디맨드로 로딩하도록 바꿔, `claude-api` 같은 참조 문서형 스킬을 쓸 때 소모되던 컨텍스트가 200k+ 토큰에서 약 25k 토큰으로 줄었습니다. 이 vault는 `.claude/skills/`에 daily-brief·ask·braindump·weekly-review·consolidate 다섯 개의 마크다운 스킬을 두고 예약 실행으로 매일 돌립니다 — 스킬 로딩 비용이 낮아지면 같은 세션에서 더 많은 실제 작업(검색·본문 확인·노트 작성)에 컨텍스트를 쓸 수 있다는 뜻입니다. 같은 주간, Todo/Task 추적 도구가 최신 모델에서 기본 비활성화된 것도 함께 봐야 할 변화입니다 — 이번 실행에서도 "task tools haven't been used recently" 알림이 그 결과입니다.

## anthropic

### Claude Code — 내장 스킬 로딩 컨텍스트 비용 절감
`claude-api` 등 내장 참조 스킬을 필요할 때만 문서를 불러오는 방식으로 바꿔, 로딩 비용이 200k+ 토큰에서 약 25k 토큰으로 줄었습니다.

- 출처: [Claude Code Changelog — v2.1.234](https://code.claude.com/docs/en/changelog) · 2026-08-17
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 다섯 개의 커스텀 스킬(braindump, daily-brief, weekly-review, consolidate, ask)로 동작합니다. 스킬 로딩 오버헤드가 줄면 예약 실행마다 실제 검색·집필에 쓸 수 있는 컨텍스트가 늘어납니다.

### Claude Code — Todo/Task 추적 도구, 최신 모델에서 기본 비활성화
Opus 4.8, Sonnet 5, Fable 5, Mythos 5 이상에서 `TaskCreate`/`TaskUpdate`/`TodoWrite` 같은 태스크 추적 도구가 기본적으로 꺼집니다. 필요하면 `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`로 복원할 수 있습니다.

- 출처: [Claude Code Changelog — v2.1.233](https://code.claude.com/docs/en/changelog) · 2026-08-14
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: 이번 daily-brief 예약 실행 세션에서 실제로 "task tools haven't been used recently"라는 안내가 떴는데, 이 변경이 원인입니다. [[secbrain-site]]의 스킬들은 별도 태스크 추적 없이 단일 절차를 순서대로 수행하는 구조라 영향은 적지만, 여러 단계짜리 스킬을 새로 설계할 때는 이 기본값을 감안해야 합니다.

### Compliance API — 로컬 세션(Cowork·Claude Code) 트랜스크립트 조회 베타
Enterprise 조직 대상으로, 사용자 기기에서 실행된 Cowork·Claude Code 세션의 트랜스크립트를 `GET /v1/compliance/apps/sessions/local` 계열 엔드포인트로 조회할 수 있게 됐습니다.

- 출처: [Claude Platform Release Notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-11
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: 예약 실행으로 vault에 자동 커밋되는 이 daily-brief 같은 산출물의 감사 추적(audit trail)이 Enterprise 플랜에서는 API로 조회 가능해진다는 신호입니다. 개인 vault에는 직접 해당하지 않지만, "AI가 무엇을 근거로 이 노트를 썼는가"를 사후 검증하는 흐름이 플랫폼 차원에서 강화되고 있습니다.
