## 오늘 하나만 본다면

Claude Code 2.1.235에서 언어 서버가 연결·재연결될 때마다 프롬프트 캐시 전체가 무효화되던 버그가 수정됐습니다. 이 vault는 `.claude/skills/`의 daily-brief·weekly-review·braindump·consolidate·ask를 예약 실행으로 매일 돌리는데, 같은 스킬을 반복 실행할 때마다 캐시가 매번 깨졌다면 그만큼 비용과 지연이 누적됐을 가능성이 있습니다 — 이번 수정으로 그 낭비가 줄어듭니다.

## anthropic

### Claude Code 2.1.235 — 프롬프트 캐시 무효화 버그 수정
`spellcheck` 설정 추가와 함께, 언어 서버 연결·재연결 시 프롬프트 캐시 전체가 무효화되던 문제를 수정했습니다. `/ultrareview`, `/autofix-pr` 등 클라우드 백그라운드 세션의 메모리·CPU 사용량도 최적화됐습니다.

- 출처: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) · 날짜 미상 (2.1.234(8/17) 다음 버전, 확인 시점 2026-08-18)
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 스킬을 예약 실행으로 매일 반복합니다. 프롬프트 캐시가 세션마다 무효화되면 반복 실행 비용이 누적되는데, 이 수정으로 그 낭비가 줄어듭니다.
