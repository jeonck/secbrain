## 오늘 하나만 본다면

Claude Code 2.1.236에서 auto mode의 git 상태 확인이 `status.showUntrackedFiles=no` 설정에 속아 "깨끗한 트리"로 잘못 보고하던 문제가 고쳐졌고, auto mode가 켜져 있는 동안 `Monitor` 허용 규칙도 Bash 명령과 같은 방식으로 재검토되도록 바뀌었습니다. 이 vault는 스킬이 파일만 남기면 "다음 단계가 처리"하는 구조([[secbrain-site]])라, 그 다음 단계가 git 상태를 근거로 커밋 여부를 판단한다면 이번 수정이 바로 그 판단의 정확도에 영향을 줍니다.

## anthropic

### Claude Code 2.1.236
`ANTHROPIC_DEFAULT_MODEL` 환경변수가 추가돼 새 세션의 시작 모델을 지정할 수 있게 됐고(`/model`로 고르면 재시작 후에도 유지), macOS 샌드박스에서 `**/.env` 같은 와일드카드 read-deny 규칙이 허용된 읽기 영역 안에서도 우선 적용되고 파일명을 바꿔도 우회되지 않도록 강화됐습니다. 위에서 언급한 auto mode git status 수정도 이 버전에 포함됩니다.

- 출처: [claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · 날짜 미상 (2.1.235(8/18) 다음 버전, 확인 시점 2026-08-19)
- 신뢰도: 높음 (공식 GitHub 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]의 파이프라인이 신뢰하는 git 상태 판단과 샌드박스 read-deny 규칙 양쪽에 걸린 수정입니다.

### Admin API — Claude Enterprise 사용자 관리 GA
멤버·초대·그룹·커스텀 역할을 다루는 Admin API의 사용자 관리 엔드포인트가 베타에서 정식 출시(GA)로 전환됐습니다. `anthropic-beta: ce-user-management-2026-07-13` 헤더는 더 이상 그룹·커스텀 역할 요청에 필수가 아닙니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-19
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: 이 vault는 개인 저장소라 Claude Enterprise 조직 관리와 직접 닿지는 않지만, 베타로 시작한 API 표면이 안정화되는 속도를 보여주는 지표입니다.
