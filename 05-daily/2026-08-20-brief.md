## 오늘 하나만 본다면

Claude Code 2.1.238에서 확장 세션 중 서브에이전트 결과가 화면 표시 범위를 벗어나면 즉시 메모리에서 해제되도록 바뀌어, 장시간 세션에서 무한히 쌓이던 메모리 증가 버그가 고쳐졌습니다. 이 vault는 [[secbrain-site]]에서 설명하는 것처럼 GitHub Actions가 매일·매주 Claude Code를 예약 실행하는 구조라, 세션이 길어질수록 메모리가 새던 문제가 고쳐진 것은 이 파이프라인이 실제로 의존하는 안정성에 직접 닿습니다.

## anthropic

### Claude Code 2.1.238
확장 세션에서 서브에이전트 결과가 표시 범위를 벗어나면 해제되도록 고쳐 무한 메모리 증가를 막았고, 자체 호스팅 러너가 종료 전 세션을 정상적으로 정지시킬 수 있는 `--defer-shutdown-max-min` 플래그가 추가됐습니다. 그 외 `keybindingFlavor` 설정(Ctrl+W를 Bash처럼 이전 공백까지 지우는 "readline" 모드), 플러그인 마켓플레이스의 `headersHelper` 커맨드(카탈로그·아카이브 요청용 HTTP 헤더 생성)도 포함됐습니다.

- 출처: [claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · 2026-08-20 (확인 시점 기준 최신 버전)
- 신뢰도: 높음 (공식 GitHub 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]의 예약 실행 파이프라인이 매일 Claude Code 세션을 새로 띄우는 구조라, 장시간 세션의 메모리 누수 수정은 이 파이프라인 자체의 안정성 수정입니다.

### Claude Code 2.1.237 — Concise 출력 스타일
`/config`에서 고를 수 있는 내장 "Concise" 출력 스타일이 추가됐습니다. 서론이나 진행 상황 서술 없이 결과부터 제시하되 작업 자체의 철저함은 유지합니다. 같은 버전에서 LLM 게이트웨이나 커스텀 base URL을 쓰는 세션의 프롬프트 캐싱 문제도 고쳐졌습니다.

- 출처: [claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · 2026-08-19
- 신뢰도: 높음 (공식 GitHub 체인지로그, 1차 출처)
- 왜 중요한가: 이 skill들은 결과 파일만 남기고 커밋은 다음 단계가 처리하는 구조([[secbrain-site]])라, 대화형 서술이 아니라 결과 중심으로 동작하는 출력 스타일이 스킬 실행 방식과 방향이 같습니다.

### 컴퓨터 사용·브라우저 사용 툴셋 GA
Claude API의 computer use 툴이 `computer_toolset_20260801`로 정식 출시(GA)돼 베타 헤더 없이 배치 액션과 기본 활성화된 `zoom`을 지원하게 됐고, 새 브라우저 사용 툴(`browser_toolset_20260801`)도 함께 출시돼 데스크톱 전체가 아니라 브라우저 뷰포트 안에서 접근성 트리·폼·탭을 직접 다룰 수 있게 됐습니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-19
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: 이 vault는 정적 사이트([[secbrain-site]])라 브라우저 자동화를 직접 쓰진 않지만, 에이전트 툴 표면이 데스크톱 전체 제어에서 브라우저 단위 제어로 세분화되는 흐름은 에이전트 설계 참고 사례입니다.

## agents

### Microsoft Agent Framework — dotnet-1.18.0
A2A 태스크 스토어에 격리 키(isolation key) 스코핑이 실험적으로 추가됐고, 호스팅 에이전트가 대화 기록을 단일 소스로 관리할 수 있게 됐습니다. 동시 툴 호출(concurrent tool invocation) 옵션과 선언형 워크플로 문자열 파싱 개선, 툴 승인 자동 승인 루프 버그 수정도 포함됐습니다.

- 출처: [microsoft/agent-framework releases — dotnet-1.18.0](https://github.com/microsoft/agent-framework/releases) · 2026-08-18
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 대화 기록을 단일 소스로 관리하는 방식은, 이 vault가 마크다운 파일 하나를 노트의 단일 소스로 삼는 구조와 비교해볼 만한 참고 사례입니다.

## devtools

### GitHub Copilot CLI v1.0.81-6
인터랙티브 세션의 시작 모드와 승인 동작을 지정하는 `defaultMode`·`defaultPermissionMode` 설정이 추가됐고, 로그인 시 표준입력으로 인증 토큰을 받는 `--with-token` 플래그가 생겼습니다. ACP 클라이언트는 이제 서브에이전트 ID와 원시 이벤트 구독, 제목·모드·명령·플랜의 실시간 업데이트를 받을 수 있습니다.

- 출처: [github/copilot-cli releases — v1.0.81-6](https://github.com/github/copilot-cli/releases) · 2026-08-20
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: ACP를 통한 서브에이전트 ID·실시간 업데이트 노출은, [[secbrain-site]]가 GitHub Actions로 Claude Code를 예약·온디맨드 실행하며 겪는 것과 같은 종류의 "에이전트 실행을 외부 클라이언트에 어떻게 노출할까" 문제입니다.
