## 오늘 하나만 본다면

Claude Code 2.1.239 (2026-08-21)에서 WebFetch가 만료된 페이지 내용을 세션이 끝날 때까지 메모리에 남겨두던 버그, 커스텀 세션 제목이 대화가 약 64KB를 넘으면 사라지던 버그, deferred tool 실행의 OpenTelemetry 트레이스가 조각나던 버그가 함께 고쳐졌습니다. `daily-brief` 스킬은 주제마다 WebSearch 2~3회에 더해 후보 3~5건을 WebFetch로 직접 확인하라고 규정하는데([[secbrain-site]] 파이프라인이 매일 이 스킬을 예약 실행), WebFetch 결과가 세션 내내 누적되던 버그가 고쳐진 것은 바로 이 실행 패턴의 안정성에 닿습니다.

## anthropic

### Claude Code 2.1.239
WebFetch가 만료된 페이지 내용을 세션 전체 동안 메모리에서 해제하지 않던 버그, 대화가 약 64KB를 넘으면 커스텀 세션 제목이 사라지던 버그, deferred tool 실행의 OpenTelemetry 트레이스 조각화 문제가 고쳐졌습니다. 그 외 원격 MCP 서버가 일시적 5xx 오류 후 계속 실패 상태로 남던 버그, 클라우드 세션이 유휴 워커 재시작 후 플랜 모드 밖으로 재개되던 버그도 수정됐고, `/claude-api upgrade` 명령으로 Python 프로젝트를 `anthropic` 0.x에서 1.x로 마이그레이션할 수 있게 됐습니다.

- 출처: [claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · 2026-08-21
- 신뢰도: 높음 (공식 GitHub 체인지로그, 1차 출처)
- 왜 중요한가: 이 vault의 스킬은 WebSearch·WebFetch를 반복 호출하는 예약 세션으로 도는 구조([[secbrain-site]])라, WebFetch 메모리 누수 수정은 이 실행 패턴 자체의 안정성 개선입니다.

### Python SDK v1.0
Anthropic Python SDK가 1.0으로 올라가며 HTTP 레이어가 `httpx`에서 API 호환 포크인 `httpx2`로 바뀌었습니다. Python 3.10 이상이 필요하고, 레거시 Text Completions API·Messages의 `temperature`/`top_p`/`top_k`·tool runner의 클라이언트 측 `compaction_control` 등 오래전에 지원 종료(deprecated)된 표면이 제거되는 breaking change입니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-20
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: 이 vault 자체는 Python SDK를 직접 쓰지 않지만, Claude API를 Python으로 감싼 도구를 쓴다면 1.x 마이그레이션 가이드를 먼저 봐야 하는 breaking change입니다.

## agents

### Microsoft Agent Framework — python-1.14.0

- 출처: [microsoft/agent-framework releases — python-1.14.0](https://github.com/microsoft/agent-framework/releases) · 2026-08-14
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: [[cog-architecture]]가 정리한 "리드(비싼 모델)가 판단, 워커(싼 모델)가 I/O" 패턴처럼, 에이전트 실행 중간에 훅을 끼워 넣는 미들웨어 방식은 이 vault의 스킬 구조를 다른 프레임워크와 비교해볼 참고 사례입니다.
