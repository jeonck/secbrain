## 오늘 하나만 본다면

Microsoft Agent Framework가 `dotnet-1.19.0`(2026-08-22)과 `python-1.15.0`(2026-08-21)을 연달아 냈습니다. dotnet 쪽은 세션이 영속된 채팅 클라이언트 라우팅과 Azure Blob Storage 세션 영속화를, python 쪽은 OpenTelemetry 시맨틱 컨벤션 정리와 워크플로 체크포인트·A2UI 지원을 더했습니다. [[cog-architecture]]가 정리한 "리드가 판단, 워커가 I/O" 패턴과 맞닿는, 세션·상태 영속화 쪽 움직임이라 이 vault의 스킬 구조와 비교해볼 만합니다.

## agents

### Microsoft Agent Framework — dotnet-1.19.0
세션이 영속된 채팅 클라이언트 라우팅과 Azure Blob Storage 기반 세션 영속화가 추가됐고, MCP 장기 실행 작업(long-running task) 지원이 2026-07-28 Tasks 확장으로 이관됐습니다.

- 출처: [microsoft/agent-framework releases — dotnet-1.19.0](https://github.com/microsoft/agent-framework/releases) · 2026-08-22
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 세션 상태를 어디에 영속시키느냐는 [[cog-architecture]]에서 다룬 리드/워커 분리 구조와 직접 연결되는 설계 결정입니다.

### Microsoft Agent Framework — python-1.15.0
OpenTelemetry 시맨틱 컨벤션을 명시적 메시지 이벤트 제어로 통합했고, Foundry Hosted Agents용 steering·retry 지원, 워크플로 체크포인트, A2UI 지원이 강화됐습니다.

- 출처: [microsoft/agent-framework releases — python-1.15.0](https://github.com/microsoft/agent-framework/releases) · 2026-08-21
- 신뢰도: 높음 (공식 GitHub 릴리스, 1차 출처)
- 왜 중요한가: 에이전트 실행 관측성(observability)을 표준화하려는 시도로, 이 vault의 스킬 실행을 다른 프레임워크의 트레이싱 방식과 비교할 참고 사례입니다.

## anthropic

### Claude Code 2.1.240
"버그 수정 및 안정성 개선"이라는 한 줄 설명 외에 공개된 세부 항목이 없는 유지보수 릴리스입니다. 전날(2026-08-21) 나온 2.1.239는 WebFetch 메모리 누수, 세션 제목 유실, OpenTelemetry 트레이스 조각화 등을 고쳤고 이미 어제 브리프에서 다뤘습니다.

- 출처: [Claude Code changelog](https://code.claude.com/docs/en/changelog) · 2026-08-22
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: 내용이 얇아 당장 조치할 것은 없지만, 이 vault의 스킬이 매일 Claude Code로 예약 실행되므로([[secbrain-site]]) 버전 추적 목적으로만 기록합니다.

## devtools

### Zed 1.17.0 (preview)
CSV·TSV·PSV·SSV 파일을 정렬·크기조절 가능한 컬럼으로 미리보는 표 데이터 프리뷰가 추가됐고, Git blame 액션과 추적/스테이지 대상만 골라 스태시하는 옵션이 생겼습니다. 대용량 파일 로딩 시 최대 메모리 사용량도 파일 크기만큼 줄었고, 에이전트의 터미널·fetch 도구에 샌드박싱이 적용됐습니다.

- 출처: [Zed preview releases](https://zed.dev/releases/preview/latest) · 2026-08-19
- 신뢰도: 높음 (공식 릴리스 페이지, 1차 출처)
- 왜 중요한가: 에이전트 도구 실행에 샌드박싱을 붙이는 방향은 이 vault의 스킬이 파일시스템 쓰기 범위를 제한받는 것과 같은 문제의식입니다.
