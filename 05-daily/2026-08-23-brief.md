## 오늘 하나만 본다면

Model Context Protocol 코어 메인테이너가 커뮤니티 워킹그룹과 함께 2026-08-22 새 로드맵을 발표했습니다. 서버 시작 이벤트·구독·진행 알림 같은 "에이전트 메시징 기본 요소", 원격 MCP 서버를 일반 HTTP 워크로드처럼 배포하게 하는 전송 통합, DPoP 기반 에이전트 신원·보안 표준화가 다음 우선순위로 명시됐습니다. 2026-07-28 사양이 상태 비저장 서버 확장성과 다중 왕복 요청을 이미 들여온 뒤라, 이번 로드맵은 이 vault의 스킬이 의존하는 "에이전트가 도구를 호출하고 상태를 주고받는" 기본 패턴이 앞으로 어떻게 표준화될지 보여줍니다.

## agents

### MCP 로드맵 (2026-08-22)
코어 메인테이너와 커뮤니티 워킹그룹이 다음 우선순위 5가지를 발표했습니다: ① 에이전트 메시징 기본 요소(서버 시작 이벤트, 구독, 진행 알림), ② HTTP 기반 전송 통합("원격 MCP 서버는 다른 HTTP 워크로드와 다를 바 없음"), ③ DPoP·워크로드 신원 페더레이션 기반 에이전트 신원·보안 표준화, ④ 도구 호출 결과 처리 표준화와 점진적 기능 발견, ⑤ SDK 인체공학 개선. 2026-03 로드맵 대비 2026-07-28 사양 릴리스(상태 비저장 서버, 다중 왕복 요청)가 이미 상당 부분을 달성했다고 평가했습니다.

- 출처: [The New MCP Roadmap — Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) · 2026-08-22
- 신뢰도: 높음 (코어 메인테이너 공식 블로그, 1차 출처)
- 왜 중요한가: [[cog-architecture]]가 정리한 "리드가 판단, 워커가 I/O" 패턴은 결국 에이전트 간 메시징·신원 문제로 이어지는데, 이번 로드맵이 그 표준화 방향을 먼저 제시합니다.

## anthropic

### Claude Skills API · Files API 정식 출시(GA)
2026-08-20 발표에서 Skills API가 업로드·버전 관리를 간소화한 형태로 정식 출시됐고, Files API는 속도 제한이 5배로 늘고 조직당 저장 공간이 1TB로 확대됐습니다. 같은 발표에서 computer use 툴과 새 browser use 툴도 정식 출시됐는데, 이 부분은 [[2026-08-20-brief]]에서 이미 다뤘습니다.

- 출처: [Build production agents with computer use, the Skills API, and the Files API — Claude by Anthropic](https://claude.com/blog/computer-use-skills-api-files-api) · 2026-08-20
- 신뢰도: 높음 (공식 블로그, 1차 출처)
- 왜 중요한가: `.claude/skills/`로 스킬을 마크다운 지시문으로 관리하는 이 vault의 구조와, Anthropic이 API 레벨에서 "재사용 가능한 스킬"을 정식 기능으로 만든 방향이 같은 문제의식을 공유합니다.
