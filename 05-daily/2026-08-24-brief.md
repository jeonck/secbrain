## 오늘 하나만 본다면

Linux Foundation 산하 Agentic AI Foundation(AAIF)이 2026-08-20 Google의 A2A 프로토콜 합류를 발표했습니다. AAIF는 이미 Anthropic이 창립 프로젝트로 기증한 MCP를 품고 있던 곳이라, 이제 "에이전트-도구" 계층(MCP)과 "에이전트-에이전트" 계층(A2A)이 같은 중립 거버넌스 아래 놓이게 됐습니다. AWS·Anthropic·Google·Microsoft 등 250개 이상 조직이 참여 중이라, 특정 벤더에 락인되지 않는 멀티벤더 에이전트 아키텍처가 표준 차원에서 힘을 받는 흐름입니다.

## agents

### A2A 프로토콜, Agentic AI Foundation에 합류
2026-08-20, Linux Foundation 산하 Agentic AI Foundation(AAIF)이 Google의 A2A(Agent2Agent) 프로토콜이 재단에 합류했다고 발표했습니다. AAIF는 2025-12 OpenAI·Anthropic·Google·Microsoft·AWS·Block 6개사가 공동 창립했고 현재 250개 이상 조직이 참여하는 중립 거버넌스 재단으로, Anthropic의 MCP가 창립 프로젝트로 이미 속해 있던 곳입니다. MCP가 에이전트와 도구/데이터를 연결하는 수직 계층을 표준화한다면, A2A는 조직 경계를 넘는 에이전트 간 통신·조율을 다룹니다.

- 출처: [A2A Protocol Surpasses 150 Organizations... — Linux Foundation](https://www.linuxfoundation.org/press/a2a-protocol-surpasses-150-organizations-lands-in-major-cloud-platforms-and-sees-enterprise-production-use-in-first-year) · 2026-08-20
- 신뢰도: 높음 (Linux Foundation 공식 보도자료, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 이슈 → Actions → Claude Code라는 단일 에이전트 파이프라인이지만, [[cog-architecture]]가 정리한 "리드-워커" 패턴을 여러 조직·벤더로 확장하려면 결국 이런 조직 간 에이전트 통신 표준에 의존하게 됩니다. 어제 브리프에서 다룬 MCP 로드맵(에이전트 신원·메시징 기본 요소)과 같은 방향의 움직임입니다.

## anthropic

### Claude Code 2.1.239 (2026-08-21)
데이터 레지던시 워크스페이스에 대해 비용 추정치가 미국 전용 추론 1.1배 프리미엄을 반영하도록 바뀌었고, `anthropic` SDK 0.x → 1.x 마이그레이션을 돕는 `/claude-api upgrade` 스킬이 추가됐습니다. Bedrock·Vertex·Foundry 등 이전에 제외됐던 환경에도 풀스크린 렌더러 제안이 붙었고, Alpine/musl 빌드에서 네이티브 이미지 붙여넣기·클립보드·오디오 캡처가 지원됩니다.

- 출처: [claude-code CHANGELOG.md](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md) · 2026-08-21
- 신뢰도: 높음 (공식 GitHub 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]의 예약 실행이 매일 GitHub Actions에서 Claude Code로 도는 구조라, 비용 추정·SDK 마이그레이션 관련 변경은 파이프라인 운영에 직접 닿습니다.

### Python SDK v1.0 (2026-08-20)
Anthropic Python SDK가 1.0으로 올라가며 HTTP 레이어가 `httpx`에서 `httpx2`로 바뀌고, 레거시 Text Completions API와 `temperature`/`top_p`/`top_k` 파라미터 등 오래된 표면이 제거됐습니다. Python 3.10 이상이 필요합니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-20
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: 이 vault는 API를 직접 호출하지 않지만, `.claude/skills/`가 결국 Claude Code CLI(내부적으로 이 SDK 계열)에 의존하므로 breaking change 계열 업데이트로 기록해 둡니다.

## devtools

### GitHub Copilot, Slack 안에서 협업형 에이전트 세션 공개 프리뷰
2026-08-21, GitHub이 Slack 안에서 `@GitHub`를 멘션해 에이전트 세션을 시작하는 기능을 공개 프리뷰로 냈습니다. 에이전트 세션이 팀 전체에 공유되어 한 사람이 사적으로 붙잡고 있는 대신 diff 리뷰·피드백을 채널에서 같이 하고, 세션은 비동기로 계속 작업을 진행합니다. Copilot Business/Enterprise 플랜에서 사용 가능합니다.

- 출처: [The new GitHub Copilot experience in Slack — GitHub Changelog](https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack/) · 2026-08-21
- 신뢰도: 높음 (공식 GitHub Changelog, 1차 출처)
- 왜 중요한가: Claude Code도 최근(2.1.236, `notify_when_idle`; 2.1.232, 세션 간 `@`멘션) 세션 간 협업 기능을 붙이는 중이라, "에이전트 작업을 어디서 같이 볼 것인가"가 여러 벤더에서 동시에 풀리고 있는 문제라는 걸 보여줍니다. [[secbrain-site]]는 아직 단일 세션·단일 이슈 모델이라 직접 적용점은 없지만 비교 대상으로 기록.
