## 오늘 하나만 본다면

Model Context Protocol이 2026-08-22 새 로드맵을 발표했습니다. 지난 3월 로드맵(전송 계층, 에이전트 통신, 거버넌스, 엔터프라이즈 준비)의 성과 대부분이 2026-07-28 스펙에 반영됐고, 이제 다음 우선순위는 메시징 프리미티브(구독·진행 알림 등 요청-응답을 벗어난 패턴), HTTP 네이티브 전송 통합, 에이전트 신원(DPoP·Workload Identity Federation 기반), 프리미티브 개선, SDK 경험입니다. "도구를 어떻게 부를까"에서 "장기 실행되는 위임 작업을 어떻게 신뢰하고 추적할까"로 MCP의 무게중심이 옮겨가는 흐름이라, [[secbrain-site]]처럼 이슈 → Actions → Claude Code로 실행이 위임되는 구조와 직접 맞닿습니다.

## agents

### MCP, 2026 로드맵 갱신 — "도구 호출"에서 "위임 인프라"로
MCP 코어 메인테이너와 워킹그룹이 2026-08-22 새 로드맵을 공개했습니다. 지난 로드맵의 성과(프로토콜 레벨 세션·초기화 핸드셰이크 제거로 서버가 상태 없이 수평 확장 가능, Contributor Ladder 공식화, 기능 수명주기·폐기 정책 도입)를 정리한 뒤, 다음 5개 우선순위를 제시했습니다: ①메시징 프리미티브(태스크·구독·진행 알림), ②HTTP 네이티브 전송 통일, ③에이전트 신원과 엔터프라이즈 보안(DPoP, Workload Identity Federation), ④도구 호출 결과 처리 표준화와 점진적 발견을 통한 카탈로그 확장성, ⑤SDK 개발자 경험 개선.

- 출처: [The New MCP Roadmap — Model Context Protocol Blog](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/) · 2026-08-22
- 신뢰도: 높음 (MCP 공식 블로그, 1차 출처)
- 왜 중요한가: [[cog-architecture]]가 정리한 리드-워커 패턴과 [[secbrain-site]]의 이슈 기반 위임 실행 모두 "누가 이 작업을 요청했고 언제 끝났는지"를 신뢰할 방법이 필요합니다. 에이전트 신원 우선순위는 지금은 GitHub 로그인에 얹혀 있는 이 vault의 인증 모델이 나중에 벤더 중립 표준으로 옮겨갈 여지를 보여줍니다.

## anthropic

### Claude Code 2.1.243 — 루프 사용량 분석과 조직 계약 가격
2026-08-25 배포된 2.1.243은 `/usage`에 "Loops" 분석(루프별 실행 횟수·총 토큰·실행당 토큰·마지막 실행 시각)을 추가했고, `modelPricing` 관리 설정으로 조직의 계약 가격을 비용 추정에 반영할 수 있게 됐습니다. `promptCacheTtl`/`subagentPromptCacheTtl`로 프롬프트 캐시 TTL을 직접 제어하는 설정과, Anthropic Console을 통한 키리스 로그인, `/status`의 GitHub 연결 상태 표시도 함께 들어왔습니다. 같은 날 나온 2.1.245는 glibc 2.44(Arch·CachyOS·Fedora Rawhide) 환경의 시작 시 크래시를 수정한 패치입니다.

- 출처: [Claude Code changelog](https://code.claude.com/docs/en/changelog) · 2026-08-25
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 GitHub Actions에서 예약 스킬(`daily-brief`, `weekly-review` 등)을 루프처럼 반복 실행하는 구조라, 루프별 토큰 사용량을 볼 수 있게 된 것은 이 파이프라인의 비용을 직접 추적할 수 있게 됐다는 뜻입니다.

## devtools

### GitHub Copilot for JetBrains, 엔터프라이즈 관리 설정 추가
2026-08-18 GitHub이 Copilot for JetBrains에 서버 기반 엔터프라이즈 관리 설정을 추가했습니다. 관리자가 플러그인 거버넌스, MCP 서버 접근 범위, OpenTelemetry, 권한 우회(bypass) 동작을 조직 전체에 걸쳐 중앙에서 통제할 수 있습니다.

- 출처: [Enterprise managed settings in GitHub Copilot for JetBrains — GitHub Changelog](https://github.blog/changelog/2026-08-18-enterprise-managed-settings-in-github-copilot-for-jetbrains/) · 2026-08-18
- 신뢰도: 높음 (공식 GitHub Changelog, 1차 출처)
- 왜 중요한가: 직접적인 적용점은 없지만, "MCP 서버 접근"이 엔터프라이즈 관리 설정 항목으로 명시된 것은 agents 섹션의 MCP 에이전트 신원 우선순위와 같은 방향 — 개인 vault 수준에선 아직 안 보이는 통제 계층이 조직 규모에서는 이미 표준 기능이 되고 있습니다.
