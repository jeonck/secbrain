## 오늘 하나만 본다면

2026-08-26 Anthropic 블로그에 공개된 사례에서, 터미널 앱 Warp는 코드 리뷰 에이전트를 "기능 스킬"(실제 작업 수행)과 "개선 스킬"(스케줄에 따라 사람 피드백을 분석해 기능 스킬의 지시문을 고치는 감독자) 두 층으로 나눴습니다. 사람 피드백은 PR·이슈 위에서 바로 남기고, 개선 스킬이 이를 모아 패턴을 뽑아 기능 스킬 파일을 고치며, 그 변경은 일반 코드 리뷰를 거쳐 머지된 뒤에야 다음 실행에 반영됩니다. [[secbrain-site]]의 스킬(`daily-brief`, `braindump` 등)도 똑같이 "마크다운 파일이 곧 에이전트의 행동"인 구조이므로, 지금은 사람이 `.claude/skills/*.md`를 직접 고치는 자리에 이런 피드백 수집·제안 단계를 넣을 수 있는지가 참고할 지점입니다.

## agents

### Warp, Claude 위에서 자가개선 에이전트를 만드는 방법 공개
Warp의 코드 리뷰 에이전트는 도메인 지식을 담은 "기능 스킬"과, 스케줄대로 실행되며 누적된 사람 피드백과 에이전트 제안을 비교해 기능 스킬의 지시문을 고쳐 쓰는 "개선 스킬"로 나뉩니다. 스킬이 평범한 파일이기 때문에 이 수정 자체도 표준 코드 리뷰 워크플로(리뷰·승인·머지)를 거치고, 다음 에이전트 실행부터 개선분을 물려받습니다. Warp는 이 구조로 누적 40M건의 에이전트 대화, 주간 40만 건 이상의 Claude Code 세션을 처리한다고 밝혔습니다.

- 출처: [How Warp builds self-improving agents on Claude — Claude by Anthropic](https://claude.com/blog/how-warp-builds-self-improving-agents-on-claude) · 2026-08-26
- 신뢰도: 높음 (Anthropic 공식 블로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]의 스킬 파일이 정확히 이 "기능 스킬"에 해당합니다. 지금은 스킬 지시문을 고칠 사람이 저 자신(사용자)뿐인데, Warp처럼 "사람이 브리프·답변에 남긴 피드백을 모아 스킬 파일 수정을 제안하는" 감독 스킬을 얹으면 [[cog-architecture]]의 위임 체인에 자기개선 루프를 붙일 수 있습니다.

## anthropic

### Compliance API 세션 엔드포인트, Cowork·Claude Code 세션에 대해 정식 출시
2026-08-26 Claude 개발자 플랫폼 릴리스 노트에 따르면, Compliance API의 세션 엔드포인트가 베타를 벗어나 Cowork와 Claude Code 세션의 전체 트랜스크립트를 조회할 수 있게 됐습니다. 같은 릴리스에서 로컬 세션 엔드포인트는 Claude Science 세션과 Word·Excel·PowerPoint·Outlook용 Microsoft 365 에이전트 세션의 트랜스크립트도 반환하도록 확장됐고(Claude Enterprise 베타), Admin API가 `ant` CLI와 Python·TypeScript·C#·Go·Java·PHP·Ruby SDK의 `client.beta.organization` 아래 정식 지원됐습니다.

- 출처: [Claude Platform release notes](https://platform.claude.com/docs/en/release-notes/overview) · 2026-08-26
- 신뢰도: 높음 (공식 릴리스 노트, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 GitHub Actions에서 Claude Code를 시크릿으로 실행하는 파이프라인입니다. Compliance API로 그 실행 세션의 전체 트랜스크립트를 조회할 수 있다는 것은, 이슈 트리거 → Claude Code 실행 구간에서 "무슨 일이 있었는지"를 사후에 감사할 수 있는 공식 통로가 생겼다는 뜻입니다. 다만 이 저장소는 Claude Enterprise가 아니라 일반 API/Actions 기반이라 실제 접근 가능 여부는 별도 확인이 필요합니다.
