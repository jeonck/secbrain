## 오늘 하나만 본다면

Anthropic 공식 발표(anthropic.com, 2026-09-01)에 따르면 Claude Fable 5.1과 Mythos 5.1이 오늘 출시됐습니다. 두 모델은 안전장치 수준만 다른 동일 모델로, 100만 토큰 컨텍스트·128k 출력 토큰을 기본 지원하고 사이버보안 도메인 오탐이 60% 줄었다고 설명합니다. 이 저장소 입장에서 더 실질적인 변화는 가격입니다 — 표준 입출력 단가($10/$50 per MTok)는 그대로지만 **프롬프트 캐시 읽기 단가가 기존 0.1배에서 0.025배($0.25/MTok)로 75% 인하**됐습니다. `daily-brief`·`weekly-review` 등은 매 실행마다 스킬 지시문(`SKILL.md`)과 CLAUDE.md를 캐시로 반복 로드하는 구조라, 이 인하는 [[secbrain-site]]의 예약 실행(`scheduled.yml`) 비용을 실질적으로 낮춥니다.

### Claude Fable 5.1 · Mythos 5.1 출시 — 100만 토큰 컨텍스트, 캐시 읽기 75% 인하
2026-09-01 Anthropic 공식 발표. Fable 5.1은 API·AWS·Google Cloud·Microsoft Azure 등 전 플랫폼에 즉시 공개됐고, Mythos 5.1은 안전장치를 완화한 동일 모델로 사이버보안·생명과학 분야의 승인된(Project Glasswing) 기관에만 제한 제공됩니다. 코딩·과학 연구·장시간 무인 에이전트 작업 성능이 개선됐다고 밝혔으며, 전형적 워크로드 비용은 약 25% 절감, 에이전틱 작업은 최대 45% 절감된다고 설명합니다 — 이는 대부분 캐시 읽기 단가 인하($1/MTok → $0.25/MTok)에서 나옵니다.

- 출처: [Introducing Claude Fable 5.1 and Claude Mythos 5.1 — Anthropic](https://www.anthropic.com/claude-fable-and-mythos-5-1) · 2026-09-01
- 신뢰도: 높음 (Anthropic 공식 발표, 1차 출처)
- 왜 중요한가: [[secbrain-site]]의 모든 스킬은 매 실행마다 긴 시스템 지시문(SKILL.md, CLAUDE.md)을 반복해서 컨텍스트에 올리는 캐시 의존 구조입니다. 캐시 읽기 단가 75% 인하는 매일/매주 자동 실행되는 daily-brief·weekly-review·consolidate의 실질 운영 비용을 직접 낮추는 변화입니다.

### Simon Willison, ChatGPT Work의 서브에이전트·스킬 구성을 분석
2026-08-30 게시. ChatGPT Work는 Sol·Luna·Terra 등 모델과 추론 레벨을 선택할 수 있고, "Ultra" 모드는 복잡한 프로젝트에서 서브에이전트에 더 적극적으로 위임합니다. 시스템은 223개의 등록 도구와 44개의 스킬을 통합해 문서 생성·브라우저 제어·PDF 처리·스프레드시트 조작 등을 수행합니다. 필자는 OpenAI가 시스템 프롬프트와 도구 설명을 공개하지 않아 투명성이 떨어진다고 지적합니다.

- 출처: [Understanding ChatGPT Work — Simon Willison's Weblog](https://simonwillison.net/2026/Aug/30/understanding-chatgpt-work/) · 2026-08-30
- 신뢰도: 중간 (독립 분석가의 리버스엔지니어링 관찰, OpenAI의 1차 공개 문서는 아님)
- 왜 중요한가: [[secbrain-site]]는 "기능 스킬"(daily-brief, braindump 등) 여러 개를 하나의 에이전트가 파일 형태로 실행하는 구조입니다. 44개 스킬 + 223개 도구를 모드(Ultra)로 위임 강도를 조절하는 방식은, [[cog-architecture]]에서 스킬 수가 늘어날 때 "언제 서브에이전트에 위임할지" 판단 기준을 설계하는 데 참고가 됩니다.

### GitHub Actions, checks·workflow run·status 보존을 저장소 보존 설정으로 통합
2026-08-27 GitHub Changelog 공식 발표. 지금까지 checks·workflow run·status는 저장소 보존 설정과 무관하게 400일 이상 유지됐지만, 2026-10-01부터는 artifacts·logs와 같은 단일 "Check, workflow run, status, artifact and log retention" 설정을 따릅니다. 기본값은 90일이며 공개 저장소는 최대 90일로 상한이 걸리고, 변경은 소급 적용되지 않습니다.

- 출처: [Actions retention will cover checks, workflow runs, and statuses — GitHub Changelog](https://github.blog/changelog/2026-08-27-actions-retention-will-cover-checks-workflow-runs-and-statuses/) · 2026-08-27
- 신뢰도: 높음 (GitHub 공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 공개 저장소이고 `scheduled.yml`이 매일 daily-brief를, 매주 weekly-review를 자동 실행합니다. 10월부터 Actions 실행 로그가 90일 뒤 사라지므로, "어느 날 브리프가 왜 실패했는지" 같은 감사는 3개월 안에 확인해야 합니다. 브리프·리뷰 산출물 자체는 커밋으로 남아 무관합니다.
