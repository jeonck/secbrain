## 오늘 하나만 본다면

GitHub Changelog(2026-08-27)에 따르면 2026-10-01부터 checks·workflow run·status의 보존 기간이 지금까지의 "400일 이상 무조건 유지"에서 artifacts·logs와 같은 저장소 보존 설정(기본 90일)으로 통합됩니다. 소급 적용은 아니지만, 공개 저장소는 최대 90일로 상한이 걸립니다. [[secbrain-site]]는 `.github/workflows/scheduled.yml`로 daily-brief·weekly-review를 매일/매주 자동 실행하는 공개 저장소이므로, 실행 이력(성공/실패 로그) 자체는 10월부터 90일이 지나면 사라집니다. 다만 이 브리프가 만드는 실제 산출물(`05-daily/*.md`)은 git 커밋으로 vault에 영구히 남으므로 데이터 손실은 아니고, "무슨 실행이 언제 실패했는지"를 나중에 Actions 로그로 추적하는 용도로만 영향이 있습니다.

## devtools

### GitHub Actions, checks·workflow run·status 보존을 저장소 보존 설정으로 통합
2026-08-27 GitHub Changelog 공식 발표. 지금까지 checks·workflow run·status는 저장소 보존 설정과 무관하게 400일 이상 유지됐지만, 2026-10-01부터는 artifacts·logs와 같은 단일 "Check, workflow run, status, artifact and log retention" 설정을 따릅니다. 기본값은 90일이며, 조직/엔터프라이즈 상한이 적용되고 공개 저장소는 최대 90일로 제한됩니다. 변경은 소급 적용되지 않아 이미 지난 데이터가 복구되지는 않습니다.

- 출처: [Actions retention will cover checks, workflow runs, and statuses — GitHub Changelog](https://github.blog/changelog/2026-08-27-actions-retention-will-cover-checks-workflow-runs-and-statuses/) · 2026-08-27
- 신뢰도: 높음 (GitHub 공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 공개 저장소이고 `scheduled.yml`이 매일 daily-brief를, 매주 weekly-review를 자동 실행합니다. 10월부터 Actions 실행 로그가 90일 뒤 사라지므로, "어느 날 브리프가 왜 실패했는지" 같은 감사는 3개월 안에 확인해야 합니다. 브리프·리뷰 산출물 자체는 커밋으로 남아 무관합니다.

## agents

### Simon Willison, ChatGPT Work의 서브에이전트·스킬 구성을 분석
2026-08-30 게시. ChatGPT Work는 Sol·Luna·Terra 등 모델과 추론 레벨을 선택할 수 있고, "Ultra" 모드는 복잡한 프로젝트에서 서브에이전트에 더 적극적으로 위임합니다. 시스템은 223개의 등록 도구와 44개의 스킬을 통합해 문서 생성·브라우저 제어·PDF 처리·스프레드시트 조작 등을 수행하며, Codex와 동일한 프롬프트 주입 방어 체계를 씁니다. 필자는 OpenAI가 시스템 프롬프트와 도구 설명을 공개하지 않아 투명성이 떨어진다고 지적합니다.

- 출처: [Understanding ChatGPT Work — Simon Willison's Weblog](https://simonwillison.net/2026/Aug/30/understanding-chatgpt-work/) · 2026-08-30
- 신뢰도: 중간 (독립 분석가의 리버스엔지니어링 관찰, OpenAI의 1차 공개 문서는 아님)
- 왜 중요한가: [[secbrain-site]]는 "기능 스킬"(daily-brief, braindump 등) 여러 개를 하나의 에이전트가 파일 형태로 실행하는 구조입니다. ChatGPT Work가 44개 스킬 + 223개 도구를 조합해 위임 여부를 모드(Ultra)로 조절하는 방식은, [[cog-architecture]]에서 스킬 수가 늘어날 때 "언제 서브에이전트에 위임할지"를 어떻게 판단 기준으로 삼을지에 참고가 됩니다.
