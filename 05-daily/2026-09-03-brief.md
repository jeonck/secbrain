## 오늘 하나만 본다면

Salesforce와 Anthropic이 2026-08-26 "Claudeforce"를 발표했습니다. Salesforce 데이터를 37개 스킬 플러그인으로 Claude에 넣고, Claude를 Agentforce의 기본 추론 모델이자 Slack 전체(Slackbot, Claude Tag, Slack Code)의 기본 AI로 삼는 구조입니다. [[secbrain-site]]가 GitHub 이슈 → Actions → Claude Code 파이프라인으로 돌아가는 것처럼, 이번 발표는 Claude가 서드파티 플랫폼의 "기본 추론 엔진"으로 내장되는 흐름을 보여주는 사례입니다.

## anthropic

### Salesforce·Anthropic, "Claudeforce" 발표 — Claude가 Agentforce·Slack 기본 모델로
Salesforce 공식 보도자료(2026-08-26). Salesforce 데이터를 37개 사전 구축 스킬로 감싼 플러그인이 Claude 안에서 동작하고, Claude가 Agentforce의 Atlas Reasoning Engine 기본 추론 모델이자 Slackbot·Claude Tag·Slack Code 전반의 기본 AI가 됩니다. "Salesforce in Claude"는 현재 일부 파일럿 고객에 제공 중이며 2026년 9월 오픈 베타 예정입니다.

- 출처: [Salesforce and Anthropic Announce Claudeforce — Salesforce 공식 보도자료](https://www.salesforce.com/news/press-releases/2026/08/26/salesforce-and-anthropic-announce-claudeforce/) · 2026-08-26
- 신뢰도: 높음 (기업 공동 보도자료, 1차 출처)
- 참고: 발표일이 7일 창(2026-08-27~09-03) 하루 밖입니다 — 구자료로 표시.
- 왜 중요한가: [[secbrain-site]]는 Claude Code를 파이프라인 실행기로 쓰는 구조라, Claude가 다른 플랫폼(Slack, Salesforce)에 기본 모델로 내장되는 방식은 향후 secbrain을 다른 서비스와 엮을 때 참고할 통합 패턴입니다.

## agents

### Genesys, Xperience 2026에서 에이전트 오케스트레이션 4종 발표
Genesys Xperience 2026 행사(2026-09-02) 발표를 다수 업계 매체가 보도. Navigator(고객 요청을 AI 에이전트·워크플로·사람 중 어디로 보낼지 판단), Orchestrator(여정 전체의 상태·정책·가드레일 유지), Contextual Intelligence(상호작용 신호를 고객 이력과 연결하는 "영속 기업 메모리"), AI Control Plane(에이전트 행동 범위·접근 권한·인간 개입 시점을 정의하는 거버넌스 계층) 4종입니다. Contextual Intelligence와 AI Control Plane은 현재 이용 가능, Navigator는 2026년 11월~2027년 1월, Orchestrator는 2027년 2월~4월 GA 예정입니다.

- 출처: [Genesys Unveils AI Control Plane and Agentic Orchestration Stack — CX Today](https://www.cxtoday.com/ai-automation-in-cx/genesys-ai-control-plane-xperience-2026/) · 2026-09-02
- 신뢰도: 중간 (복수 업계 매체가 기업 행사 발표를 인용, 1차 보도자료 링크는 확인 못함)
- 왜 중요한가: "에이전트 행동 범위·접근 권한을 정의하는 거버넌스 계층"이라는 프레임은 [[에이전트-권한-경계-체크리스트]]가 다루는 문제(에이전트에게 어디까지 권한을 줄지)와 같은 축입니다. 엔터프라이즈 벤더가 이 문제를 별도 제품 계층으로 분리하고 있다는 점이 참고가 됩니다.

## devtools

### Cursor, 셀프호스팅 머신 지원 — 코드·시크릿을 사내망에 유지
Cursor 공식 체인지로그(2026-09-02). "My Machines"(개인 노트북·VM 연결)와 "Team pools"(팀·엔터프라이즈용 동적 워커 큐) 두 가지로, 코드베이스·빌드 산출물·시크릿이 사내 머신을 벗어나지 않는 구조입니다. AWS Lambda, Coder, Cloudflare 같은 기존 인프라와 통합되며 Linux·Mac에서 컴퓨터 사용(클릭·타이핑·스크린샷)도 지원합니다.

- 출처: [Cursor Changelog](https://cursor.com/changelog) · 2026-09-02
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: [[secbrain-site]]는 GitHub Actions 러너에서 시크릿을 갖고 실행하는 구조라, "코드·시크릿을 사내 머신에 고정하고 에이전트만 접근시키는" Cursor의 셀프호스팅 모델은 이 파이프라인의 권한 경계를 설계할 때 비교 대상이 됩니다.

## pkm

### Obsidian 1.14.0 출시 — 데스크톱 칸반 레이아웃, iOS 잠금화면 빠른 캡처
Obsidian 공식 체인지로그(2026-09-02). 데스크톱은 하이라이트 색상 지정과 파일을 열 단위로 드래그 앤 드롭 정리하는 칸반 레이아웃, 전체 작업공간 RTL(우측 언어) 지원이 추가됐습니다. 모바일은 iOS 26 잠금화면·제어센터·단축어에서 vault 로딩 없이 바로 캡처하는 기능과 위치 기반 템플릿 변수(`{{latitude}}`, `{{longitude}}`)를 새로 지원합니다.

- 출처: [Obsidian Changelog](https://obsidian.md/changelog/) · 2026-09-02
- 신뢰도: 높음 (공식 체인지로그, 1차 출처)
- 왜 중요한가: secbrain은 Obsidian 문법(`[[wikilink]]`, 프론트매터)을 그대로 쓰는 vault입니다. 칸반 레이아웃은 [[secbrain-site]] 같은 프로젝트 노트의 태스크를 보드로 볼 때, 잠금화면 캡처는 `00-inbox` 캡처 습관을 앱 전환 없이 만들 때 바로 시험해볼 만합니다.
