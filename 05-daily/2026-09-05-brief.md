## 오늘 하나만 본다면

Anthropic이 2026-09-01 Claude Fable 5.1과 Mythos 5.1을 출시했습니다. 가격은 기존과 동일($10/$50 per Mtok)하되 캐시 읽기 비용을 75% 낮춰 에이전트형 작업 비용을 최대 45%까지 줄였고, 사이버보안 필터 개입은 세션당 약 60% 줄었습니다. 같은 날 Claude Code v2.1.257이 `claude-fable-5-1` 모델을 바로 추가했으니, [[secbrain-site]]가 워크플로에서 쓰는 `--model claude-sonnet-5` 지정도 조만간 이 라인업 변화를 반영할 근거가 됩니다.

## anthropic

### Claude Fable 5.1 / Mythos 5.1 출시 — 캐시 비용 75%↓, 사이버보안 개입 60%↓
Anthropic 공식 발표(2026-09-01). 동일 모델을 안전장치 수준으로 구분해, Fable 5.1은 일반 공개, Mythos 5.1은 사이버보안·생명과학 검증 프로그램 참여 조직에만 제공됩니다. 기본 토큰 가격은 Fable 5와 동일하지만 캐시 읽기 가격 인하로 실질 비용이 낮아졌고, Enterprise Frontier Safeguards(고객이 통제하는 클라우드에 오용 탐지 로그 저장)가 적용됩니다.

- 출처: [Introducing Claude Fable 5.1 and Claude Mythos 5.1 — Anthropic 공식](https://www.anthropic.com/claude-fable-and-mythos-5-1) · 2026-09-01
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: [[secbrain-site]]의 `.github/workflows/claude-ondemand.yml`이 `claude-code-action`으로 특정 모델을 지정해 매 스킬을 실행하는 구조라, 모델 라인업과 비용 구조 변화는 워크플로의 `--model` 인자를 재검토할 근거가 됩니다.

### Claude Code v2.1.257~261 — `/skill-doctor`, diff 패널, `managedMcpServers` 추가
Claude Code 공식 체인지로그(2026-09-01~09-04). v2.1.261에서 미사용 스킬을 점검하는 `/skill-doctor` 명령이 새로 생겼고, v2.1.260은 대화 옆에 뜨는 diff 패널을, v2.1.259는 MCP 서버를 관리자가 통제하는 `managedMcpServers` 설정을 추가했습니다.

- 출처: [Claude Code changelog — Claude Code 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-04
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: `/skill-doctor`는 정확히 [[secbrain-site]]의 `.claude/skills/` 아래 스킬(braindump, daily-brief, weekly-review, consolidate, ask)이 실제로 쓰이고 있는지 점검하는 데 바로 적용할 수 있는 도구입니다.

### Microsoft Agent Framework python-1.17.0 — OpenAI SDK 3.x 지원, Mistral 공식 SDK 이관
GitHub 공식 릴리스(2026-09-03). Foundry 호스팅 Telegram 에이전트 샘플이 추가됐고, OpenAI SDK 3.x 지원과 Mistral 공식 SDK로의 마이그레이션이 포함됐습니다. 승인(approval) 흐름, 히스토리 재생, 응답 보존 관련 버그도 다수 수정됐습니다.

- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: AutoGen·Semantic Kernel을 통합한 이 프레임워크가 계속 활발히 릴리스되는 중이라, 멀티 에이전트 오케스트레이션 설계를 참고할 때 [[에이전트-권한-경계-체크리스트]]에 비교 대상으로 남겨둘 만합니다.

## devtools

### GitHub CLI Linux 패키지 서명 키, 오늘(2026-09-05) 만료
GitHub 공식 체인지로그(2026-09-03). 공식 APT/RPM 저장소로 설치한 `gh` CLI의 현재 PGP 서명 키가 2026-09-05 만료되며, 이후 첫 릴리스부터 저장소 메타데이터와 신규 RPM 패키지는 대체 키로만 서명됩니다. Windows/macOS, 소스 빌드, Homebrew/Conda, GitHub Releases 직접 다운로드 사용자는 영향이 없습니다.

- 출처: [GitHub CLI Linux package signing key expires September 5 — GitHub 공식 체인지로그](https://github.blog/changelog/2026-09-03-github-cli-linux-package-signing-key-expires-september-5/) · 2026-09-03
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: `.github/workflows/claude-ondemand.yml`이 `ubuntu-latest` 러너에서 `gh issue comment`·`gh issue close`를 직접 호출합니다. GitHub 호스팅 러너 이미지는 GitHub가 직접 관리해 통상 자동 대응되지만, 워크플로가 `gh`에 의존한다는 사실 자체를 인지해 둘 필요가 있습니다.

## pkm

### Obsidian 1.14.0 — iOS Lock Screen Quick Capture, 데스크톱 색상 강조·칸반 레이아웃
Obsidian 공식 체인지로그(2026-09-02). 모바일 1.14.0은 iOS 26의 Lock Screen·Control Center·Shortcuts에서 vault 로딩을 기다리지 않고 바로 캡처하는 기능과 위치 기반 캡처(위도·경도 변수)를 추가했습니다. 같은 날 나온 데스크톱 1.14.0은 색상 강조, 칸반 레이아웃, 워크스페이스 RTL 지원을 더했습니다.

- 출처: [Obsidian Changelog — Obsidian 공식](https://obsidian.md/changelog/) · 2026-09-02
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: secbrain은 순수 마크다운 vault라 Obsidian으로도 열람할 수 있는 구조입니다. Lock Screen Quick Capture 같은 "마찰 없는 캡처"는 `00-inbox/`에 즉시 던져 넣는 기존 워크플로와 같은 방향의 기능입니다.
