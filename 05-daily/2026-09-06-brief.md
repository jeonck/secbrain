## agents

### GitHub Copilot — 장기 자율 코딩용 GPT-6 Astra 일반 출시
GitHub 공식 체인지로그(2026-09-04). "long-horizon, autonomous coding and agentic tasks"를 위해 설계된 GPT-6 Astra 모델이 Copilot에서 일반 공급을 시작했습니다. 같은 날 Gemini 3.8 Flash도 복잡한 터미널 기반 코딩 작업에서 강한 성능을 보였다고 언급됐고, 일부 기존 Copilot 모델은 10월 2일 중단 예정입니다.

- 출처: [GitHub Changelog — GitHub 공식](https://github.blog/changelog/) · 2026-09-04
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 장시간 자율 실행을 목표로 한 모델이 주류 코딩 에이전트에 GA로 들어온다는 것은, 사람이 매 실행을 검토하지 않는 파이프라인이 늘어난다는 뜻입니다. [[에이전트-권한-경계-체크리스트]]가 다루는 "예약/이슈 트리거 파이프라인" 시나리오와 정확히 겹칩니다.

### Anthropic Model Hardware Standard — 에이전트가 실험실·공장 하드웨어를 직접 제어 (구자료)
2026-08-27 공개(연구 프리뷰, 7일 기준보다 오래된 자료라 명시). AI 에이전트가 로봇팔·현미경·액체 핸들러 같은 물리 장비를 표준 드라이버 인터페이스로 발견·제어하도록 하는 사양. 장비의 무게·안전 한계·조작 가능 범위 같은 정보를 드라이버가 노출해, 기존에는 매뉴얼이나 전문가의 암묵지로만 존재하던 정보를 에이전트가 읽을 수 있게 합니다. Genentech·카네기멜런 등이 프리뷰에 참여했습니다.

- 출처: [Previewing the Model Hardware Standard — Anthropic 공식](https://www.anthropic.com/news/model-hardware-standard-research-preview) · 2026-08-27
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: 에이전트의 행동 범위가 소프트웨어 도구 호출을 넘어 물리 장비 제어로 확장되는 사례입니다. [[에이전트-권한-경계-체크리스트]]가 다루는 "도구·파일·명령 권한을 얼마나 줄지" 질문이, 이제 물리적 안전 한계까지 포함해야 한다는 근거가 됩니다.

## devtools

### VS Code 2026년 9월 — Agent Merge 프리뷰, Agent Host, 멀티루트 워크스페이스 에이전트 세션
GitHub 공식 블로그(2026-09-04, "GitHub Copilot expands model choice and content protections, while VS Code adds new ways to manage agent sessions"). Agent Merge(프리뷰)는 PR이 머지 가능해질 때까지 리뷰 피드백·실패한 체크·머지 충돌을 에이전트가 해결합니다. Agent Host는 Agent Host Protocol(AHP) 기반으로 여러 VS Code 창이 같은 에이전트 세션에 연결할 수 있게 하고, 멀티루트 워크스페이스에서도 Copilot·Claude 에이전트 세션을 폴더 전체에 걸쳐 다룰 수 있게 됐습니다.

- 출처: [GitHub Changelog — GitHub 공식](https://github.blog/changelog/) · 2026-09-04
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 여러 창·여러 폴더에 걸친 에이전트 세션 관리가 표준 기능이 되고 있다는 신호로, 이 vault를 로컬에서 VS Code로 편집·검토할 때 참고할 만한 워크플로 변화입니다.
