### Claude Fable 5.1 · Mythos 5.1 출시 — 캐시 읽기 75%↓, 안전장치 개선
2026-09-01 발표. 코딩·과학 연구·다학제 추론에서 Fable 5 대비 성능이 향상됐고, 일반 워크로드 기준 약 25% 비용 절감, 에이전트 작업은 캐싱 활용 시 최대 45% 절감이 가능합니다. 캐시 히트 가격이 기존 대비 75% 인하(표준 대비 0.025배)됐고, 사이버보안 관련 오탐(false positive)이 60% 줄었습니다. Mythos 5.1은 신뢰 접근 프로그램을 통해서만 제공됩니다.

- 출처: [Introducing Claude Fable 5.1 and Claude Mythos 5.1 — Anthropic 공식](https://www.anthropic.com/claude-fable-and-mythos-5-1) · 2026-09-01
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: 캐시 비용 구조가 크게 바뀌는 모델이 나온 시점으로, [[07-answers/2026-08-10-에이전트-비용-구조-정리와-빈틈]]에서 다룬 에이전트 비용 계산에 새 변수가 생겼습니다.

### GitHub Copilot CLI — Project HydraFusion(다중 모델 런타임 오케스트레이션) 리서치 프리뷰
2026-09-04 공식 발표. 작업마다 단일 모델·캐스케이드(효율 모델이 초안 → 품질 게이트가 상위 모델 승격 여부 판단)·비평(다른 모델군이 초안을 검토 후 1회 수정) 세 가지 실행 패턴 중 하나를 런타임에 선택해 여러 공급사 모델을 조합합니다. TerminalBench 2.1에서 Claude Opus 5 대비 비용 67% 절감, 품질 4.9%p 향상을 보였지만 DeepSWE 등 다른 벤치마크에서는 품질이 소폭 하락(-1.5%p)한 경우도 있었습니다. `/experimental`로 모든 Copilot 플랜에서 사용 가능합니다.

- 출처: [Project HydraFusion: Frontier quality via multi-model orchestration — GitHub 공식 블로그](https://github.blog/ai-and-ml/github-copilot/project-hydrafusion-frontier-quality-via-multi-model-orchestration/) · 2026-09-04
- 신뢰도: 높음 (1차 출처, 공식 블로그)
- 왜 중요한가: 단일 모델 호출이 아니라 "어떤 모델에 맡길지"를 런타임이 대신 결정하는 구조는 [[에이전트-권한-경계-체크리스트]]가 다루는 권한·행동 경계 질문에 "어떤 모델이 이 단계를 수행했는지 추적 가능한가"라는 항목을 추가할 근거가 됩니다.

### GitHub CLI Linux 패키지 서명 키 교체 — 9/5 만료, 조치 필요할 수 있음
2026-09-03 공지. GitHub CLI의 APT/RPM 저장소에 쓰이던 기존 PGP 서명 키가 2026-09-05 만료됐고, 이후 배포되는 패키지·저장소 메타데이터는 대체 키로만 서명됩니다. 2026-04-08 이전에 공식 안내대로 GitHub CLI를 설치하고 이후 저장소 설정·키링을 갱신하지 않은 Linux 사용자는 다음 `apt update`/`dnf update`가 서명 검증 실패로 막힐 수 있습니다.

- 출처: [GitHub CLI Linux package signing key expires September 5 — GitHub 공식 체인지로그](https://github.blog/changelog/2026-09-03-github-cli-linux-package-signing-key-expires-september-5/) · 2026-09-03
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 로컬에서 `gh` CLI로 이 저장소를 다루는 환경이라면, 2026-04-08 이전에 APT/RPM으로 설치했을 경우 키링 갱신이 필요한지 확인할 실익이 있습니다.
