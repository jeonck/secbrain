## 오늘 하나만 본다면

GitHub Actions가 `GITHUB_TOKEN`에 부여할 수 있는 새 `vulnerability-alerts` 권한(읽기 전용 Dependabot 알림 접근)을 추가했습니다. secbrain-site의 워크플로(`.github/workflows/claude-ondemand.yml`, `scheduled.yml`, `pages.yml`)가 실제로 `permissions`를 선언해 쓰는 구조라, 최소 권한 원칙을 다시 점검해볼 구체적인 계기입니다.

## devtools

### GitHub Actions — 2026년 9월 초 업데이트 3건
러너 버전 지원 종료 시점을 조회하는 REST API(`GET /actions/runners/deprecations/{version}`), `GITHUB_TOKEN`에 읽기 전용 Dependabot 알림 접근을 주는 `vulnerability-alerts` 권한, 재사용 워크플로가 자신의 출처를 런타임에 식별할 수 있는 `job.workflow_ref`/`workflow_sha`/`workflow_repository`/`workflow_file_path` 컨텍스트 속성이 추가됐습니다.

- 출처: [GitHub Actions: Early September 2026 updates — GitHub Changelog 공식](https://github.blog/changelog/2026-09-03-github-actions-early-september-2026-updates/) · 2026-09-03
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: [[secbrain-site]]는 GitHub Actions로 이슈 트리거·예약 실행·Pages 배포를 전부 돌립니다. `vulnerability-alerts`처럼 스코프가 좁은 권한이 생겼다는 건 [[에이전트-권한-경계-체크리스트]]가 다루는 "워크플로에 필요한 만큼만 권한을 준다"는 원칙을 실제로 적용해볼 대상이 하나 늘었다는 뜻입니다.

## agents

### GitHub Copilot 앱 — 병렬 에이전트 세션
GitHub Copilot 앱에서 여러 에이전트 세션을 동시에 띄우고 서로 간섭 없이 진행할 수 있는 기능을 냈습니다. 세션마다 독립된 Git worktree에서 돌아가 격리되며, 기능 구현·접근성 검토·테스트 실행처럼 서로 다른 작업을 병렬로 맡기고 세션 뷰에서 진행 상황을 모니터링하는 방식입니다.

- 출처: [GitHub Copilot App: Run Several Agents at Once — GitHub 공식 블로그](https://github.blog/ai-and-ml/github-copilot/github-copilot-app-for-beginners-run-several-agents-at-once/) · 2026-09-03
- 신뢰도: 높음 (1차 출처, 공식 블로그)
- 왜 중요한가: worktree 단위 격리로 병렬 세션을 돌리는 구조는, 어제 브리프에서 다룬 Anthropic의 "서브에이전트 대신 스킬을 얹은 단일 에이전트" 권고와 반대 방향의 선택입니다. 같은 문제(여러 작업 동시 처리)에 두 회사가 다른 답을 낸 셈이라, [[secbrain-site]]가 스킬 기반 단일 루프를 유지할지 판단할 때 비교 대상으로 남겨둘 만합니다.

## anthropic

### Claude Code 2.1.268 — 게이트웨이 요금제 지원, HTTP 400 회귀 수정 등 다수
2026-09-10 배포. Claude apps 게이트웨이를 통한 요금제(pricing) 지원과 조직 IPv4 대역을 위한 `gatewayInternalNetworks` 설정이 추가됐고, v2.1.265부터 발생하던 서드파티 Anthropic 호환 엔드포인트의 HTTP 400 오류, WebFetch가 무한 대기하던 문제(이제 300초 타임아웃, `CLAUDE_CODE_WEBFETCH_DEADLINE_MS`로 조정 가능), 플러그인/마켓플레이스 오류 메시지가 git 소스 URL의 토큰·비밀번호를 노출하던 문제 등을 수정했습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: WebFetch 무한 대기 수정은 이 브리프를 작성하는 `daily-brief` 스킬 자체가 WebFetch를 반복 호출하는 과정과 직접 맞닿아 있습니다. 플러그인 마켓플레이스의 시크릿 노출 수정도 [[에이전트-권한-경계-체크리스트]]가 다루는 자격 증명 노출 경계와 같은 종류의 문제입니다.

## pkm

### Obsidian 1.14.1 — 수학 렌더링 MathJax 4.1.3, Bases RTL 테이블 지원
2026-09-08 배포(Desktop·Mobile 동시). 데스크톱은 수식 렌더링을 MathJax 4.1.3으로 올리고 Bases에 오른쪽에서 왼쪽 언어 테이블 지원을 추가했으며, 모바일은 Quick Capture용 홈 화면 위젯을 추가했습니다.

- 출처: [Obsidian Changelog — 공식 문서](https://obsidian.md/changelog/) · 2026-09-08
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 vault는 Obsidian이 아니라 파일 기반 마크다운 + Git이라 직접 영향은 없지만, `[[wikilink]]` 문법과 프론트매터 관습을 Obsidian 생태계에서 그대로 가져왔으므로 상위 호환 여부는 계속 체크할 만합니다.
