## 오늘 하나만 본다면

Claude Code 2.1.269가 "세션이 오래 실행되면 read-only git 명령도 권한을 다시 묻는" 회귀를 만들었는데, 하루 만에 2.1.270으로 고쳤습니다. 이 vault의 예약 실행 자체가 Claude Code 세션이라 남 얘기가 아닙니다.

## anthropic

### Claude Code 2.1.270 — read-only git 권한 회귀 당일 수정
2.1.269(2026-09-11)에서 세션이 한동안 실행된 뒤 read-only git 명령(`git status` 등)이 예상 밖으로 권한 승인을 요구하던 회귀가 있었는데, 다음 날 2.1.270에서 수정됐습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-12
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 브리프를 포함한 secbrain의 모든 예약 실행이 Claude Code 세션이며, 스킬들이 `git status`류 read-only 명령을 반복 호출합니다. 회귀가 하루 넘게 남아 있었다면 예약 실행이 권한 프롬프트에서 멈췄을 상황이라, [[secbrain-site]]의 무인 실행 안정성과 직결됩니다.

## agents

### GitHub Copilot — VS Code에 반복 예약 에이전트 작업 (실험적)
VS Code 1.137에서 에이전트 작업을 시간·일·주 단위 또는 온디맨드로 반복 예약하는 기능이 실험 단계로 들어갔습니다. Agents 창에서 이슈·PR을 직접 검토하는 기능, 음성 모드와 함께 공개됐습니다.

- 출처: [GitHub Copilot weekly releases — September 7 — GitHub Changelog 공식](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: "반복 예약 에이전트 작업"은 secbrain이 GitHub Actions 크론으로 이미 하고 있는 것과 같은 문제를 에디터 안에서 풀려는 시도입니다. [[secbrain-site]]의 예약 실행 구조를 다른 벤더가 어떻게 접근하는지 비교할 대상으로 남겨둘 만합니다.

## devtools

### GitHub Copilot CLI — Project HydraFusion, 로컬·클라우드·복합 모델 자동 라우팅 (실험적)
작업마다 로컬·클라우드·복합(compound) 모델 사이에서 성능·비용·지연을 자동으로 저울질해 라우팅하는 실험 기능입니다. 수동 설정 없이 작업 단위로 모델을 고른다는 점이 핵심입니다.

- 출처: [GitHub Copilot weekly releases — September 7 — GitHub Changelog 공식](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: "로컬 모델도 후보에 넣고 자동으로 고른다"는 방향은 devtools 관심사가 짚는 로컬 우선(local-first) 흐름과 맞닿아 있습니다. 아직 실험 단계라 바로 쓸 건 아니지만, 비용·지연 저울질을 사람이 아니라 라우터가 하게 만드는 설계는 지켜볼 만합니다.
