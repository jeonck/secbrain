## 오늘 하나만 본다면

Cursor의 새 "Projects"는 코드를 직접 안 짜는 코디네이터 에이전트가 수천 개 서브에이전트에게 작업을 위임하고, 클라우드 컴퓨터에서 Slack 채널·PR 이벤트·스케줄 같은 시그널을 보고 프롬프트 없이 스스로 움직입니다. secbrain이 GitHub Actions 크론으로 하고 있는 것과 정확히 같은 문제(사람 없이, 시그널 기반으로, 위임된 에이전트가 실행)를 상용 에디터가 정면으로 풀기 시작했다는 신호입니다.

## agents

### Cursor Projects — 코디네이터가 서브에이전트에 위임, 클라우드 상시 실행
코디네이터 에이전트는 코드를 직접 작성하지 않고 계획·위임만 하며, 작업을 "수천 개 서브에이전트"에 병렬로 나눠 맡깁니다. Projects는 기본적으로 클라우드의 자체 컴퓨터에서 돌아가 노트북을 닫아도 멈추지 않고, 로컬 테스트가 필요하면 로컬 에이전트를 따로 띄웁니다. 구독 방식으로 Slack 채널 감시, 스케줄 실행, PR open/merge 시 CI 수정 같은 "시그널 기반 자율 동작"을 지원합니다.

- 출처: [Cursor — Introducing Projects (공식 블로그)](https://cursor.com/blog/projects) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 블로그)
- 왜 중요한가: [[secbrain-site]]가 이미 하고 있는 "이슈 생성 → Actions가 스킬 라우팅 → Claude Code 실행" 구조와 같은 축의 문제(사람이 매번 프롬프트하지 않아도 시그널로 에이전트가 움직인다)를 상용 제품이 어떻게 푸는지 비교할 대상입니다. "코디네이터는 코드를 안 짜고 위임만 한다"는 설계는 이 vault의 스킬들이 Agent/Workflow 도구로 하위 작업을 위임하는 패턴과도 맞닿습니다.

### Claude Managed Agents — 서버가 툴 호출을 직접 평가하는 `auto` 권한 정책
권한 정책에 `auto`가 추가되어, 서버가 에이전트나 MCP 툴 호출마다 실행·거부·승인 대기 중 하나로 직접 평가합니다. `ant beta:sessions connect`로 터미널을 세션에 붙여 실시간으로 지켜보고 대기 중인 툴 호출을 승인·거부할 수도 있습니다.

- 출처: [Claude Platform Release Notes — 공식 문서](https://platform.claude.com/docs/en/release-notes/overview) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: "누가 권한을 평가하느냐"(사람 vs 서버)는 [[secbrain-site]]의 무인 예약 실행이 안전하게 돌아가는지와 직결되는 축입니다. 어제 브리프가 다룬 read-only git 권한 회귀와 같은 문제군 — 권한 평가 로직이 어디서, 어떻게 도는지 — 를 다른 각도에서 보여주는 사례로 쌓아둘 만합니다.

## anthropic

### Claude Code 2.1.269 — Workflow 도구 동시 에이전트 상한 조절
`CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`(1~256) 환경변수가 추가되어, 추론 위주로 팬아웃하는 작업에서 Workflow 도구의 실행당 동시 에이전트 상한을 올릴 수 있습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-11
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: secbrain의 스킬들이 바로 이 Claude Code 세션 위에서 돌고, 위 Cursor Projects 항목과 같은 "여러 에이전트를 얼마나 동시에 띄우느냐"는 질문에 대한 Anthropic 쪽 답입니다. 기본 상한에 걸리는 대규모 브레인덤프·리뷰 작업이 있다면 참고할 손잡이입니다.

### Claude Code 2.1.269 — `claude plugin eval` 추가
플러그인의 eval 스위트를 Claude Code에 대해 돌려 점수화되고 재현 가능한 결과(JSON + HTML 리포트)를 받는 명령이 추가됐습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-11
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: `.claude/skills/` 아래 마크다운 지시문으로 이 브레인의 동작 전체가 정의되는 구조라, 스킬을 "eval로 검증한다"는 개념 자체는 나중에 daily-brief·braindump 같은 스킬의 회귀를 잡는 데 쓸 수 있는 도구입니다.
