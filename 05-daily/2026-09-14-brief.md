## 오늘 하나만 본다면

Claude Code 2.1.270이 2.1.269에서 생긴 회귀 — 세션이 오래 돌면 read-only git 명령도 매번 권한을 물었던 문제 — 를 고쳤습니다. secbrain의 예약 실행 스킬들은 정확히 이런 장시간 무인 세션에서 git 명령을 반복 호출하므로, 이번 수정은 숫자 이상의 의미가 있습니다. 같은 흐름에서 VS Code 1.137은 에이전트 작업을 시간 단위 스케줄로 예약 실행하는 "Automations"를 프리뷰로 냈는데, 어제 브리프가 다룬 Cursor Projects에 이어 상용 에디터들이 "사람 프롬프트 없이 시그널·스케줄로 에이전트를 돌린다"는 문제를 같은 시기에 정면으로 풀고 있다는 신호입니다.

## agents

### VS Code 1.137 — Automations, 에이전트 작업 스케줄 예약 실행 (프리뷰)
`chat.automations.enabled`를 켜면 Agents 창에서 반복 일정(시간·일·주 단위)이나 온디맨드로 에이전트 프롬프트를 실행할 수 있습니다. 변경사항 캐치업, 이슈 트리아지, 버그 찾기 같은 템플릿을 쓰거나 직접 프롬프트와 일정을 정의할 수 있고, 새로 도입된 Agent Host 아키텍처(개방 프로토콜 AHP)는 에이전트 세션을 워크스페이스에서 분리해 폴더를 닫거나 SSH로 원격에서도 세션이 유지되게 합니다.

- 출처: [Visual Studio Code 1.137 — 공식 릴리스 노트](https://code.visualstudio.com/updates/v1_137) · 2026-09-09
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: [[secbrain-site]]가 GitHub Actions 크론으로 하고 있는 "사람 없이, 스케줄로, 에이전트가 알아서 실행"과 같은 축의 문제를 VS Code가 정면으로 풀기 시작했습니다. Agent Host가 세션을 워크스페이스와 분리한다는 설계는 이 vault의 무인 실행이 세션 상태를 어떻게 다루는지 비교할 만한 지점입니다.

### GitHub Copilot CLI — HydraFusion, 태스크별 다중 모델 런타임 오케스트레이션 (리서치 프리뷰)
`/model`에서 HydraFusion을 선택하면 태스크마다 로컬·클라우드·복합 모델 사이에서 자동으로 라우팅해, 한 모델이 직접 푸는 방식과 저비용 모델이 초안을 만들고 필요할 때만 상위 모델로 에스컬레이션하는 방식 등 여러 실행 패턴 중 하나를 골라줍니다. 과금은 실제 쓰인 모델의 표준 요금대로 이뤄집니다.

- 출처: [GitHub Copilot weekly releases — September 7 (공식 블로그)](https://github.blog/changelog/2026-09-10-github-copilot-weekly-releases-september-7/) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 GitHub Blog)
- 왜 중요한가: 어제 브리프가 다룬 `CLAUDE_CODE_WORKFLOW_MAX_CONCURRENT_AGENTS`(여러 에이전트를 얼마나 동시에 띄우느냐)와 짝을 이루는 질문 — "태스크마다 어떤 모델/워크플로를 고르느냐" — 에 대한 GitHub 쪽 답입니다. 스킬마다 다른 무게의 작업(브레인덤프 vs 데일리 브리프)을 돌리는 secbrain 구조에도 참고할 패턴입니다.

2.1.269에서 생긴 회귀로 세션이 오래 실행되면 read-only git 명령도 매번 권한을 물었던 문제가 2.1.270에서 고쳐졌습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-12
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: secbrain의 예약 실행 스킬들이 바로 이런 장시간 무인 세션에서 `git status` 같은 read-only 명령을 반복 호출합니다. 어제 브리프가 "권한 평가 로직이 어디서 도는지"의 사례로 언급했던 문제군의 실제 수정판이자, 무인 실행 안정성에 직접 걸리는 변화입니다.
