## 오늘 하나만 본다면

Claude Code 2.1.273이 bypass 모드에서 permission checker가 완전히 분석할 수 없는 Bash 명령이 프롬프트를 건너뛰던 문제와, 서브셸이 위험한 `rm`을 숨기는 권한 우회를 고쳤습니다. secbrain의 예약 실행 스킬들은 사람이 매 명령을 확인하지 않는 구조라, 권한 검사기가 놓칠 수 있는 구멍이 곧바로 무인 실행 안전성에 걸립니다. [[에이전트-권한-경계-체크리스트]]가 다루는 "권한 검사기가 어디까지 분석하는가"의 실제 취약점 사례로 남겨둘 만합니다.

## anthropic

### Claude Code 2.1.273 — bypass 모드 rm 서브셸 권한 우회 수정
permission checker가 완전히 분석하지 못하는 Bash 명령이 `permissions.blockReadsOutsideWorkingDirectories` 아래에서 프롬프트를 건너뛰던 문제와, 서브셸이 bypass 모드에서 위험한 `rm`을 숨기는 문제를 수정했습니다. 같은 릴리스에 Remote 세션(클라우드·셀프호스트 러너)에 fast mode 지원도 추가됐습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-15
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: secbrain의 스킬들은 사람이 매 명령을 승인하지 않는 예약 실행 구조입니다. [[에이전트-권한-경계-체크리스트]]가 짚어야 할, 권한 검사기 우회가 실제로 발견되고 고쳐진 구체적 사례입니다.

### Messages API — compact-on-demand 베타
`compaction` 파라미터로 원하는 시점에 대화를 압축할 수 있는 기능이 `compact-2026-09-04` 베타 헤더로 나왔습니다. API가 서명된 압축 블록을 반환하면 이후 요청에서 원본 메시지 대신 그 블록을 보내면 되고, 최근 턴은 요약 없이 그대로 유지할 수 있습니다.

- 출처: [Claude Platform Release Notes — 공식 문서](https://platform.claude.com/docs/en/release-notes/api) · 2026-09-14
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 압축 시점을 개발자가 직접 고른다는 설계는 daily-brief·weekly-review처럼 매일 누적되는 예약 실행 세션이 컨텍스트를 어떻게 관리할지에 참고할 만한 손잡이입니다.

## devtools

### GitHub Copilot — auto 모델 선택에 비용/품질 티어 추가
efficiency·balance·intelligence 세 티어가 추가되어, 프롬프트마다 auto가 비용·품질·응답 속도를 어떻게 가중할지 고를 수 있습니다. 세 티어 모두 같은 모델 풀을 쓰고, 프롬프트별로 자동 평가해 모델을 고르는 방식은 그대로입니다. VS Code, Copilot CLI, GitHub Copilot 앱에 순차 적용 중입니다.

- 출처: [Configure cost and quality in Copilot auto model selection — GitHub Changelog 공식](https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection/) · 2026-09-14
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 어제 브리프가 다룬 GitHub Copilot CLI의 HydraFusion(태스크별 모델 라우팅)과 짝을 이루는 손잡이 — 이번엔 "어떤 모델을 쓸지"가 아니라 "비용과 품질 중 무엇을 우선할지"입니다. braindump처럼 가벼운 스킬과 weekly-review처럼 무거운 스킬이 섞인 secbrain 구조에 참고할 만한 축입니다.
