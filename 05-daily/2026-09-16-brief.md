## 오늘 하나만 본다면

AWS가 체크포인트·크론 스케줄·사람 승인 대기를 이메일 받은편지함 UI로 다루는 백그라운드 에이전트 도구 Pizza Bot을 오픈소스로 냈습니다. secbrain의 스킬들도 정확히 "사람 없이, 스케줄로 돌다가 특정 순간엔 사람 승인이 필요한" 구조라, [[에이전트-권한-경계-체크리스트]]가 다뤄야 할 참고 아키텍처입니다.

## agents

### AWS Pizza Bot — 백그라운드 에이전트를 위한 오픈소스 "받은편지함" (Apache 2.0)
LangChain의 DeepAgents(LangGraph 기반 장시간 에이전트 하네스) 위에 지은 도구로, 완료된 작업은 "읽지 않음" 큐에, 사람 판단이 필요한 작업은 "액션" 큐에 쌓입니다. 작업 상태는 SQLite와 파일로 디스크에 계속 체크포인트돼 앱이 꺼져도 재시작 없이 이어서 돌고, 특정 액션은 사람이 승인·수정할 때까지 멈춥니다. 크론 스케줄과 웹훅으로 작업을 시작할 수 있고 Anthropic·Bedrock·Gemini·OpenAI·OpenRouter·Ollama와 MCP 서버를 지원합니다. AWS 내부에서 30명 이상 기여자·2,000명 사용자를 거쳐 독립 커뮤니티 프로젝트로 공개됐습니다(AWS 공식 지원 없음).

- 출처: [Introducing Pizza Bot — AWS Open Source Blog](https://aws.amazon.com/blogs/opensource/introducing-pizza-bot-an-open-source-inbox-for-ai-agents-that-work-in-the-background/) · 2026-09-10
- 신뢰도: 높음 (1차 출처, 공식 AWS 블로그)
- 왜 중요한가: [[secbrain-site]]의 "이슈 생성 → Actions가 스킬 라우팅 → Claude Code 실행" 구조도 사람이 매번 지켜보지 않는 백그라운드 실행입니다. Pizza Bot의 "완료는 받은편지함, 승인 대기는 액션 큐"라는 구분은 지금 이 vault에 없는 손잡이 — 예약 실행 스킬이 늘어나면 결과 확인·승인 흐름을 어떻게 노출할지 참고할 설계입니다.

## anthropic

### Claude Code 2.1.273 — LLM 게이트웨이용 요청 헤더 추가
`CLAUDE_CODE_GATEWAY_HINT_HEADERS=1`로 켜면 `x-claude-code-request-class`, `x-claude-code-agent-type`, `x-claude-code-prev-tool-durations`, `x-claude-code-compaction`, `x-claude-code-context-compacted` 헤더가 요청에 실려, 게이트웨이가 요청 종류·에이전트 유형·컨텍스트 압축 여부를 보고 라우팅·캐싱 판단을 할 수 있습니다. 같은 릴리스에 MCP 서버 연결 끊김 알림·자동 재연결과 `--remote-control` 세션 포크 기능도 추가됐습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-15
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 헤더 자체는 게이트웨이를 직접 운영하지 않는 secbrain과는 거리가 있지만, "요청이 압축을 거쳤는지, 어떤 에이전트 유형인지"를 노출한다는 방향은 daily-brief·weekly-review처럼 누적 세션을 쓰는 스킬의 컨텍스트 상태를 나중에 관찰하고 싶을 때 참고할 만한 신호입니다.

## devtools

### Zed 1.20.1 — 마크다운 파일 열자마자 렌더링 미리보기, macOS/Linux 바이너리 25% 축소
`markdown_preview.open_markdown_files_in_preview` 설정을 켜면 `.md` 파일을 열 때 원문 대신 렌더링된 미리보기로 바로 엽니다. 디버그 심볼 스트리핑으로 macOS·Linux 바이너리 크기가 약 25% 줄었고, 대형 워크스페이스에서 "파일이 너무 많이 열려 있음" 오류를 줄이는 파일 디스크립터 상한 상향, Git 클론 진행률 표시 개선도 포함됐습니다.

- 출처: [Zed 1.20.1 — 공식 릴리스 노트](https://zed.dev/releases/stable) · 2026-09-16
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: secbrain은 마크다운 파일 뭉치 그 자체입니다. `.md`를 열 때 기본으로 렌더링 미리보기를 띄우는 설정은 Zed로 이 vault를 훑어볼 때 Obsidian 없이도 읽기 좋은 뷰를 얻는 손잡이입니다.
