## anthropic

### Claude Code 2.1.275 — 서브에이전트 텍스트 누락, 메모리발 캐시 미스 수정
`--forward-subagent-text`를 켰을 때 스트림-JSON과 SDK 출력에서 서브에이전트 메시지가 빠지던 문제를 고쳤고, 메모리 파일의 "마지막 수정" 노트가 압축(compaction)이나 재개 후 바뀌어 매 요청마다 프롬프트 캐시를 미스시키던 문제도 수정했습니다. 같은 릴리스에 클라우드 세션(루틴)이 더 이상 해결되지 않을 때 "새 루틴" 버튼을 보여주는 개선, claude.ai에서 서명한 스킬·플러그인을 터미널 세션과 동기화하는 기능(`syncClaudeAiSkills`)도 포함됐습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-17
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: [[secbrain-site]]의 스킬들이 Agent 도구로 서브에이전트를 위임하는 구조를 실제로 씁니다 — 서브에이전트 출력이 누락되면 예약 실행 로그에서 무슨 일이 있었는지 못 보게 됩니다. 메모리 캐시 미스 수정은 daily-brief·weekly-review처럼 매일 반복되는 예약 세션의 비용에 직접 걸립니다.

## agents

### 한컴 노마디안 — 3D 에이전트 워크포스 플랫폼, 되돌릴 수 없는 액션 전에 승인 게이트
한글과컴퓨터가 자체 "에이전트틱 OS" 위에 지은 노마디안을 공개했습니다. 사용자가 데이터 분석·콘텐츠 마케팅 같은 직무별 AI 에이전트를 골라 팀을 꾸리면, 상위 에이전트가 역할을 분배하고 결과를 취합하며, 이메일 발송처럼 되돌릴 수 없는 액션은 사람이 승인할 때까지 멈춥니다. 미국 1인 창업가를 겨냥했고 베타는 12월 공개 예정입니다.

- 출처: [Hancom to launch AI workforce platform targeting US solo entrepreneurs — The Korea Times](https://www.koreatimes.co.kr/business/tech-science/20260915/hancom-to-launch-ai-workforce-platform-targeting-us-solo-entrepreneurs) · 2026-09-15
- 신뢰도: 중간 (매체가 회사 발표를 인용, 1차 발표 원문 자체는 확인 못 함)
- 왜 중요한가: "상위 에이전트가 위임, 되돌릴 수 없는 액션 앞에서만 사람 승인"이라는 구분은 [[에이전트-권한-경계-체크리스트]]가 다루는 "예약 실행 중 어느 지점에서 사람 승인이 필요한가"와 정확히 같은 질문입니다. secbrain은 지금 모든 커밋을 무인으로 밀어붙이는데, 이 구분을 기준으로 어떤 액션을 "승인 대기"로 남길지 참고할 사례입니다.

## devtools

### VS Code 1.138 — Dev Container에서 에이전트 세션 실행, Codex harness 확장
설정을 켜면 에이전트를 프로젝트의 Dev Container 안에서, 그 프로젝트의 실제 도구·의존성을 갖춘 채로 돌릴 수 있습니다. Codex harness는 GitHub Copilot과 ChatGPT 구독 중 선택할 수 있게 넓어졌고, ChatGPT 앱과 VS Code 사이에서 같은 세션을 이어갈 수 있습니다.

- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 격리된 실행 환경에서 에이전트를 돌린다는 방향은 [[secbrain-site]]가 GitHub Actions 러너에서 스킬을 실행하는 구조와 같은 축입니다. 로컬에서 같은 걸 재현하고 싶을 때(Dev Container로 vault를 열고 스킬을 시험할 때) 참고할 손잡이입니다.
