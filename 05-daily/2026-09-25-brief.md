## 오늘 하나만 본다면

Claude Code v2.1.283(오늘 배포)에 `/doctor prompt-audit` 명령이 추가됐습니다. CLAUDE.md, 스킬, 에이전트, 커맨드 파일을 훑어 "더 오래된 모델을 대상으로 쓰인 패턴"을 찾아줍니다. secbrain은 정의상 `.claude/skills/`의 마크다운 지시문과 루트 `CLAUDE.md`가 동작 전부인 저장소라, 이 감사 도구가 정확히 이 vault의 파일들을 대상으로 합니다 — 실제로 돌려보고 지적사항이 나오는지 확인해볼 가치가 있습니다.

## anthropic

### Claude Code v2.1.283 — `/doctor prompt-audit`로 CLAUDE.md·스킬·에이전트·커맨드 감사
새 명령어 `/doctor prompt-audit`이 프로젝트의 CLAUDE.md, 스킬, 에이전트, 슬래시 커맨드를 스캔해 더 오래된 모델을 염두에 두고 쓰인 지시 패턴(예: 과도하게 명시적인 단계별 지시, 요즘 모델엔 불필요한 예시 반복 등)을 찾아냅니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-25
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 저장소의 `.claude/skills/*/SKILL.md`와 `CLAUDE.md`가 바로 이 감사의 대상입니다. `daily-brief`·`weekly-review`처럼 예약 실행되는 스킬 문서가 실제로 최신 모델 기준에 맞게 쓰였는지 점검할 도구가 생겼다는 뜻으로, [[secbrain-site]] 파이프라인 점검 항목에 추가할 만합니다.

### Claude Code v2.1.283 — SDK 세션의 지연된 tool call 유실, MCP stdio 서버 좀비 프로세스 수정
같은 릴리스에 SDK 세션이 지연된(deferred) tool call이나 완료된 tool 결과를 잃어버리던 버그, 세션 종료 후에도 MCP stdio 서버 프로세스가 계속 떠 있던 버그가 함께 고쳐졌습니다.

- 출처: [Claude Code Changelog — 공식 문서](https://code.claude.com/docs/en/changelog) · 2026-09-25
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: daily-brief·weekly-review 같은 예약 실행이 Agent SDK 세션 위에서 도는 구조라, tool call 유실 버그 수정은 이런 예약 파이프라인이 조용히 실패하던 원인 중 하나가 없어졌다는 뜻입니다.

## agents

### Dataiku Agent Management 출시 — 플랫폼 가로질러 에이전트 재고·위험 등급 관리
Dataiku가 AWS Bedrock, Databricks Agents, Google Vertex, Microsoft Copilot Studio/Azure Foundry, Salesforce Agentforce, Snowflake Cortex, Dataiku 자체를 가로질러 에이전트를 찾아내고, 각 에이전트의 도구·모델 구성과 인증 상태를 기록하며, 고객 응대·민감 데이터·실거래를 다루는 에이전트를 우선순위로 위험 등급을 매기는 독립 제품을 발표했습니다. 10월 정식 출시 예정입니다.

- 출처: [Dataiku Launches Agent Management — 공식 발표](https://www.dataiku.com/company/news/dataiku-agent-management-general-availability) · 2026-09-24
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: "AI 시스템 전체 재고를 유지하는 조직이 5곳 중 1곳도 안 된다"는 이 발표의 문제의식은 [[에이전트-권한-경계-체크리스트]]가 소규모(1인, 예약 실행 몇 개) 스케일에서 이미 짚은 "권한 경계를 사람이 매번 검토하지 않는다"는 문제의 엔터프라이즈 버전입니다.

## devtools

### Zed 1.21.0 — 에이전트 실행 중 시스템 절전 방지, Claude Opus 5.5 BYOK 지원
`agent.prevent_idle_sleep` 설정(기본 켜짐)이 추가돼 에이전트 스레드가 도는 동안 시스템이 절전 모드로 안 빠집니다. Anthropic API 키로 Claude Opus 5.5를, OpenAI 키로 GPT-6 Sol/Luna/Astra를 BYOK로 쓸 수 있게 됐습니다.

- 출처: [Zed Releases — 공식](https://zed.dev/releases/stable/latest) · 2026-09-23
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 장시간 도는 에이전트 스레드가 이제 "노트북이 잠들어서 끊기는" 문제까지 신경 쓰는 기본값이 됐다는 신호로, secbrain의 예약 실행은 GitHub Actions 러너에서 도니 직접 해당되진 않지만 로컬에서 스킬을 수동 실행할 때는 참고할 만합니다.

### Cursor Rollouts·Security Review — 배포 후 회귀 감시 봇, PR 보안 전담 리뷰 봇
Cursor가 두 봇을 동시에 출시했습니다. Rollouts는 배포된 변경을 환경별로 추적해 "정상/회귀/판단 불가"로 보고하고 필요시 되돌리기 PR을 엽니다. Security Review는 SQL 인젝션·인증 우회·자격증명 유출 같은 취약점만 전담으로 스캔하며, 스타일·품질 지적은 별도 봇(Bugbot) 몫으로 남겨둡니다. 둘 다 Teams·Enterprise 플랜 대상입니다.

- 출처: [Cursor Changelog — 공식](https://cursor.com/changelog) · 2026-09-23
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: "품질 리뷰와 보안 리뷰를 별도 봇으로 분리한다"는 설계는 이 vault가 `/code-review`와 `/security-review`를 별개 스킬로 두는 것과 같은 결의 구분입니다. 관심사를 분리해두면 각각을 독립적으로 예약·검증할 수 있다는 근거 사례로 참고할 만합니다.
