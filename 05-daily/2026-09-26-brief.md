## 오늘 하나만 본다면

Anthropic이 950개의 Claude 에이전트를 21시간·2억1천만 토큰 동원해 20만 개 이상의 역전사효소를 뒤진 끝에, CRISPR 시스템과 유사한 반복서열을 동반한 신규 효소 시스템(ART)을 찾아냈다고 발표했습니다. 구조는 단순합니다 — 에이전트 1개가 계획하고 실행하면 다른 1개가 검토하고, 그 결과에 따라 새 작업이 계속 열리는 방식입니다. 대량 병렬이 아니라 "계획-실행-검토"를 반복하는 조율 패턴이라는 점이 이 규모의 예약 실행 파이프라인에도 옮겨볼 만합니다.

### Anthropic, 950-에이전트 스웜으로 신규 효소 시스템(ART) 발견
Claude 에이전트 950개가 21시간 동안 20만 개 이상의 역전사효소(reverse transcriptase)를 조사해 약 3,500개 후보를 추려내고, 최종적으로 CRISPR 계열과 유사하게 배열된 비암호화 반복서열을 동반한 신규 시스템(ART)을 찾아냈습니다. 한 에이전트가 작업을 계획·실행하면 다른 에이전트가 검토하는 2단 구조였고, 실험실 검증과 후보 판별은 사람이 맡았습니다.

- 출처: [Claude discovers a novel enzyme system — Anthropic 공식](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) · 2026-09-23
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: "에이전트가 가설을 프롤리하게 쏟아내고, 그중 쓸 만한 걸 사람이 고른다"는 이 구조는 [[에이전트-권한-경계-체크리스트]]가 다루는 "사람이 매번 검토하지 않으면 위험하다"는 문제의 반대편 — 검토자를 에이전트 자체에 심어 사람의 개입 지점을 줄인 사례입니다. 소규모 파이프라인에서 플래너/리뷰어를 분리하는 설계에 참고할 만합니다.

### Alibaba, Apsara 컨퍼런스에서 AgentCore 발표 — 에이전트 전 생애주기 관리 플랫폼
Alibaba Cloud가 에이전트를 빌드·실행·관리하는 엔터프라이즈 플랫폼 AgentCore를 공개했습니다. 실시간 위협 탐지를 내세운 Agent Security Center, 장기 메모리를 제공하는 Agent Context가 함께 발표됐습니다.

- 출처: [Alibaba Unveils Roadmap on Full-Stack AI Strategy — Alizila(Alibaba 공식 미디어)](https://www.alizila.com/alibaba-unveils-agentic-computer-ai-wearables-and-more-at-2026-apsara-conference/) · 2026-09-22
- 신뢰도: 중간 (기업 공식 발표지만 컨퍼런스 마케팅 자료라 상세 스펙은 불확실)
- 왜 중요한가: 어제 브리프의 Dataiku Agent Management에 이어, "에이전트 인벤토리·권한·위험 등급을 누가 관리하나"라는 같은 문제의식이 다른 벤더에서도 반복됩니다. [[에이전트-권한-경계-체크리스트]]가 짚은 문제가 업계 전반의 화두라는 근거로 쌓아둘 만합니다.

### Claude Plugins 디렉터리 제출 포털 오픈
유료 플랜 사용자가 MCP 커넥터·Agent Skills를 묶은 플러그인을 Claude 디렉터리에 직접 제출하고, 심사 상태를 추적하고, 배포 후 설치 수·조회수 같은 사용량 분석을 볼 수 있는 포털(`claude.ai/directory/manage`)이 열렸습니다. 제출 즉시 안전성 스캔이 돌아갑니다.

- 출처: [Build plugins for Claude — Claude 공식 블로그](https://claude.com/blog/build-plugins-for-claude) · 2026-09-25
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: 이 vault의 `.claude/skills/`가 바로 이 "플러그인"의 구성요소(Agent Skills)입니다. 디렉터리 제출·심사·분석 체계가 생겼다는 건, 지금은 이 저장소 안에서만 도는 `daily-brief`·`ask` 같은 스킬을 외부에 배포할 경로가 공식적으로 열렸다는 뜻이라 [[secbrain-site]] 로드맵에 옵션으로 적어둘 만합니다.
