## anthropic

### Claude Sonnet 5.5 출시
Sonnet 5 대비 출력 속도 30%+ 향상, 토큰·툴 호출 감소로 작업당 비용 최대 30% 절감. API 가격 자체는 동일(입력 $2/출력 $10/캐시읽기 $0.20, 백만 토큰당)하게 유지됩니다. Terminal-Bench 4.0 70.6%(이전 10.3%), OSWorld 2.1 80.1%(이전 57.0%) 등 에이전틱 코딩·컴퓨터 사용 벤치마크에서 큰 폭으로 개선됐고, 보이지 않는 텍스트 워터마킹과 Anthropic 최상위 모델 수준의 사이버 안전장치가 Sonnet 라인에 처음 적용됐습니다.

- 출처: [Introducing Claude Sonnet 5.5 — Anthropic 공식](https://www.anthropic.com/claude-sonnet-5-5) · 2026-09-28
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: [[secbrain-site]]의 예약 실행 파이프라인(daily-brief, weekly-review 등)은 Claude 모델 위에서 돈다는 전제로 설계돼 있습니다. 가격 동일 + 속도/효율 개선은 같은 예산으로 더 잦은 예약 실행이나 더 긴 맥락 처리가 가능해진다는 뜻이라, 어제 브리프에서 다룬 Opus 5.5 가격 인하([[에이전트-권한-경계-체크리스트]] 관련 비용 논의)와 함께 이 vault의 운영 비용 구조를 다시 볼 근거가 됩니다.
