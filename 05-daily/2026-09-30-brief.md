## 오늘 하나만 본다면

Claude Code 2.1.284(2026-09-28)가 기본 모델을 Claude Sonnet 5.5로 전환했고, 커스텀 `ANTHROPIC_BASE_URL`을 쓰는 세션도 1M 컨텍스트 윈도우(Opus 4.7+, Sonnet 5+, Fable 대상)를 쓸 수 있게 됐습니다. 어제 브리프에서 다룬 Sonnet 5.5 출시가 이제 이 vault를 매일 예약 실행하는 CLI 자체의 기본값이 되었다는 뜻이라, daily-brief·weekly-review 같은 스킬이 실제로 어떤 모델·컨텍스트 한도 위에서 도는지가 오늘부터 바뀐 셈입니다.

## devtools

### Claude Code v2.1.284: 기본 모델 Sonnet 5.5 전환 + 1M 컨텍스트 확장
`claude-sonnet-5-5`가 Anthropic API의 새 기본 Sonnet 모델로 지정됐고(가격 동일: 입력 $2·출력 $10·캐시읽기 $0.20, 백만 토큰당), 커스텀 베이스 URL을 쓰는 세션도 1M 컨텍스트 윈도우를 활용하도록 확장됐습니다. 이틀 전 v2.1.283(9/25)에서는 `/autocompact 200k` 권장, `availableModelsMatch`·`deniedModels` 같은 모델 고정/차단 관리 설정이 먼저 추가됐습니다.

- 출처: [Claude Code Changelog — 공식](https://code.claude.com/docs/en/changelog) · 2026-09-28
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: [[secbrain-site]]의 예약 실행(daily-brief, weekly-review 등)은 Claude Code 위에서 돈다는 전제로 설계돼 있어, 기본 모델·컨텍스트 한도 변경은 이 vault의 실제 운영 방식에 직접 영향을 줍니다.

## agents

### Dataiku, 여러 플랫폼에 흩어진 AI 에이전트를 단일 인벤토리로 묶는 "Agent Management" 발표
Dataiku가 연례 컨퍼런스 Dataiku Succeed에서 AWS Bedrock·Google Vertex·Microsoft Copilot Studio 등 플랫폼을 가로질러 조직 내 모든 AI 에이전트를 자동 탐지·인벤토리화하고, 각 에이전트의 구조·툴·모델을 식별해 위험도를 모니터링하는 독립 제품을 공개했습니다. 정식 출시는 10월이며, 인스턴스당 연 단위 과금에 에이전트별 모니터링 종량 요금이 더해집니다.

- 출처: [Dataiku Launches Agent Management — 공식 보도자료](https://www.dataiku.com/company/news/dataiku-agent-management-general-availability) · 2026-09-24
- 신뢰도: 높음 (1차 출처, 회사 공식 발표)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]]가 다루는 "에이전트별 권한·소유권·위험 파악"이 이제 개별 조직의 내부 규칙이 아니라 벤더가 별도 제품 카테고리로 파는 영역이 되고 있다는 신호입니다.

## anthropic

### Claude, CRISPR 유사 반복 구조를 가진 신규 효소 시스템(ART) 발견
Anthropic의 생명과학 연구팀이 Claude를 활용해 "배열 연관 역전사효소(ART)"라는 이전에 알려지지 않은, CRISPR과 유사한 반복 DNA 패턴을 가진 효소 시스템을 발견했습니다. 약 950개 에이전트가 21시간에 걸쳐 2억 1천만 토큰을 소모하며 대규모 DNA 데이터베이스를 자율 탐색한 결과이며, CRISPR 공동개발자 Feng Zhang도 이 발견을 긍정적으로 평가했습니다.

- 출처: [Claude discovers a novel enzyme system with CRISPR-like repeats — Anthropic 공식](https://www.anthropic.com/news/claude-discovers-novel-enzyme-system) · 2026-09-23
- 신뢰도: 높음 (1차 출처, 공식 발표)
- 왜 중요한가: 이 vault와 직접 연결된 노트는 없지만, 수백 개 에이전트가 초기 지시만으로 21시간 자율 실행된 규모는 [[에이전트-권한-경계-체크리스트]]가 상정하는 "대규모 자율 에이전트 실행" 시나리오의 실제 사례로 참고할 만합니다.
