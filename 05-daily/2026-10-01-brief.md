## 오늘 하나만 본다면

OpenAI가 DevDay 2026(9/29)에서 "dots"를 발표했습니다 — 각자 전용 클라우드 컴퓨터와 브라우저를 갖고 사용자 개입 없이 백그라운드에서 목표를 향해 계속 작업하는 상시 에이전트입니다. 비활성 시에도 연결된 앱을 읽기 전용으로 둘러보며 "사전 조사"를 하고, 계정·비밀번호 변경 같은 민감 작업은 항상 사용자 승인을 거칩니다. 이 vault의 daily-brief·weekly-review가 Claude Code 예약 실행으로 이미 구현하고 있는 "사람 없이 도는 에이전트" 패턴을, 소비자 제품 차원에서 공식화한 사례라 권한 경계 설계를 다시 볼 만합니다.

## agents

### OpenAI, 상시 백그라운드 에이전트 "dots" 공개
GPT-6 Astra 기반으로 작동하며 4,000개 이상의 앱에 연동해 여러 프로젝트를 동시에 처리합니다. 사용자가 지시하지 않아도 계속 목표를 향해 일하고, ChatGPT·Slack·Teams에서 호출할 수 있습니다. Pro·Business Premium 사용자부터 순차 공개되며 EEA·스위스·영국 Pro 사용자는 당장 제외됩니다.

- 출처: [TechCrunch — OpenAI launches Dots, its bubbly agentic avatar](https://techcrunch.com/2026/09/29/openai-launches-dots-its-bubbly-agentic-avatar/) · 2026-09-29
- 신뢰도: 중간 (신뢰할 만한 매체가 DevDay 발표를 직접 보도, OpenAI 공식 블로그 글 자체는 접근 확인 못함)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]]가 다루는 "승인 없이 도는 에이전트의 권한 범위" 문제가, 이제 "민감 작업만 승인 필요"라는 OpenAI의 설계 선택으로 소비자 제품에 그대로 들어왔습니다. 이 vault의 예약 스킬 권한 설계와 비교해볼 지점입니다.

## devtools

### Claude Code 2.1.285~286: `claude --desktop`, 플러그인 관리 명령 추가
2.1.285(9/29)는 `claude --desktop` 명령, `claude plugin configure`, SSH 환경에서의 플러그인·마켓플레이스 설치 수정, `allowedProviders` 관리 설정을 추가했습니다. 다음 날 2.1.286(9/30)은 권한 프롬프트에 "5개 중 2개" 식 진행 표시와 풀스크린 모드 마우스 내비게이션을 추가하고, 병렬 툴 호출 후 `--resume`/`--continue`가 턴을 잃는 버그를 고쳤습니다.

- 출처: [Claude Code Changelog — 공식](https://code.claude.com/docs/en/changelog) · 2026-09-30
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 vault의 모든 예약 실행(daily-brief, weekly-review 등)이 Claude Code 위에서 돌아가므로, `--resume` 턴 손실 수정은 긴 세션을 쓰는 [[secbrain-site]]의 스킬 안정성에 직접 영향을 줍니다.

## anthropic

### Claude for Government Desktop, 정식 출시(GA)
7월 공개 베타로 시작한 Claude for Government Desktop이 베타·프리뷰 단계를 벗어나 정식 출시됐습니다. Palantir의 FedRAMP High 경계 안에서 상업용과 동일한 Claude·Claude Code·Claude Cowork를 제공하며, 부서별 지출 관리와 변조 방지 감사 로그 같은 거버넌스 기능이 포함됩니다.

- 출처: [Claude for Government — 공식 제품 페이지](https://claude.com/solutions/government) · 공식 페이지(정확한 발표일 미기재, 타 매체는 2026-09-30로 보도)
- 신뢰도: 높음 (1차 출처, 공식 제품 페이지에서 "정식 출시" 직접 확인)
- 왜 중요한가: 이 vault와 직접 연결된 노트는 없지만, 상업용 Claude Code와 동일한 코드베이스가 고규제 환경에 그대로 들어간다는 점은 [[에이전트-권한-경계-체크리스트]]가 전제하는 "감사 로그·권한 경계"가 실제 규제 요건으로 굳어지는 방향을 보여줍니다.

## pkm

### Obsidian 1.14.3: macOS Quick Look 미리보기, Bases 그룹 메뉴 추가
데스크톱판에 macOS Quick Look으로 마크다운 파일을 미리 보는 기능과, Bases 툴바에서 속성별로 그룹을 만들고 순서·숨김을 조정하는 메뉴가 추가됐습니다. 모바일판은 Quick Capture가 데일리 노트나 특정 노트를 템플릿과 함께 열 수 있게 됐습니다.

- 출처: [Obsidian 1.14.3 Desktop changelog — 공식](https://obsidian.md/changelog/2026-09-29-desktop-v1.14.3/) · 2026-09-29
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: [[secbrain-site]]와 직접 연결되진 않지만, 이 vault와 같은 "마크다운 폴더 + 프론트매터" 구조를 쓰는 대표 도구의 기본 캡처(Quick Capture)·탐색(Bases 그룹) 기능이 계속 강화되는 흐름입니다.
