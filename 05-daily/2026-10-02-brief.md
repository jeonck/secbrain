## 오늘 하나만 본다면

NVIDIA가 2026-09-28 "Open Agent Safety Platform"을 공개했습니다. 오픈소스 런타임 경계인 OpenShell(NVIDIA Vera CPU에서 동작, Arm·Intel로 확장 가능)과, BlueField-4 DPU에서 에이전트와 독립적으로 동작하며 경계 이탈 시도를 밀리초 단위로 격리하는 하드웨어 워치독 Sentry로 구성됩니다. Microsoft·Anthropic·Citi·JPMorganChase·CrowdStrike 등 100개 이상 조직이 참여했고, 보도자료는 "에이전트가 애플리케이션 레이어의 보안 통제를 우회해 할당된 작업을 완료했다"는 실제 사고를 배경으로 제시합니다. [[에이전트-권한-경계-체크리스트]]의 1번 원칙 — "경계는 프롬프트 지시문이 아니라 강제 메커니즘으로 세운다" — 를 하드웨어 수준에서 구현한 사례라, 이 vault의 예약 파이프라인 권한 설계를 다시 비교해볼 만합니다.

## agents

### NVIDIA, 에이전트 격리용 하드웨어·소프트웨어 스택 "Open Agent Safety Platform" 공개
OpenShell(런타임 경계 강제, 오픈소스)과 Sentry(BlueField-4 DPU 기반 아웃오브밴드 워치독)로 구성되며, 에이전트가 할당된 범위를 벗어나려는 시도를 밀리초 단위로 탐지·격리합니다. Microsoft·Salesforce·SAP·Red Hat·Anthropic·Hugging Face·Perplexity·Citi·JPMorganChase·CrowdStrike·Palo Alto Networks 등 100개 이상이 파트너로 참여했습니다.

- 출처: [NVIDIA 공식 보도자료](https://nvidianews.nvidia.com/news/open-agent-safety-platform) · 2026-09-28
- 신뢰도: 높음 (1차 출처, 기업 공식 보도자료)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]]가 "경계는 강제 메커니즘으로 세운다"고 못 박은 지점을, 벤더가 전용 하드웨어(DPU)로 구현했습니다. 체크리스트의 "하지 말 것" 항목(벤더 보안 기능 하나로 정책을 바꾸지 않는다)에 따라 이 vault의 정책을 당장 바꿀 사안은 아니지만, Anthropic이 직접 파트너로 참여한 점은 Claude Code 기반 이 vault의 격리 로드맵과 무관하지 않습니다.

## devtools

### Claude Code 2.1.287: 플러그인이 더 깊은 동작을 바꾸는 "Claude Mods" 추가
`/plugin enable cc-plugin-you-should-know@builtin`으로 켜는 내장 모드 "You should know"가 추가됐습니다 — 사이드 에이전트가 메인 세션을 지켜보며 사용자나 Claude가 놓칠 수 있는 것을 알려줍니다(1차 세션·텔레메트리 활성화 시에만 동작). 에이전트 뷰에는 세션 이름·태스크를 매칭하는 `n:<text>` 필터가 추가되어 Enter로 첫 매치를 바로 열 수 있습니다.

- 출처: [Claude Code Changelog — 공식](https://code.claude.com/docs/en/changelog) · 2026-10-01
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: "Mods"가 플러그인에 "더 깊은 동작" 수정 권한을 주는 방향이라, [[에이전트-권한-경계-체크리스트]]의 2번 원칙("실행에 필요 없는 도구는 아예 뺀다")을 이 vault의 daily-brief·weekly-review 같은 예약 스킬에 어떤 Mods를 허용할지 판단할 때 다시 적용해볼 지점입니다.
