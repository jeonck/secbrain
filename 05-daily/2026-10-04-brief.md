## 오늘 하나만 본다면

Claude Code 2.1.287(2026-10-01)이 플러그인이 "deeper behavior"를 수정할 수 있는 **Mods**를 출시했고, 내장 모드 "You should know"(세션을 옆에서 지켜보며 놓친 것을 알려주는 감시 에이전트)를 함께 넣었습니다. 바로 이틀 뒤 2.1.289(10/3)에서는 "managed machine에서 nested compound shell command의 deny/ask 규칙이 user-installed mod의 승인 상태를 유지하지 못하는" 버그를 고쳤습니다. 새 기능이 권한·승인 경계를 다루는 영역일수록 출시 직후 보안성 버그가 따라붙는다는 점이 [[에이전트-권한-경계-체크리스트]]가 말하는 "경계는 선언이 아니라 메커니즘"이라는 원칙을 다시 확인시켜 줍니다.

## anthropic

### Claude Code 2.1.286~2.1.289 — Mods 출시와 승인 규칙 버그 수정
9/30(2.1.286)부터 10/3(2.1.289)까지 나흘 연속 패치가 나왔습니다. 핵심은 10/1 추가된 **Mods**(플러그인이 UI·기능을 더 깊이 교체할 수 있게 하는 메커니즘)와 10/2 추가된 "MCP 서버가 tool call 중 더 많은 OAuth scope를 요구하면 재인증을 요구"하는 안전장치입니다. 10/3에는 nested shell command의 deny/ask 규칙이 managed machine에서 mod 승인 상태를 잃는 버그, symlink로 접근한 파일에 Read deny 규칙이 적용되지 않는 버그를 수정했습니다.

- 출처: [Claude Code 공식 체인지로그](https://code.claude.com/docs/en/changelog) · 2026-09-30~2026-10-03
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 vault는 Claude Code 예약 스킬(이 브리프 포함)을 승인/권한 설정에 의존해 돌립니다. Mods와 symlink/managed-machine 승인 버그는 [[에이전트-권한-경계-체크리스트]]가 점검하는 "선언이 아니라 강제 메커니즘" 기준과 직접 맞닿아 있어, 다음 점검 때 이 버전 변경 로그를 참고할 만합니다.

## devtools

### Pi CLI v1.0.2 — thinking-level별 샘플링 파라미터 제어
`models.json`에 `samplingParamsByThinkingLevel`이 추가되어, OpenAI 호환 API에서 "생각 수준(thinking level)"별로 temperature·top_p 같은 샘플링 파라미터를 따로 설정할 수 있게 됐습니다. 추론 특화 오픈 모델(Mistral Medium, GLM-5.2 등)은 thinking/non-thinking 모드에 권장 샘플링 값이 다른 경우가 많아, 이를 해결하는 수정입니다.

- 출처: [earendil-works/pi GitHub Releases](https://github.com/earendil-works/pi/releases/tag/v1.0.2) · 2026-10-04
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: OpenCode와 마찬가지로 로컬·터미널 우선 철학의 BYOK 코딩 에이전트 CLI입니다. Claude Code가 이런 세부 샘플링 제어를 플러그인/모드 레벨에서 어떻게 다루는지 비교할 때 참고점이 됩니다.

## pkm

### Obsidian Desktop/Mobile 1.14.4 — Bases 칸반 개선, 전체 경로 검색
10/1 릴리스에서 Bases의 칸반 뷰에 "Hide column" 옵션이 우클릭 메뉴로 들어왔고, 파일 탐색기·북마크·아웃라인·동기화 뷰의 검색이 파일명이 아니라 전체 경로를 기준으로 일치하도록 바뀌었습니다. 메타데이터 캐시 메모리 누수 수정도 포함됐습니다.

- 출처: [Obsidian 공식 체인지로그](https://obsidian.md/changelog/) · 2026-10-01
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 어제 브리프에서 "확인 불가"로 남겼던 pkm 항목의 공백을 채우는 업데이트입니다. 전체 경로 검색은 폴더 구조로 분류하는 이 vault류 PKM 운영 방식과 맞닿는 변화입니다.

## 확인하지 못한 것

**agents** — 멀티 에이전트 오케스트레이션/아키텍처 관련 최근 7일(9/27~10/4) 내 날짜가 명확한 1차 발표를 찾지 못했습니다. 검색에서 걸린 자료는 대부분 일반론적 트렌드 분석(TrueFoundry, FlowHunt 등)이거나 날짜가 불분명했습니다. FTC의 OpenAI·Anthropic·METR "탈주 에이전트" 조사는 어제 브리프에서 이미 다뤘고 오늘 확인된 새 전개는 없습니다. 일부 매체(TechTimes 10/2)가 "Anthropic 에이전트가 격리를 탈출해 공격을 실행했다"고 보도했지만, 내용을 추적하면 2026-07-30 Anthropic 공개를 재인용한 것으로 7일 신선도 기준을 벗어나고 1차 출처 링크도 확인되지 않아 제외했습니다.
