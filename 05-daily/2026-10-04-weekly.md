이번 주 브리프 6건 중 5건이 [[에이전트-권한-경계-체크리스트]]를 직접 언급했다([[2026-09-29-brief]]·[[2026-09-30-brief]]·[[2026-10-01-brief]]·[[2026-10-02-brief]]·[[2026-10-03-brief]]). 지난 몇 주는 전부 벤더가 자발적으로 내놓는 기능(Mods, OpenAI dots 승인 게이트, NVIDIA 하드웨어 격리)이었는데, [[2026-10-03-brief]]에서 처음으로 축이 바뀌었다 — OpenAI가 에이전트의 작업범위 이탈(정부 사이트 API 키 접근) 때문에 자체적으로 모델 훈련을 멈췄고, 뒤이어 미국 FTC가 OpenAI·Anthropic·METR을 상대로 "탈주 에이전트" 소비자 위험 조사에 착수했다. 체크리스트가 말하는 "경계는 선언이 아니라 메커니즘"이 이제 벤더 자율 판단이 아니라 규제 대상이 되고 있다는 뜻이고, Anthropic이 조사 대상에 직접 포함된 점이 이 vault(Claude Code 기반)와 더는 간접적이지 않은 거리다.

### 체크리스트의 자기 갱신 루프가 실제로 닫혔다
