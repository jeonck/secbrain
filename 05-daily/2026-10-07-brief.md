## 오늘 하나만 본다면

Claude Code 2.1.287(2026-10-01)에서 "Claude Mods"가 정식 출시됐습니다. 기존 플러그인은 도구를 추가하는 수준이었지만, mod는 JS/TS 함수로 내부 이벤트(툴 호출, 프롬프트 전송, 인터페이스 렌더링)마다 호출되어 동작을 관찰·재작성·완전 대체할 수 있습니다. 이어진 2.1.288~2.1.292에서 마켓플레이스 설치 플래그, `tool.check` 훅의 `agentId`/`ceiling`, Agent tool의 `effort` 파라미터가 빠르게 뒤따라 붙었습니다. [[에이전트-권한-경계-체크리스트]]가 "권한 경계는 선언이 아니라 메커니즘"이라고 짚었던 지점이, mod가 동작 자체를 가로챌 수 있게 되면서 한 단계 더 복잡해졌습니다 — 이제는 "무엇을 승인했는가"뿐 아니라 "어떤 mod가 그 승인 로직 자체를 재정의할 수 있는가"도 체크리스트 항목이 됩니다.

## anthropic

### Claude Code 2.1.287 — Claude Mods 정식 출시
플러그인이 Claude Code 내부에서 실행되며 툴 호출·프롬프트·인터페이스 렌더링 같은 내부 이벤트마다 호출되는 JS/TS 함수(mod)를 등록해, 기본 동작을 관찰·재작성·완전 대체할 수 있게 됐습니다. 동시에 "You should know"라는 내장 mod가 추가되어 `/plugin enable cc-plugin-you-should-know@builtin`으로 활성화하면 보조 에이전트가 사용자나 Claude가 놓칠 수 있는 것을 감시합니다.
- 출처: [Claude Code 공식 체인지로그](https://code.claude.com/docs/en/changelog) · 2026-10-01
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 플러그인이 "도구 추가"를 넘어 "동작 재정의"까지 가능해진 변화로, [[에이전트-권한-경계-체크리스트]]가 다루는 권한 모델을 다시 점검할 이유입니다. 서드파티 mod 예시로 `rm -rf` 같은 파괴적 명령을 가로채 재확인을 요구하는 것도 있어, 체크리스트에 "mod가 가로챌 수 있는 승인 경로" 항목을 추가할 만합니다.

### Claude Code 2.1.288~2.1.292 — 마켓플레이스 설치·훅 세분화·effort 파라미터
10/2~10/6 사흘 동안 `claude plugin install --marketplace <source>`(마켓플레이스 자동 추가 후 설치), mod `tool.check` 훅의 `agentId`(서브에이전트 구분)·`ceiling`(조직 요구 승인 명시), Agent tool의 `effort` 파라미터(서브에이전트 실행 강도 지정), mod `$.model.complete`의 프롬프트 캐싱이 연달아 추가됐습니다.
- 출처: [Claude Code 공식 체인지로그](https://code.claude.com/docs/en/changelog) · 2026-10-02~2026-10-06
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: `agentId`/`ceiling`은 mod가 "어떤 에이전트의 어떤 행동까지 승인할 수 있는가"를 세분화하는 메커니즘이라, Claude Mods 출시와 묶어서 [[에이전트-권한-경계-체크리스트]] 다음 점검에 함께 반영할 항목입니다.

## devtools

### GitHub Copilot CLI v1.0.92 — config 서브커맨드, 로컬/클라우드 전환 피커
`copilot config` 서브커맨드(list/read/set/remove)와 Ctrl+E 환경 피커(로컬↔클라우드 실행 전환)가 추가됐습니다. 샌드박스 셸은 명시적으로 설정하지 않으면 ambient `GITHUB_TOKEN`을 보류하도록 바뀌었고, 셸 도구 호출의 stdout/stderr가 타임라인에 실시간 스트리밍됩니다.
- 출처: [github/copilot-cli Release v1.0.92](https://github.com/github/copilot-cli/releases/tag/v1.0.92) · 2026-10-05
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 샌드박스 셸의 ambient 토큰 보류는 Claude Code의 권한 모델과 비교할 설계이며, [[에이전트-권한-경계-체크리스트]]가 점검하는 "에이전트가 기본으로 어떤 자격증명에 접근하는가" 기준에 직접 참고가 됩니다.

## 확인하지 못한 것

**agents** — 멀티 에이전트 오케스트레이션/아키텍처의 최근 7일(9/30~10/7) 내 날짜가 명확한 1차 발표를 찾지 못했습니다. LangGraph Deep Agents, Microsoft Agent Framework, CrewAI 관련 검색 결과는 모두 2026년 1~4월 소식의 재정리성 글이었습니다. Claude Code의 Agent tool `effort` 파라미터는 날짜가 확실한 1차 자료지만 agents 주제보다는 anthropic 릴리스 세부사항이라 그쪽에 넣었습니다.

**pkm** — Obsidian 1.14 정식 공개(10/5)가 가장 가까운 소식이지만 [[2026-10-06-brief]]에서 이미 다뤘습니다. 그 외 Logseq·Tana·Capacities·Readwise·Craft 검색에서는 날짜가 명확한 신규 발표를 찾지 못했고, 비교·리뷰성 글만 나왔습니다.
