## 오늘 하나만 본다면

Claude Code v2.1.293(2026-10-07)에서 Claude Haiku 5.5(`claude-haiku-5-5`)가 Anthropic API의 기본 Haiku 모델로 추가됐습니다. 컨텍스트 1M, 가격 $0.10/$0.50 per Mtok(100K 초과 프롬프트는 $0.50/$2.50)입니다. [[에이전트-비용-구조-정리와-빈틈]]은 "리드(비싼 모델)=판단, 워커(싼 모델)=I/O" 패턴이 vault 안에서 신뢰도 높게 확립돼 있지만 그 패턴을 뒷받침할 실측 비용 데이터가 전혀 없다고 짚었습니다. 이번 Haiku 5.5의 1차 출처 가격표는 그 공백에 처음으로 "워커 모델" 쪽 구체적인 숫자를 제공합니다 — 다만 이걸로 비용 절감 수치를 계산해 넣는 건 아직 별개 작업입니다.

## anthropic

### Claude Code v2.1.293 — Claude Haiku 5.5 추가, 서브에이전트 관련 버그 다수 수정
Claude Haiku 5.5가 Anthropic API 기본 Haiku 모델로 추가됐습니다(컨텍스트 1M, $0.10/$0.50 per Mtok). 같은 릴리스에서 `subagentStatusLine` 페이로드에 `agentType`이 추가됐고, 서브에이전트에게 메시지를 보내라고 잘못 안내하던 문제·서브에이전트에 내장 도구가 세션 전체에서 비활성화된 것처럼 안내되던 문제·`worker`라는 이름의 커스텀 에이전트가 "Agent"로 잘못 표시되던 문제가 수정됐습니다.
- 출처: [Claude Code 공식 체인지로그](https://code.claude.com/docs/en/changelog) · 2026-10-07
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: Haiku 5.5 가격은 [[에이전트-비용-구조-정리와-빈틈]]의 "리드/워커 2단 라우팅" 빈 자리를 채울 후보 숫자입니다. 서브에이전트 표시 버그 수정들은 멀티 에이전트 구성을 쓸 때 상태 추적 신뢰도에 직접 영향을 줍니다.

## devtools

### GitHub Copilot CLI v1.0.94 프리릴리스 — Assisted Permissions를 관리형 정책으로 끄고 Manual Approval 강제
관리형 설정(managed settings)으로 Assisted Permissions를 끄고 세션을 Manual Approval 모드로 고정할 수 있게 됐습니다. 또한 관리형 정책이 더 새로운 CLI 버전을 요구할 때 업데이트 안내를 띄우되 일반 프롬프트는 막지 않도록 바뀌었습니다.
- 출처: [github/copilot-cli Releases](https://github.com/github/copilot-cli/releases) (v1.0.94-0, 1.0.94-1) · 2026-10-07
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트) — 단, 정식 릴리스가 아닌 프리릴리스 태그임을 밝힙니다.
- 왜 중요한가: 조직 정책으로 "자동 승인을 끄고 수동 승인만 허용"을 강제하는 설계는 [[에이전트-권한-경계-체크리스트]] 6번("되돌릴 수 없거나 민감한 액션은 실행 전에 사람 승인을 거치게 한다")과 같은 방향의 게이트입니다. 벤더별 구현 비교 자료로 체크리스트 다음 보강 때 참고할 만합니다.

## pkm

### Obsidian v1.14.4 — Bases 칸반 뷰, 볼트 밖 마크다운 파일 열기
데스크톱 v1.14.4에서 볼트 밖의 마크다운 파일을 열어 macOS Quick Look으로 미리 볼 수 있게 됐고, Bases에 칸반 뷰와 하이라이트 색상 6종이 추가됐습니다. 같은 날 모바일 v1.14.4는 iOS 26 잠금 화면·제어 센터·위젯·단축어에서 볼트 로딩 없이 바로 캡처하는 기능을 추가했습니다.
- 출처: [Obsidian 공식 체인지로그](https://obsidian.md/changelog) · 2026-10-05
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: "볼트 밖 마크다운 파일 열기"는 이 vault처럼 Git으로 버전 관리되는 마크다운 저장소를 Obsidian으로 들여다볼 때 폴더 구조를 그대로 유지하면서 개별 파일만 빠르게 확인할 수 있다는 의미라, 이 저장소를 Obsidian으로 열어보는 워크플로우가 있다면 실익이 있습니다.

## 확인하지 못한 것

**agents** — 멀티 에이전트 오케스트레이션/아키텍처의 최근 7일(10/1~10/8) 내 날짜가 명확한 1차 발표를 찾지 못했습니다. LangGraph는 2026-08-19(SDK)·2026-07-10(CLI)이 최신으로 보이고, AutoGen은 2025-10부터 유지보수 모드, AG2·CrewAI는 버전 번호만 떠돌고 날짜가 확실한 10월 발표가 없었습니다. Claude Agent SDK도 가장 최근 확인된 변경은 2026-06-15 과금 정책 변경으로, 7일 창 밖입니다.
