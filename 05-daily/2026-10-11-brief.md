## 오늘 하나만 본다면

GitHub Copilot CLI v1.0.94(2026-10-08)는 화면에 보이는 셸 명령을 권한 판단 모델("permission judge")에 보내 일부 명령을 수동 승인 없이 통과시키도록 Assisted Permissions를 바꿨습니다. 같은 주 v1.0.95(2026-10-09)는 macOS에서 Microsoft Entra 브로커 인증을 기본으로 쓰고(미지원 시 브라우저 로그인 폴백), `copilot config`에 샌드박스 자격증명 주입용 `injectHosts` 키를 추가했습니다. [[에이전트-권한-경계-체크리스트]] 6번 원칙은 "되돌릴 수 없거나 민감한 액션은 실행 전에 사람 승인을 거치게 한다"인데, v1.0.94는 정반대 방향 — 승인을 자동화해서 줄이는 — 기본값 변화입니다. 관리형 정책으로 Assisted Permissions를 끄고 Manual Approval을 강제할 수 있다는 점([[2026-10-08-brief]]에서 이미 확인)과 짝을 이루는, "기본값은 느슨해지지만 조직이 조일 수 있는 손잡이는 남겨둔다"는 벤더 설계 패턴입니다.

## devtools

### GitHub Copilot CLI v1.0.94/v1.0.95 — Assisted Permissions 자동화 확대, 샌드박스 자격증명 주입 키 추가
v1.0.94는 화면에 보이는 셸 코드를 권한 판단 모델에 보내 일부 명령이 수동 승인 없이 통과하도록 Assisted Permissions를 바꿨고(관리형 정책으로 이 기능 자체를 끄고 Manual Approval에 고정 가능), MCP 활성화/비활성화가 서버 탐색 전에도 동작하도록 고쳤습니다. v1.0.95는 macOS Microsoft Entra 브로커 인증(미지원 시 브라우저 폴백), 샌드박스 자격증명 주입용 `injectHosts` 설정 키, ACP 세션에서 `--context` 플래그가 신규·재개 세션 모두에 적용되도록 한 수정을 더했습니다.
- 출처: [github/copilot-cli Releases](https://github.com/github/copilot-cli/releases) (v1.0.94, v1.0.95) · 2026-10-08, 2026-10-09
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 6번("되돌릴 수 없거나 민감한 액션은 실행 전에 사람 승인을 거치게 한다")을 적용하는 입장에서, "화면에 보이는 명령이면 자동 승인"이라는 기본값 완화는 Copilot CLI를 쓸 때 관리형 정책으로 Manual Approval을 명시적으로 고정해야 안전한 기본값이 된다는 뜻입니다. 샌드박스 자격증명을 설정 파일 레벨에서 주입 경로를 좁히는 `injectHosts` 키도 같은 체크리스트의 "실행 전 범위를 좁힌다" 계열 항목과 맞닿습니다.
