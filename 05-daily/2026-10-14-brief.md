## 오늘 하나만 본다면

GitHub Copilot CLI v1.0.97이 2026-10-13에 프리릴리스(v1.0.97-0, 10/12)에서 정식(Latest) 릴리스로 승격했습니다. [[2026-10-13-brief]]가 "아직 프리릴리스"라고 표시했던 바로 그 변경 — autopilot이 preToolUse 훅의 "ask" 결정을 거부(deny)로 처리하는 동작 — 이 이제 정식 동작입니다. [[에이전트-권한-경계-체크리스트]] 핵심 6("되돌릴 수 없거나 민감한 액션은 실행 전 사람 승인")이 요구하는 승인 게이트를, 사람이 없는 무인 실행에서는 거부로 채운다는 방향이 하루 만에 "실험적"에서 "기본값"으로 굳어진 셈입니다.

## devtools

### GitHub Copilot CLI v1.0.97 — autopilot ask-거부가 정식 승격
v1.0.97(10/13, 정식)은 10/12 프리릴리스 v1.0.97-0의 변경사항 대부분을 포함합니다: 에이전트 범위 선언형 훅, 원격 플러그인 마켓플레이스의 HTTPS 인증 실패 시 GitHub 토큰 재시도, `/usage`에 청구 AI 크레딧 표시, 100개 초과·깊게 중첩된 커스텀 에이전트 탐색 범위 확대, 지원 터미널 인라인 이미지 기본 렌더링, 메모리 부족으로 죽던 긴 세션이 압축 기록을 유지한 채 생존하도록 개선. 같은 날 나온 프리릴리스 v1.0.97-1~3은 원격 플러그인 재시도·TLS 프록시 스트림·SCP 주소 파싱 등 후속 수정이고, v1.0.98-0은 "Fixes and changes"로만 공개돼 세부 내용은 확인 불가입니다.
- 출처: [github/copilot-cli Releases](https://github.com/github/copilot-cli/releases) (v1.0.97) · 2026-10-13
- 신뢰도: 높음 (1차 출처, 공식 릴리스 페이지)
- 왜 중요한가: [[2026-10-13-brief]]가 "프리릴리스 단계라 설정 방법 미공개"라고 유보했던 autopilot ask-거부 동작이 정식 릴리스로 넘어왔다는 뜻입니다. [[에이전트-권한-경계-체크리스트]]에 "무인 폴백의 기본값은 승인이 아니라 거부"라는 사례가 프리릴리스가 아닌 정식 버전 근거로 바뀌었습니다.

## agents

### langgraph-cli v0.4.33 — 인증정보 포함 Git 의존성 배포 거부
10/7 릴리스로, `langgraph deploy`가 인증정보(credential)가 포함된 Git 의존성 URL을 거부하도록 바뀌었습니다(#8542). 같은 버전에 이미 푸시된 이미지를 바로 배포하는 `--image-uri` 옵션과 `langgraph deploy listeners list` 명령도 추가됐습니다.
- 출처: [langchain-ai/langgraph Releases](https://github.com/langchain-ai/langgraph/releases) (langgraph-cli v0.4.33) · 2026-10-07
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 페이지)
- 왜 중요한가: [[2026-10-11-brief]]가 "LangGraph CLI의 10/7 날짜는 트래커에서만 확인돼 1차 출처를 찾지 못했다"고 남긴 빈틈을 이번에 공식 릴리스 페이지로 채웠습니다. 배포 설정에 인증정보가 끼어드는 경로 자체를 프레임워크가 기본값으로 거부한 사례로, [[에이전트-권한-경계-체크리스트]]가 모아온 "강제 메커니즘으로 경계를 세운다"(핵심 1) 계열 사례에 보탤 수 있습니다.
