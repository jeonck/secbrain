## 오늘 하나만 본다면

Anthropic이 10/14~10/15에 Claude Platform 쪽에서 두 가지를 바꿨습니다. Messages API 요청과 Claude Managed Agents 세션을 옵저버빌리티 백엔드로 추적할 수 있는 **OpenTelemetry export(베타)**가 나왔고, **Claude Opus 5.5의 Fast mode가 연구 프리뷰를 벗어나 정식(GA) 전환**되면서 베타 헤더 없이도 쓸 수 있게 됐습니다. 같은 기간 Managed Agents에는 AWS용 scheduled deployments도 추가됐습니다. 이 vault가 daily-brief·weekly-review를 예약 실행으로 돌리는 구조([[secbrain-site]])라서, "무인 실행을 트레이싱으로 들여다볼 수 있게 됐다"는 변화가 CLI 쪽 재시도 워치독([[2026-10-15-brief]])과 같은 줄기로 이어집니다.

## anthropic

### Claude Platform — Messages API·Managed Agents OpenTelemetry export 베타, Opus 5.5 Fast mode 정식 전환
10/14에 Messages API 요청과 Claude Managed Agents 세션을 추적하는 OpenTelemetry export가 베타로 나왔습니다. Claude SDK가 Python·TypeScript·C#·Go·Java·PHP·Ruby에서 스팬을 내보내고, API 쪽은 Claude Console에서 OpenTelemetry 목적지를 추가하면 받을 수 있습니다. 같은 날 Managed Agents의 scheduled deployments가 AWS의 Claude Platform에서도 지원됐습니다. 10/15에는 Claude Opus 5.5의 Fast mode가 연구 프리뷰를 벗어나 정식 전환됐고, `fast-mode-2026-02-01` 베타 헤더 없이도 요청할 수 있게 됐습니다(Opus 5·Opus 4.8은 여전히 프리뷰라 헤더가 필요). Fast mode는 Microsoft Foundry(Azure)에도 확대됐습니다.
- 출처: [Claude Platform 릴리스 노트](https://platform.claude.com/docs/en/release-notes/api) (2026-10-14, 2026-10-15) · 2026-10-14~15
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 이 vault의 daily-brief·weekly-review는 예약(무인) 실행이라 실패 원인을 사후에 추적할 방법이 거의 없었습니다. API/Managed Agents 레벨 OpenTelemetry 트레이싱은 CLI 쪽 재시도 워치독([[2026-10-15-brief]])·예약 루틴 중복 실행 수정([[2026-10-16-brief]])과 같은 "무인 실행의 관측·복구"를 강화하는 흐름입니다. [[에이전트-권한-경계-체크리스트]] 쪽에도 "무엇이 왜 실행됐는지 사후 확인 가능한가"라는 항목을 보완할 근거가 됩니다.

## devtools

### Zed 1.24.2 — 에이전트 패널 긴 스레드 메모리·CPU 개선, 터미널 탭을 에이전트 패널로 드래그, Git 태그 생성
10/14에 나온 Zed Stable 1.24.2는 에이전트가 긴 스레드에서 응답하는 동안 메모리·CPU 사용량을 낮췄고, 터미널 탭을 에이전트 패널로 드래그해 넣을 수 있게 했습니다. Amazon Bedrock 커스텀 모델은 툴 사용·이미지·thinking을 설정할 수 있게 됐고, Git 쪽에는 로컬 태그 생성 명령과 Git Graph의 커밋 상세 확장이 추가됐습니다. Linux x86_64 배포 바이너리는 약 23% 작아졌습니다.
- 출처: [Zed 1.24.2 릴리스 노트](https://zed.dev/releases/stable/1.24.2) · 2026-10-14
- 신뢰도: 높음 (1차 출처, 공식 릴리스 페이지)
- 왜 중요한가: 에이전트가 긴 스레드를 돌릴 때의 리소스 사용량을 줄이는 방향은 이 브리프가 계속 추적해온 "에이전트 실행 비용·안정성" 흐름과 맞닿습니다. 로컬 에디터에서 에이전트 패널을 1급 UI로 다루는 변화이기도 합니다.
