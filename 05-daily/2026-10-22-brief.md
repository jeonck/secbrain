## 오늘 하나만 본다면

Claude Code v2.1.309(10/22)이 샌드박스 Bash가 명령마다 셸 시작 파일을 샌드박스 밖에서 실행하던 문제, `--mcp-config` 파일을 샌드박스 내부 명령이 수정할 수 있던 문제, `Edit(path)` deny 규칙이 특정 Bash 리다이렉트를 막지 못하던 문제를 고쳤습니다. 동시에 우회 권한 모드(Desktop·VS Code)에서 위험한 `rm`/`rmdir` 명령은 확인 없이 즉시 거부되도록 바뀌었고, `claude ultrareview`는 워크스페이스 신뢰를 요구하게 됐습니다. 세 가지 모두 "권한 경계를 명목상으로만 두지 않는다"는 방향의 수정이라, [[에이전트-권한-경계-체크리스트]]가 전제하는 샌드박스·거부 규칙의 신뢰도를 올려주는 변화입니다.

## anthropic

### Claude Code v2.1.309 — 샌드박스 탈출 경로 3건 수정, 우회 권한 모드에서 위험한 rm/rmdir 즉시 거부 (10/22)
샌드박스 Bash의 셸 시작 파일 실행, `--mcp-config` 파일 변조, `Edit(path)` deny 규칙 우회(Bash 리다이렉트) 세 가지 문제를 고쳤습니다. 우회 권한 모드에서 Desktop 앱과 VS Code는 위험한 `rm`/`rmdir` 명령을 확인 절차 없이 즉시 거부합니다. `claude ultrareview`가 워크스페이스 신뢰를 요구하게 됐고, `sed -i`는 이제 일반 Bash 프롬프트를 거칩니다.

- 출처: [Claude Code 릴리스](https://github.com/anthropics/claude-code/releases) · 2026-10-22
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: 세 가지 샌드박스 탈출 수정 모두 [[에이전트-권한-경계-체크리스트]]가 다루는 "권한 경계는 샌드박스가 실제로 막아야 의미가 있다"는 전제와 직결됩니다. `sed -i`를 일반 프롬프트로 내린 것도 어제(10/21) v2.1.307에서 다룬 `safety_event` 텔레메트리([[2026-10-21-brief]])와 같은 방향의 연속 보강입니다.

### Claude Models on Google Cloud(Anthropic managed) 출시, Opus 5.5 Fast mode 제공 (10/22)
Google Cloud 프로젝트를 통해 Anthropic이 직접 운영하는 Claude API를 쓸 수 있게 됐습니다. 접근 권한은 Google Cloud IAM, 요금은 Google Cloud Marketplace로 청구됩니다. 같은 환경에서 Claude Opus 5.5에 Fast mode도 제공됩니다.

- 출처: [Anthropic 릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · 2026-10-22
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트)
- 왜 중요한가: 이 vault는 GitHub Actions에서 `anthropics/claude-code-action@v1`로 Claude Code를 호출하는 구조([[secbrain-site]])라 직접 쓰는 경로는 아니지만, IAM 단위 과금·권한 분리라는 패턴 자체는 참고할 만합니다.

## agents

### GitHub Copilot CLI v1.0.103 — ACP 세션이 저장된 샌드박스 설정을 재개 시에도 따름, Windows 개발 도구 shim에 샌드박스 권한 부여 (10/22)
ACP 세션이 `--sandbox`/`--no-sandbox` 플래그와 저장된 샌드박스 설정을 재개 시에도 그대로 따르게 됐습니다. `dnx`, `npm.cmd` 같은 Windows 개발 도구 shim에도 샌드박스 권한이 부여됩니다. 레거시 `--remote`/`--no-remote` 시작 플래그는 제거됐습니다.

- 출처: [GitHub Copilot CLI v1.0.103 릴리스](https://github.com/github/copilot-cli/releases) · 2026-10-22
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: 10/21 1.0.102(subagent가 도구 승인을 상속, [[2026-10-21-brief]])에 이어 사흘 연속 같은 제품이 샌드박스·승인 경계를 손대고 있습니다 — [[에이전트-권한-경계-체크리스트]] 관점에서 "세션 재개 시에도 경계가 유지되는가"는 놓치기 쉬운 지점입니다.

### LangGraph 1.2.16 / langgraph-cli 0.4.37 — resume 버그 수정, deploy 기본 타깃을 서버리스로 변경 (10/16~10/19)
재개(resume) 값이 잘못됐을 때 다른 태스크가 끝까지 실행되던 문제, 재개된 Command의 업데이트가 중복 적용되던 문제, 서브그래프가 재개 시 완료된 태스크를 다시 실행하던 문제를 고쳤습니다. `langgraph-cli` 0.4.37은 `langgraph deploy`의 기본 대상을 서버리스로 바꿨습니다.

- 출처: [LangGraph 릴리스](https://github.com/langchain-ai/langgraph/releases) · 2026-10-16~10-19
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: 멀티 에이전트 그래프에서 resume/checkpoint 정확성은 [[cog-architecture]]가 다루는 상태 관리 설계와 맞닿는 영역입니다.

## pkm

### Obsidian 1.15.0 Desktop/Mobile (얼리 액세스) — Mermaid 렌더링을 Pele로 교체, Bases 필터 재정렬, 음성 노트 (10/22)
Desktop은 Mermaid 다이어그램 렌더링을 테마 색상·폰트를 따르고 더 빠른 Pele 라이브러리로 바꿨고, 다이어그램이 노트와 함께 리사이즈·줌 됩니다. Bases 필터를 드래그로 재정렬할 수 있고, 특정 헤딩 아래에 내용을 추가하는 URI·CLI 커맨드가 생겼습니다. Mobile은 iOS 26 Quick Capture에 실시간 전사 음성 노트와 PDF 내보내기를 추가했습니다. 둘 다 "얼리 액세스"로, 정식 공개 전 단계입니다.

- 출처: [Obsidian 체인지로그 — Desktop v1.15.0](https://obsidian.md/changelog/2026-10-22-desktop-v1.15.0/) / [Mobile v1.15.0](https://obsidian.md/changelog/2026-10-22-mobile-v1.15.0/) · 2026-10-22
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: 이 vault의 노트는 `[[wikilink]]` 표기를 그대로 쓰는 등 Obsidian 관례를 따르고 있어([[secbrain-site]]), Bases 필터·URI 커맨드 변화는 vault를 Obsidian으로 열어 쓸 때 바로 영향이 갑니다. 지난 10/21 브리프에서 "16일째 변화 없음"으로 적어둔 pkm 공백이 하루 만에 메워졌습니다.

### Obsidian 1.14.5 Desktop (공개) — Electron 43.8.3 보안 업데이트, 재설치 권장 (10/22)
Electron을 43.7.5에서 43.8.3으로 올리며 여러 보안 수정이 포함됐습니다. Obsidian은 공식 웹사이트에서 다시 내려받아 재설치하라고 안내합니다.

- 출처: [Obsidian 체인지로그 — Desktop v1.14.5](https://obsidian.md/changelog/2026-10-22-desktop-v1.14.5/) · 2026-10-22
- 신뢰도: 높음 (1차 출처, 공식 체인지로그)
- 왜 중요한가: Electron 보안 패치는 로컬 vault를 쓰는 사람에게는 선택이 아니라 기본 유지보수입니다. Obsidian으로 이 vault를 열어본다면 챙길 항목입니다.
