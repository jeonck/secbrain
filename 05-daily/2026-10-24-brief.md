## 오늘 하나만 본다면

GitHub Copilot CLI 1.0.104-2(10/24, 프리릴리스)는 managed "fusion" 모델을 쓰는 세션이 Auto로 시작되며 `fusionTier` 설정을 적용받게 했고, 대화형·SDK Autopilot 세션이 백그라운드로 붙인 태스크를 기다릴 때 `COPILOT_TASK_WAIT_TIMEOUT_SECONDS` 제한으로 멈추지 않고 계속 기다리게 바꿨습니다(`-p --autopilot` 모드는 여전히 이 제한을 따릅니다). 10/20~23 나흘간 이 제품이 다룬 건 주로 샌드박스·승인 경계였는데, 오늘은 모델 선택과 백그라운드 태스크 대기라는 다른 축입니다. 다만 둘 다 "에이전트가 무기한 돌게 두는 조건이 언제인가"와 닿아 있어 [[에이전트-권한-경계-체크리스트]] 관점에서 눈여겨볼 변화입니다.

## agents

### GitHub Copilot CLI 1.0.104-2/-3 — fusion 모델 세션 Auto 시작, Autopilot 백그라운드 태스크 대기 타임아웃 제거 (10/24, 프리릴리스)
1.0.104-2는 managed "fusion" 모델을 쓰는 세션이 Auto로 시작되고 `fusionTier` 설정을 적용받도록 바꿨고, 대화형·SDK Autopilot 세션이 붙인 백그라운드 태스크를 기다릴 때 더 이상 `COPILOT_TASK_WAIT_TIMEOUT_SECONDS`에 걸려 멈추지 않습니다(`-p --autopilot`은 여전히 이 제한을 받습니다). 뒤이은 1.0.104-3은 "Fixes and changes"로만 기록돼 세부 내용이 공개되지 않았습니다. 둘 다 프리릴리스입니다.

- 출처: [GitHub Copilot CLI 릴리스](https://github.com/github/copilot-cli/releases) · 2026-10-24
- 신뢰도: 중간 (1차 출처이나 프리릴리스 — 1.0.104-3은 변경 내용 미공개)
- 왜 중요한가: Autopilot이 백그라운드 태스크 대기 중 타임아웃 없이 계속 기다리게 된 것은 에이전트가 "언제까지 기다릴지"를 스스로 판단하는 범위가 넓어진다는 뜻입니다. 10/20~23 사흘 연속 다룬 같은 제품의 샌드박스·승인 경계 변화([[2026-10-23-brief]])와는 축이 다르지만, [[에이전트-권한-경계-체크리스트]]가 다루는 "무기한 실행을 허용하는 조건"과 맞닿는 지점이라 다음 릴리스에서 안정판(Latest, 현재 1.0.103)에 반영되는지 확인할 근거로 남깁니다.
