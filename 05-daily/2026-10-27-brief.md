## 오늘 하나만 본다면

Claude Code v2.1.311(10/26)은 표준 컨텍스트 세션이 요청 하나가 200K 토큰을 넘을 때 "Usage credits required" 오류로 멈추던 것을, 자동 압축 후 계속 진행하도록 바꿨습니다. 이 저장소의 `daily-brief`·`weekly-review`는 사람이 매 실행을 지켜보지 않는 예약 트리거로 돌아가므로([[secbrain-site]]), 긴 수집·검증 과정에서 세션이 중간에 멈추지 않는 쪽으로 바뀐 건 [[에이전트-권한-경계-체크리스트]]가 전제하는 "예약 파이프라인" 자체의 안정성과 맞닿아 있습니다.

## anthropic

### Claude Code v2.1.311 — 표준 컨텍스트 세션 200K 토큰 초과 시 자동 압축 후 계속 진행 (10/26)
기존에는 표준 컨텍스트 세션에서 요청이 200K 토큰을 넘으면 "Usage credits required" 오류로 멈췄는데, 이제 자동 압축 후 이어서 진행합니다. 같은 릴리스에서 `ultrathink`가 Anthropic API 경로의 Opus 5.5·Sonnet 5.5·Haiku 5.5·Fable 5.1에서 xhigh effort로 실행되도록 바뀌었고, 효과가 없는 `[1m]` 모델 접미사는 무시하되 계속 허용됩니다.

- 출처: [Claude Code 릴리스 v2.1.311](https://github.com/anthropics/claude-code/releases/tag/v2.1.311) · 2026-10-26
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: 이 vault의 `05-daily/` 노트 전부가 사람 검토 없는 예약 실행으로 쌓이는데([[secbrain-site]]), 긴 작업 중 세션이 "멈추는" 실패 모드가 "압축 후 계속"으로 바뀌는 건 [[에이전트-권한-경계-체크리스트]]가 다루는 예약 파이프라인의 신뢰도와 직결됩니다.

## agents

### CrewAI 1.15.29 — AgentExecutor 정식 승격, LiteLLM 호환 kwargs·Azure DocumentDB 벡터 검색 추가 (10/23)
최근 몇 주 중 가장 큰 릴리스로, 실험 기능이었던 `AgentExecutor`를 정식으로 승격했습니다. LiteLLM 호환 kwargs, CLI의 플랫폼 앱 검색, Azure DocumentDB 벡터 검색, `crewai eval` 옵션 확장이 함께 들어갔고, 메모리·LanceDB 조회 관련 버그도 여러 건 고쳤습니다.

- 출처: [CrewAI 릴리스](https://github.com/crewAIInc/crewAI/releases) · 2026-10-23
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: [[cog-architecture]]가 다루는 "리드는 판단, 워커는 파일 작업" 구도에서, CrewAI 쪽 실행기(Executor)가 실험 단계를 벗어난 건 이 vault가 참고하는 멀티 에이전트 실행 모델 비교의 최신 기준점으로 남겨둘 만합니다.

LangGraph도 10/26에 `1.2.18`을 냈지만, 내용은 `DeltaChannel`의 전체 스냅샷 주기를 100회로 줄인 것(기존 1000회, `snapshot_frequency=1000`으로 복원 가능)뿐이라 별도 항목으로 올리지 않았습니다 — 출처: [LangGraph 릴리스](https://github.com/langchain-ai/langgraph/releases) · 2026-10-26, 신뢰도: 높음.
