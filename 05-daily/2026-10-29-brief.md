## 오늘 하나만 본다면

CrewAI 1.15.31(10/27)은 디시리얼라이즈(deserialization), SQL 인젝션, 경로 탈출(path traversal) 취약점을 한 릴리스에서 동시에 패치했습니다 — `output_file`에 템플릿 보간을 거는 경로 탈출 결함도 포함됩니다. 멀티 에이전트 프레임워크 하나에서 서로 다른 취약점 클래스가 한꺼번에 발견·수정됐다는 점은, [[에이전트-권한-경계-체크리스트]]의 "실행에 필요 없는 도구는 아예 뺀다"·"검사와 실행 사이의 틈(TOCTOU)을 상정한다" 항목이 벤더를 가리지 않고 반복해서 맞아떨어지는 사례로 남겨둘 만합니다.

## agents

### CrewAI 1.15.31 — 디시리얼라이즈·SQL 인젝션·경로 탈출 패치, 대화 흐름 컨텍스트 압축 추가 (10/27)
`output_file`에 템플릿 보간을 거는 경로 탈출 결함을 포함해 디시리얼라이즈·SQL 인젝션 취약점을 패치하고, 감사에서 걸린 의존성도 업데이트했습니다. 기능 쪽에서는 대화형 흐름(conversational flow)에 컨텍스트 압축(context compaction)을 지원하기 시작했고, GPT-6 이상 모델에 더 이상 `stop` 파라미터를 보내지 않도록 고쳤습니다.

- 출처: [CrewAI 1.15.31 릴리스](https://github.com/crewAIInc/crewAI/releases/tag/1.15.31) · 2026-10-27
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]]가 다루는 "불필요한 도구 표면을 없앤다"·"검사-실행 틈(TOCTOU)을 가정한다"는 원칙이, 체크리스트 작성 근거였던 Claude Code 사례를 넘어 다른 멀티 에이전트 프레임워크에서도 반복되는지 보여주는 최신 사례입니다. [[cog-architecture]]가 전제하는 워커 쪽 실행 경로의 취약점 유형이기도 합니다.

## devtools

### Zed 1.26.2 — Pyrefly 선택 언어 서버 추가, WebAssembly DWARF 디버깅 (10/28)
Python 언어 서버로 Pyrefly를 선택 사용할 수 있게 됐고, JavaScript 디버거가 WebAssembly 소스의 DWARF 디버깅을 지원합니다. 디버거 호버에서 변수 트리를 펼쳐볼 수 있게 됐고, macOS에서 Display P3 색 공간을 지원합니다. Git 패널에서 언스테이지 변경사항만 버릴 때 스테이지된 변경사항까지 같이 사라지던 버그도 고쳤습니다.

- 출처: [Zed 1.26.2 릴리스](https://zed.dev/releases/stable/1.26.2) · 2026-10-28
- 신뢰도: 높음 (1차 출처, 공식 Zed 릴리스 노트)
- 왜 중요한가: 10/23([[2026-10-23-brief]])에 다룬 1.25.3 이후 주간 릴리스로, 로컬 우선 에디터가 디버거·언어 서버 같은 핵심 개발 경험을 플러그인 없이 내장해가는 흐름이 이어지고 있습니다.
