## 오늘 하나만 본다면

CrewAI 1.15.33(10/29)은 조직이 가진 스킬을 나열하는 `crewai skill search` 명령을 새로 추가했습니다. 바로 전날 다룬([[2026-10-28-brief]]) Anthropic의 Agent Skills(SKILL.md 표준) AAIF 기부 소식과 같은 결의 흐름입니다 — 스킬을 코드에 암묵적으로 묻어두지 않고 "검색 가능한 1급 대상"으로 다루는 쪽으로 여러 프레임워크가 동시에 움직이고 있습니다. 이 vault의 `.claude/skills/*/SKILL.md` 구조([[cog-architecture]], [[secbrain-site]])가 전제하는 바로 그 설계가, CrewAI 같은 멀티 에이전트 프레임워크에서도 독립적으로 재발견되고 있다는 신호로 남겨둘 만합니다.

## agents

### CrewAI 1.15.33 — 조직 스킬 조회 명령 `crewai skill search` 추가 (10/29)
조직이 보유한 스킬을 나열하는 `crewai skill search` 명령이 추가됐고, `crewai run --inputs`가 Python 플로우에도 전달되도록 바뀌었습니다. `deploy create --zip`은 빌드 기준 커밋을 출력합니다. 버그 수정 쪽에서는 LiteLLM 도구 호출·구조화 출력 호출의 토큰 사용량 집계가 빠져 있던 문제, 디바이스 코드 로그인이 타임아웃 전에 조기 종료되던 문제 등을 고쳤습니다.

- 출처: [CrewAI 1.15.33 릴리스](https://github.com/crewAIInc/crewAI/releases/tag/1.15.33) · 2026-10-29
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: "스킬을 조직 단위로 검색 가능하게 만든다"는 방향은, 이 vault가 `.claude/skills/*/SKILL.md`로 동작을 정의하는 구조([[cog-architecture]])와 전날 다룬 Agent Skills AAIF 기부([[2026-10-28-brief]])가 가리키는 흐름에 멀티 에이전트 프레임워크 쪽 사례 하나를 더합니다.
