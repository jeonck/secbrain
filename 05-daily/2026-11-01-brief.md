## 오늘 하나만 본다면

Claude Code 2.1.316(10/31)에 `CLAUDE_CODE_SUBAGENT_EFFORT` 환경 변수가 추가돼, 다른 설정이 없을 때 서브에이전트가 실행될 effort 수준을 메인 세션과 별도로 지정할 수 있게 됐습니다. [[cog-architecture]]의 "더 모을 자료" 섹션(2026-07-31)이 "리드(비싼 모델)가 판단하고 워커(싼 모델)가 I/O를 한다"는 비용 패턴 관련 자료를 모아달라고 적어둔 지점에, 이 패턴을 플랫폼 차원에서 지원하는 1차 출처 설정이 하나 생긴 셈입니다. 같은 릴리스에서 Opus 4.8의 fast mode가 10/30부로 지원 중단, 11/30 제거 예정이라는 점도 모델 선택에 영향을 줄 수 있어 함께 짚습니다.

### Claude Code 2.1.316 — `CLAUDE_CODE_SUBAGENT_EFFORT` 추가, Opus 4.8 fast mode 지원 중단 (10/31)
`CLAUDE_CODE_SUBAGENT_EFFORT` 환경 변수가 추가되어, 서브에이전트별로 effort 수준을 메인 세션 설정과 분리해서 지정할 수 있습니다(기본값은 세션 값 상속). 같은 릴리스에서 Opus 4.8의 fast mode가 2026-10-30부로 지원 중단되고 2026-11-30 제거될 예정이며, 제거 후에는 표준 Opus 4.8로 자동 대체되지 않고 오류를 반환합니다 — 속도가 필요하면 Opus 5.5로 옮겨야 합니다. 그 외 백그라운드 작업에서 깨어난 서브에이전트가 부모 모델 대신 메인 모델로 바뀌던 버그, Vertex/Bedrock에서 최신 모델 불가 시 세션 중 오류 나던 버그 등을 고쳤습니다.

- 출처: [Claude Code 2.1.316 릴리스](https://github.com/anthropics/claude-code/releases/tag/v2.1.316) · 2026-10-31
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: `CLAUDE_CODE_SUBAGENT_EFFORT`는 [[cog-architecture]]의 비용 분리 패턴("리드는 판단, 워커는 I/O")을 세션 설정이 아니라 플랫폼 플래그로 뒷받침하는 사례입니다. [[secbrain-site]]의 스킬 실행 파이프라인에서 워커 역할(파일 I/O·검색)을 하는 서브에이전트에 낮은 effort를 강제할지 검토할 근거로 [[cog-architecture]]에 추가해둘 만합니다.
