## 오늘 하나만 본다면

VS Code 1.144(2026-10-28 stable)가 "Assisted permissions"를 GA로 전환했습니다. LLM이 각 도구 호출의 위험도를 평가해 저위험 호출은 자동 승인하는 방식입니다. [[에이전트-권한-경계-체크리스트]] 핵심 6번("되돌릴 수 없거나 민감한 액션은 실행 전 사람 승인")과 맞닿는 구조이지만, 체크리스트의 "하지 말 것" 2번("벤더의 새 기능 출시 소식 하나만으로 정책을 바꾸지 않는다")이 적용되는 사례이기도 합니다 — 같은 결함/설계 클래스가 반복 확인될 때까지는 근거 목록에 추가해둘 재료로만 보는 게 맞습니다. 같은 릴리스에 에이전트 호스트를 외부 UI와 연결할 수 있게 하는 "Agent Host Protocol v1.0"도 포함돼, [[cog-architecture]]가 말하는 "리드/워커 분리" 구조를 플랫폼이 프로토콜 수준에서 표준화하려는 움직임으로 볼 수 있습니다.

## anthropic

### Claude API 요청 크기 상한 32MB → 128MB (10/28)
1차 API(api.anthropic.com)의 Messages API와 Token Counting API 최대 요청 크기가 32MB에서 128MB로 올랐습니다. Message Batches API(256MB), Files API(500MB)는 별도 상한이며, Bedrock·Vertex 등 클라우드 플랫폼 경로는 이번 변경에 포함되지 않아 32MB 등 기존 상한이 유지됩니다.

- 출처: [Claude Platform 릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · 2026-10-28
- 신뢰도: 높음 (1차 출처, 공식 플랫폼 릴리스 노트)
- 왜 중요한가: 이미지·PDF 등 대용량 입력을 다루는 스킬(예: [[ask]]의 첨부 근거 자료 처리)에서 그동안 32MB 제약으로 쪼개야 했던 요청을 단일 호출로 처리할 수 있게 됩니다. 단, Claude Code 자체는 Anthropic API를 거쳐도 이 한도가 실행 경로에 직접 노출되는 경우는 드물어 당장 vault 작업에 영향은 적습니다.

### Usage and Cost Analytics API 베타 출시 (10/29)
`analytics-usage-cost-2026-08-24` 베타 헤더로 쓰는 신규 엔드포인트(`/v1/organizations/analytics/usage`, `/v1/organizations/analytics/cost`)가 열렸습니다. Claude Console·Enterprise 조직의 토큰 사용량·비용을 모델·워크스페이스·API 키·사용자 단위로 필터링/그룹핑해 조회할 수 있습니다. 기존 `usage_report`/`cost_report` 계열 엔드포인트는 legacy로 전환되지만 계속 지원됩니다.

- 출처: [Claude Platform 릴리스 노트](https://platform.claude.com/docs/en/release-notes/overview) · 2026-10-29
- 신뢰도: 높음 (1차 출처, 공식 플랫폼 릴리스 노트)
- 왜 중요한가: [[cog-architecture]]의 "비용 패턴"(리드는 비싼 모델, 워커는 싼 모델)을 실제로 검증하려면 모델·세션 단위 비용 데이터가 필요합니다. 이 API가 Console/Enterprise 조직 대상이라 이 vault의 개인 사용 범위와는 거리가 있지만, 나중에 "비용 패턴" 자료를 더 모을 때 측정 방법으로 참고할 수 있습니다.

## devtools

### VS Code 1.144 — Assisted permissions GA, Agent Host Protocol v1.0 (10/28)
"Assisted permissions"가 GA로 전환되어, LLM이 에이전트의 각 도구 호출 위험도를 평가해 저위험 호출은 자동 승인합니다. 같은 릴리스에서 에이전트 호스트(에이전트를 로컬·원격에서 계속 실행시키는 별도 프로세스)를 외부 UI나 WebSocket 클라이언트와 연결할 수 있는 "Agent Host Protocol v1.0"을 공개했고, Computer Use(실험적, macOS/Windows 데스크톱 제어)도 추가됐습니다.

- 출처: [Visual Studio Code 업데이트 노트](https://code.visualstudio.com/updates) · 2026-10-28
- 신뢰도: 높음 (1차 출처, 공식 에디터 릴리스 노트)
- 왜 중요한가: Assisted permissions는 [[에이전트-권한-경계-체크리스트]] 핵심 6번(승인 게이트)의 벤더 구현 사례 목록에 추가할 만한 재료입니다. 다만 체크리스트의 "하지 말 것" 2번에 따라 이 소식 하나로 정책을 바꾸지는 않습니다 — 같은 설계(위험도 기반 자동 승인)가 다른 벤더에서도 반복되는지 지켜볼 대상입니다. Agent Host Protocol은 [[secbrain-site]]의 이슈 트리거 → Actions 실행 구조와는 다른 "항상 켜진 로컬 에이전트 호스트" 모델이라, 이 vault 파이프라인에 바로 적용되는 사례는 아닙니다.

## 확인하지 못한 것

**agents** — 멀티 에이전트 오케스트레이션 쪽에서 7일 창(10/26~11/2) 안의 1차 출처 릴리스를 찾지 못했습니다. LangGraph·CrewAI·AutoGen·Microsoft Agent Framework 모두 공식 변경 로그에서 이 기간에 해당하는 날짜가 확인되는 항목을 찾지 못했고, 나온 버전 숫자들도 서드파티 비교 블로그마다 달라 신뢰하기 어려웠습니다.

**pkm** — Obsidian 공식 changelog(obsidian.md/changelog)를 직접 확인한 결과 최신 항목은 여전히 10/22(1.15.0 데스크톱/모바일, 1.14.5 보안 패치)이고 10/23~11/2 사이 새 릴리스는 없습니다([[2026-10-27-brief]]·[[2026-11-01-brief]]에서 이미 다룸). Logseq 2.0.2(10/7 추정)·Tana·Capacities 관련 소식도 찾았지만 날짜가 7일 창 밖이거나 1차 출처로 확인되지 않아 제외했습니다.
