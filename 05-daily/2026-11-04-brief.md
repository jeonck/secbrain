## 오늘 하나만 본다면

Claude Code 2.1.318(오늘, 11/4)이 두 가지 경계 우회를 고쳤습니다. 하나는 self-hosted 러너를 재시작한 뒤 이미 승인된 셸 명령이 사용자가 요청한 폴더가 아니라 세션이 처음 시작된 폴더에서 실행되던 버그 — 이제 그 폴더에 들어갈 수 없으면 명령 자체가 실행되지 않습니다. 다른 하나는 `deniedMcpServers`의 URL 차단 범위를 업스트림 URL이 일치하는 Anthropic 제공 서버와 클라우드 세션 커넥터까지 넓힌 것입니다. 둘 다 [[에이전트-권한-경계-체크리스트]] 핵심 1("경계는 정책 선언이 아니라 강제 메커니즘")과 핵심 7("게이트가 있다"와 "게이트가 실제로 버틴다"의 구분)이 10/30(v2.1.314 `blockWritesOutsideWorkingDirectories`)부터 추적해온 같은 메커니즘이 한 주 만에 또 한 번 구멍을 메운 사례입니다. 이 vault의 파이프라인은 self-hosted 러너가 아니라 GitHub Actions 호스팅 러너로 돈다는 점에서([[secbrain-site]]) 이번 수정이 직접 적용되는 건 아니지만, "재시작"이라는 조건에서 경계가 새는 패턴 자체는 체크리스트 핵심 8(무인 재실행 안전성)과도 같은 축이라 사례로 남겨둘 만합니다.

## anthropic

### Claude Code 2.1.318 — self-hosted 러너 재시작 후 폴더 경계 우회 수정, deniedMcpServers 범위 확대 (11/4)
self-hosted 러너를 재시작한 뒤 이전에 승인된 셸 명령이 요청된 폴더가 아니라 세션이 시작된 폴더에서 실행되던 문제를 고쳤습니다. 이제 요청된 폴더에 들어갈 수 없으면 명령이 실행되지 않습니다. `deniedMcpServers`의 URL 항목은 업스트림 URL이 일치하는 Anthropic 제공 서버와 클라우드 세션 커넥터까지 차단하도록 범위가 넓어졌고, 권한 프롬프트가 메시지 전송 직후 입력된 키 입력에 잘못 반응하던 문제, 헤드리스 세션에서 모델 변경 직후 보낸 메시지가 Stop 이후에도 계속 실행되던 문제(이제 대기 메시지처럼 취소됨)도 수정됐습니다.

- 출처: [Claude Code 2.1.318 릴리스](https://github.com/anthropics/claude-code/releases/tag/v2.1.318) · 2026-11-04
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: self-hosted 러너 재시작 시 폴더 경계가 새던 버그는 [[에이전트-권한-경계-체크리스트]] 핵심 1·7이 10/30(v2.1.314)부터 쌓아온 "메커니즘이 선언대로 실제로 버티는가" 사례 목록에 들어갈 재료입니다. 이 vault는 self-hosted가 아닌 GitHub 호스팅 러너로 돌아([[secbrain-site]]) 이번 건 자체는 직접 해당하지 않지만, "재시작 후 경계 유지"라는 조건은 체크리스트 핵심 8(무인 재실행 안전성)과 겹치는 지점이라 같이 적어둡니다.

## devtools

### GitHub Copilot CLI 1.0.106 시리즈 — MCP 전용 콘텐츠 모델 전달 차단, BYOK 키 로그 노출 수정 (10/31~11/3)
연속 프리릴리스(1.0.106-1~7) 중 보안 관련 수정 두 건: 사용자에게만 전달되도록 지정된 MCP 콘텐츠가 모델로 보내지지 않도록 바뀌었고(1.0.106-6, 11/3), BYOK(Bring Your Own Key) 키가 오류 메시지나 세션 로그에 노출되지 않도록 수정됐습니다(1.0.106-5, 11/3). 같은 시리즈에 `/code`로 현재 세션을 VS Code에서 열기, `/settings` 통합 대시보드, 세션 관리·열린 로컬 세션 @멘션(옵트인) 기능도 추가됐습니다.

- 출처: [GitHub Copilot CLI 릴리스](https://github.com/github/copilot-cli/releases) · 2026-11-03 (1.0.106-5, -6)
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스. 다만 프리릴리스 채널이라 안정 버전에 언제 반영될지는 확인 불가)
- 왜 중요한가: 이 벤더는 [[에이전트-권한-경계-체크리스트]] 핵심 7의 각주에 이미 등장합니다 — 2026-10-11 Assisted Permissions 기본값 완화 사례. 이번 두 수정은 반대 방향(의도치 않은 데이터 노출을 막는 쪽)이지만, "게이트가 있다"와 "실제로 버틴다"를 구분해야 한다는 같은 결론으로 수렴합니다 — MCP 콘텐츠·BYOK 키처럼 "이 수신자에게만"이라는 경계가 선언돼 있어도 실제로 지켜지는지는 별도로 확인해야 한다는 사례입니다.

## pkm

### Obsidian 1.15.1 Desktop/Mobile — catalyst 채널, Web viewer 플러그인·검색 개선 (11/3)
11/2 정식 공개된 1.15.0 다음 버전인 1.15.1이 catalyst(얼리 액세스) 채널에 올라왔습니다. 모바일에는 외부 링크를 노트 위 슬라이드업 브라우저로 여는 Web viewer 코어 플러그인이 추가됐고, 데스크톱 검색에는 "관련성(Relevance)" 정렬과 악센트 무시 검색이 들어갔습니다. 개발자 대상으로는 `Array#contains`/`String#contains`가 deprecated 처리되고 `includes` 사용이 권장됩니다.

- 출처: [Obsidian 체인지로그 — Desktop v1.15.1 (Catalyst)](https://obsidian.md/changelog/) · 2026-11-03
- 신뢰도: 높음 (1차 출처, 공식 체인지로그. catalyst는 얼리 액세스 채널이라 정식 공개 시점은 아직 미확정)
- 왜 중요한가: 이 vault는 `[[wikilink]]` 등 Obsidian 관례를 그대로 쓰는 구조라([[secbrain-site]]), 이번 릴리스의 API 변경(특히 `includes` 권장)은 당장 영향이 없지만 이 vault를 Obsidian으로 직접 열어 쓰는 경우를 대비해 기록해둡니다.
