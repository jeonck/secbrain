## 오늘 하나만 본다면

Claude Code 2.1.317(11/3)이 Agent SDK 훅 콜백에 `onFailure: "block"` 옵션을 추가했습니다 — 콜백이 실패하면 기본 동작(통과)과 달리 해당 액션 자체를 막을 수 있게 명시적으로 고를 수 있습니다. 같은 릴리스에 웹·셸 도구 호출이 계정 이메일 주소를 네트워크로 내보내려 할 때 확인을 거치게 하는 체크도 추가됐습니다. [[에이전트-권한-경계-체크리스트]] 핵심 7은 2026-10-09에 "지시문 훅 `onFailure` 기본값이 통과였던 버그"를 이미 사례로 들었는데, 이번 건은 그 버그 자체의 재발은 아니고 다른 제품 표면(CLI 훅이 아니라 Agent SDK)에서 "콜백이 실패했을 때 무조건 통과시키지 않고 고를 수 있게" 만든 보강입니다. 이메일 유출 확인 체크는 핵심 1(강제 메커니즘)과 핵심 4(트리거·경계 최소화)에 걸치는 작은 사례로 남겨둘 만합니다.

## anthropic

### Claude Code 2.1.317 — Agent SDK 훅에 `onFailure: "block"` 추가, 계정 이메일 네트워크 전송 전 확인 (11/3)
Agent SDK의 훅 콜백에 `onFailure: "block"`을 지정할 수 있게 됐습니다. 콜백이 실패했을 때 액션을 그대로 통과시키는 대신 막을 수 있는 선택지가 명시적으로 생긴 것입니다. 같은 릴리스에 웹·셸 도구 호출이 계정 이메일 주소를 네트워크로 보내려 할 때 사용자에게 먼저 확인을 구하는 체크도 추가됐고, `GET /v1/organizations/analytics/cost`(게이트웨이 관리자 API 비용 리포트), `CLAUDE_CODE_DISABLE_NESTED_SESSION_ID`(self-hosted 러너 세션 내부 `claude -p`가 고유 세션 ID 유지) 등도 포함됐습니다.

- 출처: [Claude Code 2.1.317 릴리스](https://github.com/anthropics/claude-code/releases/tag/v2.1.317) · 2026-11-03
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 7은 10/9에 "훅 `onFailure` 기본값이 통과였던 버그"를 이미 사례로 들어뒀습니다. 이번 건은 그 버그의 재발이 아니라 다른 제품 표면(Agent SDK)에서 같은 질문 — "콜백이 실패하면 무조건 통과인가, 선택 가능한가" — 에 명시적 답을 추가한 것이라 같은 축에 넣어둘 만합니다. 이메일 유출 확인 체크는 작지만 핵심 1·4(강제 메커니즘, 트리거 최소화)와 닿는 사례입니다.
