## 오늘 하나만 본다면

Claude Code `2.1.321`(11/9)은 "mod"(플러그인형 확장)가 **auto·bypass 모드에서 사용자에게 묻지 않고 자동으로 켜지도록** 바꿨습니다 — 관리형 설정 `allowUnsandboxedCommands: false`나 `allowManagedDomainsOnly`가 걸려 있어도 마찬가지입니다(`dontAsk` 모드에서는 로드되지 않음). 같은 릴리스는 mod 자신의 도구 호출(`$.tool.call`, `$.mcp.call`)이 사용자의 ask 규칙이나 `dontAsk`·`-p` 실행 중에도 **권한 프롬프트를 띄우지 않도록** 바꿨습니다 — deny 규칙과 조직 정책은 여전히 적용됩니다. 두 변경 모두 [[에이전트-권한-경계-체크리스트]] 핵심 1("경계는 강제 메커니즘, 기본값을 위험한 쪽에 두지 않는다")의 **반대 방향**(기본값을 덜 묻는 쪽으로 완화)이며, [[2026-11-09-brief]]가 짚었던 `2.1.318`의 "신규 에이전트 기본 권한을 `auto`로"와 같은 패턴입니다. deny 규칙·조직 정책이라는 백스톱이 남아 있다는 점에서 핵심 7("게이트가 있다"와 "버틴다"의 구분)이 여전히 성립하는지 확인할 필요가 있습니다 — `secbrain-site`의 예약 실행([[secbrain-site]])이 바로 이 Claude Code 버전으로 돌아갑니다.

## anthropic

### Claude Code 2.1.321 — mod 자동 활성화·자체 도구 호출의 권한 프롬프트 제거, 읽기전용 Bash 샌드박스 이탈 버그 수정 (11/9)
"오늘 하나만 본다면"에서 다룬 두 변경 외에, 같은 릴리스는 [[에이전트-권한-경계-체크리스트]] 핵심 3·7과 맞닿은 버그 수정 세 건을 포함합니다: 읽기전용 Bash 명령이 샌드박스 밖에서 프롬프트 없이 실행되던 문제, Bash 권한 검사가 잘못된 폴더 기준으로 쓰기를 판단해 프롬프트를 건너뛰던 문제, MCP OAuth가 리다이렉트 시 토큰 같은 비밀 값을 다른 호스트로 보내던 문제입니다. 이 셋은 "게이트가 선언돼 있었지만 실제로 버티지 않았던" 사례로, mod 쪽 완화와 반대로 핵심 1·7을 강화하는 방향입니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-09
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: 같은 릴리스 안에서 권한 경계가 한쪽(mod)은 완화되고 다른 쪽(샌드박스·OAuth)은 강화되는 상반된 변경이 동시에 들어갔다는 것은, 체크리스트 "하지 말 것" 항목대로 플래그·릴리스 이름만 보고 전체 방향을 판단할 수 없다는 뜻입니다.

### Claude Fable 5.2 / Mythos 5.2 출시 — 1M 컨텍스트, prefix check 전 계정 강제 적용 (11/9)
Anthropic이 `claude-fable-5-2`와 `claude-mythos-5-2`를 출시했습니다. 1M 토큰 컨텍스트, 최대 출력 128k, 상시 adaptive thinking을 지원하며 가격은 입력 $8/출력 $40 per Mtok(5.1 대비 인하)입니다. 계정 생성 시기와 무관하게 모든 계정에 prefix check가 강제되어, 이전 턴의 thinking 블록을 수정한 뒤 되돌려 보내면 400 오류가 발생합니다.

- 출처: [Claude API 릴리스 노트](https://platform.claude.com/docs/en/release-notes/api) · 2026-11-09
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트 원문 직접 확인)
- 왜 중요한가: 권한 경계 이슈는 아니지만 `anthropic` 키가 명시한 "Claude·Anthropic 제품 및 API 변경사항"에 직접 해당하며, prefix check 강제 적용은 기존 코드가 조용히 깨질 수 있는 breaking change입니다.

## devtools

### Zed 1.27.0 — `disable_ai: true`인데도 LLM 자격 증명을 읽던 문제 수정 (11/4)
에디터 Zed의 안정 채널 1.27.0은 AI 기능을 끈 상태(`disable_ai: true`)에서도 LLM 자격 증명(API 키 등)을 읽어들이던 버그를 고쳤습니다. 같은 릴리스는 동적으로 등록된 language server 기능이 선언된 `pattern` 밖의 파일에도 적용되던 문제, 무관한 파일까지 변경·저장 알림을 받던 문제도 수정했습니다.

- 출처: [Zed 1.27.0 릴리스 노트](https://zed.dev/releases/stable/1.27.0) · 2026-11-04
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트 원문 직접 확인)
- 왜 중요한가: "설정으로는 꺼져 있다고 선언했는데 실제로는 자격 증명을 읽고 있었다"는 것은 [[에이전트-권한-경계-체크리스트]] 핵심 7의 정의 그대로 — 게이트가 선언돼 있어도 실제로 버티는지는 별개임을 보여주는 사례입니다. 11월 1주차 윈도우(11/4)에 가까운 날짜지만 다른 브리프가 아직 다루지 않았습니다.
