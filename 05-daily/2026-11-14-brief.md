## 오늘 하나만 본다면

Claude Code `2.1.325`(11/13)은 샌드박스 안에서 실행되는 Bash 명령도 이제 기본적으로 일반 권한 확인 흐름을 따르도록 바꿨습니다 — 프롬프트 없이 계속 돌리려면 `sandbox.autoAllowBashIfSandboxed: true`를 명시해야 합니다. 변경 로그에 이전 동작이 직접 적혀 있진 않지만 문구("이제부터 일반 흐름을 따른다")로 보면, 그동안 샌드박스 안이라는 이유로 Bash가 승인 없이 돌았다는 뜻입니다. 같은 주 다른 벤더에서도 같은 방향의 움직임이 있었습니다 — OpenAI Agents SDK `v0.24.0-alpha.7`(11/8)은 `Environment`의 `write_policy` 기본값을 `"strict"`로 바꿨고(이전 동작을 쓰려면 `"legacy"`를 명시), LangGraph `1.2.21`(11/12)은 서브그래프가 부모 그래프에서 선언되지 않은 네임스페이스를 읽을 수 있던 버그를 고쳤습니다. [[에이전트-권한-경계-체크리스트]] 핵심 1(강제 메커니즘)·핵심 7(게이트가 "있다"와 "버틴다"의 구분)이 세 벤더에서 거의 동시에, 그리고 전부 "완화가 아니라 조이는" 방향으로 반복되고 있습니다. [[secbrain-site]]의 예약 실행도 이 샌드박스·권한 흐름 위에서 돌기 때문에, 다음 실행 전에 `.github/workflows`의 샌드박스 설정이 이 기본값 변경으로 영향을 받는지 확인할 필요가 있습니다.

## anthropic

### Claude Code 2.1.325 — 샌드박스 Bash가 기본적으로 일반 권한 흐름을 따르도록 변경 (11/13)
"오늘 하나만 본다면"에서 다룬 변경입니다. 관리형(managed) 설정으로 샌드박스를 켜는 조직도 `sandbox.autoAllowBashIfSandboxed: true`를 가장 우선순위가 높은 관리형 소스에 설정해야 기존처럼 프롬프트 없이 돌립니다. 같은 릴리스는 `/security-review` 실행 전에도 확인을 요청하도록 바꿨습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-13
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 1의 정의("경계는 강제 메커니즘으로 세운다")가 적용되는 범위가 넓어진 사례이자, 11/9 `2.1.321`의 완화("mod 도구 호출은 auto 모드에서 묻지 않음")와 다시 반대 방향으로 가는 2주 연속 조정입니다.

### Claude API — Claude Fable 5.2 / Mythos 5.2 출시, 1M 컨텍스트·fast mode (11/9)
Fable 5.2(공개)와 Mythos 5.2(Cyber Verification Program 통과 조직 한정)가 1M 토큰 컨텍스트와 상시 adaptive thinking을 지원하며 출시됐습니다. 두 모델의 thinking 블록은 다른 Claude 모델에서 읽을 수 없고 해당 계정 밖에서도 작동하지 않습니다. 가격은 입력 $8·출력 $40/MTok(fast mode는 입력 $16·출력 $80)입니다.

- 출처: [Claude API 릴리스 노트](https://platform.claude.com/docs/en/release-notes/api) · 2026-11-09
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트 원문 직접 확인)
- 왜 중요한가: 권한 경계 이슈는 아니지만, thinking 블록이 계정 밖에서 작동하지 않는다는 제약은 세션 기록 이동성에 영향을 주므로 `anthropic` 키 범위의 일반 제품 변경으로 기록합니다.

## agents

### OpenAI Agents SDK v0.24.0-alpha.7 — Environment의 write_policy 기본값이 "strict"로 변경 (11/8)
업그레이드 시 확인할 사항 중 하나로, `Environment`의 쓰기 정책 기본값이 `"strict"`로 바뀌어 이전 동작을 쓰려면 `"legacy"`를 명시해야 합니다. 같은 프리릴리스는 MCP 승인 모드 이름도 `"auto"`→`"native"`, `"approve"`→`"preapproved"`로 바꾸고 이전 값을 거부합니다.

- 출처: [openai-agents-python v0.24.0-alpha.7 릴리스](https://github.com/openai/openai-agents-python/releases/tag/v0.24.0-alpha.7) · 2026-11-08
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 본문 직접 확인)
- 왜 중요한가: "오늘 하나만 본다면"에서 다룬 대로 [[에이전트-권한-경계-체크리스트]] 핵심 1이 같은 주 다른 벤더에서 반복되는 사례입니다. 다만 alpha 단계라 안정화 전 바뀔 수 있어 다음 주기에 정식 릴리스 반영 여부를 확인해야 합니다.

### LangGraph 1.2.21 — 서브그래프의 네임스페이스 경계 버그 두 건 수정 (11/12)
`get_subgraphs`가 네임스페이스 세그먼트 전체를 일치시키지 않던 버그와, 서브그래프가 부모 그래프에서 선언되지 않은 네임스페이스를 읽을 수 있던 버그를 고쳤습니다. 같은 릴리스에 보안 관련 의존성(`filelock`, `langgraph-api`) 업데이트도 포함됩니다.

- 출처: [langgraph 1.2.21 릴리스](https://github.com/langchain-ai/langgraph/releases/tag/1.2.21) · 2026-11-12
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 본문 직접 확인, PR 제목까지 확인)
- 왜 중요한가: "선언되지 않은 네임스페이스를 읽을 수 있었다"는 정확히 [[에이전트-권한-경계-체크리스트]] 핵심 3(검사-실행 사이 틈)이 상정하는 경계 누수의 모양이고, 이 vault가 핵심 8의 근거로 이미 추적 중인 LangGraph의 resume/네임스페이스 결함 계열([[2026-10-18-brief]])이 계속되고 있다는 뜻입니다.

## devtools

### GitHub Copilot CLI 1.0.112 — 조직의 MCP 비활성화 정책이 내장 GitHub MCP 서버에도 적용, 서브에이전트가 세션 전체 AI 크레딧 한도를 따르도록 변경 (11/13)
그동안 조직 정책으로 MCP 서버를 껐어도 내장 GitHub MCP 서버는 예외였는데, 이번 릴리스로 그 구멍이 막혔습니다. 서브에이전트도 `--max-ai-credits`로 설정한 세션 전체 한도를 따르도록 바뀌었고, 세션 재개 시 이전에 쓴 크레딧도 한도에 포함됩니다.

- 출처: [copilot-cli v1.0.112 릴리스](https://github.com/github/copilot-cli/releases/tag/v1.0.112) · 2026-11-13
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 본문 원문 직접 확인)
- 왜 중요한가: "내장 서버는 예외"라는 구멍이 닫힌 것은 [[에이전트-권한-경계-체크리스트]] 핵심 7("게이트가 있다"는 착시)이 벤더 스스로 수정된 또 다른 사례입니다. 서브에이전트의 크레딧 한도 상속도 핵심 1(강제 메커니즘이 하위 단위까지 미치는가)과 같은 결의 보강입니다.

### GitHub Copilot CLI 1.0.111 — 기업 관리형 Shell/Bash/PowerShell 권한 규칙에 정규식 지원 추가 (11/13)
기업이 관리형 정책으로 Shell·Bash·PowerShell 명령 허용·차단 규칙을 쓸 때 정규식을 지원하게 됐습니다. `--host-allow-session-creation` 옵션도 새로 추가됐습니다.

- 출처: [copilot-cli v1.0.111 릴리스](https://github.com/github/copilot-cli/releases/tag/v1.0.111) · 2026-11-13
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 본문 원문 직접 확인)
- 왜 중요한가: 정규식 규칙은 권한 경계를 더 세밀하게 그릴 도구를 주는 변화지만, 정규식 자체가 오탐·우회의 새 표면이 될 수 있어 [[에이전트-권한-경계-체크리스트]] 핵심 3 관점에서 다음 주기에 관련 결함 보고가 나오는지 지켜볼 대상입니다.
