## 오늘 하나만 본다면

Anthropic이 11/12 Claude Managed Agents의 **self-hosted** 옵션(서비스 전체를 자체 인프라에서 운영)을 공개했습니다. 기존 self-hosted sandboxes는 "툴 실행 환경"만 사용자 쪽으로 옮기지만, 이번 옵션은 API·에이전트 루프·세션 저장소까지 전부 사용자가 돌립니다. 문서는 보안 책임 섹션에서 "에이전트의 bash 툴은 워커 프로세스의 권한과 네트워크 접근을 그대로 가진 진짜 셸이며, 워커 자신은 그 셸을 격리하지 않는다 — 격리는 워커를 무엇으로 감싸느냐에서 나온다"고 명시합니다. [[에이전트-권한-경계-체크리스트]] 핵심 1("경계는 강제 메커니즘으로 세운다")이 벤더 문서에 이렇게 직접적으로 쓰인 경우는 드뭅니다. self-hosted 옵션을 쓰는 순간 "격리됐다"는 착시(핵심 7)를 막을 책임이 운영자에게 완전히 넘어간다는 뜻이고, [[secbrain-site]]가 GitHub Actions 위에서 돌리는 예약 실행도 결국 "무엇이 그 셸을 감싸는가"로 같은 질문을 받습니다.

## anthropic

### Claude Managed Agents — self-hosted 옵션 공개, 서비스 전체를 자체 인프라에 (11/12)
"오늘 하나만 본다면"에서 다룬 변경입니다. 모델 호출만 Anthropic·Bedrock·Google Cloud·Foundry·자체 게이트웨이 중 고를 수 있고, 서버(`cma-server`)·DB(PostgreSQL 16+)·워커는 전부 사용자가 운영·보안·버전 관리를 책임집니다. 서버-워커-인프라 간 신뢰 경계를 넘는 자격증명은 서버 API 키·추론 자격증명·환경 키 3종으로 분리되어 있습니다.

- 출처: [Self-hosted Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/self-hosted) · 2026-11-12
- 신뢰도: 높음 (1차 출처, 공식 문서 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 1·7이 벤더 공식 문서에 명시적으로 쓰인 사례. self-hosted sandboxes의 보안 모델을 그대로 가져오면서 "각 신뢰 수준마다 별도 배포가 필요하다"는 조건을 추가했다는 점도 멀티테넌시 경계 설계에 참고할 만합니다.

### Claude Code 2.1.323 — 훅 실패·MCP 승인 스펠링 불일치에서의 권한 판정 변경 (11/12)
`PreToolUse` 훅이 "allow"를 반환한 뒤 권한 검사 자체가 에러로 실패하면 이제 훅이 아예 응답하지 않은 것처럼 처리합니다. `PermissionRequest` 훅이 입력을 고쳐 쓴 뒤 검사가 실패하면 다시 묻거나(답할 사람이 없으면) 거부합니다. 또한 `.mcp.json` 프로젝트 MCP 서버 승인이 서버 이름과 정확히 일치해야 하며, 다른 표기로 저장된 승인은 다시 묻게 바뀌었습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-12
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: 세 변경 모두 "훅·승인이 있다"와 "훅·승인이 실제로 버틴다"(핵심 7)의 간극을 좁히는 조정입니다. 특히 MCP 승인의 스펠링 불일치 허점은 [[에이전트-권한-경계-체크리스트]] 핵심 3(검사-실행 사이 틈)이 상정하는 바로 그 모양의 결함이었습니다.

## agents

### LangGraph 1.2.22 — 서브그래프 스트리밍 버그 수정, 성능 개선 다수 (11/14)
호출자가 `stream_mode="subgraphs"`로 스트리밍할 때 자식 그래프가 자신만의 스레드에서 실행되면 스트림이 제대로 전달되지 않던 버그를 고쳤습니다. 메시지 변환 생략, 보류 중 쓰기 필터링 등 성능 개선 5건이 함께 들어갔습니다.

- 출처: [langgraph 1.2.22 릴리스](https://github.com/langchain-ai/langgraph/releases/tag/1.2.22) · 2026-11-14
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 본문·PR 제목 직접 확인)
- 왜 중요한가: [[2026-11-14-brief]]가 추적한 1.2.21의 네임스페이스 경계 수정과 같은 서브그래프 영역에서 하루 뒤 또 수정이 나온 것으로, [[에이전트-권한-경계-체크리스트]] 핵심 8의 근거로 쌓아온 LangGraph 서브그래프 결함 계열([[2026-10-18-brief]])이 계속되고 있습니다. 이번 건은 경계 결함이 아니라 스트리밍 버그라 직접 해당하진 않지만, 같은 서브코드 영역의 변경 빈도 자체가 지켜볼 신호입니다.
