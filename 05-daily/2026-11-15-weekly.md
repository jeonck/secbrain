## 발견한 패턴

### 완화와 강화가 쌍으로 온다 — 경계 변경은 한 방향으로 가지 않는다

[[2026-11-10-brief]]가 "같은 릴리스 안에서 한쪽(mod 자동 활성화)은 완화되고 다른 쪽(샌드박스·OAuth)은 강화되는 상반된 변경이 동시에 들어갔다"고 적은 뒤, 같은 관찰이 이번 주 내내 다른 표현으로 반복됐다. [[2026-11-12-brief]]는 GitHub Copilot CLI에서 "경계를 좁히는 변경과 넓히는 변경이 같은 사흘 안에 동시에 들어갔다"며 이를 "벤더를 바꿔 반복된 사례"라고 명시적으로 이어붙였다. [[2026-11-13-brief]]는 Claude Code `2.1.323`이 11/9 `2.1.321`의 완화를 "같은 2주 사이클 안에서 Anthropic 자신이 다시 조인" 사례라 적었고, [[2026-11-14-brief]]는 Claude Code·OpenAI Agents SDK·LangGraph 세 벤더가 "거의 동시에 기본 권한 범위를 좁힌" 흐름으로 범위를 넓혔다. [[2026-11-16-brief]]는 결국 `2.1.321`(완화)→`2.1.323`(되돌림)→`2.1.325`(강화)를 한 묶음으로 요약했다. 다섯 개 노트가 다섯 가지 표현으로 같은 모양을 짚은 셈이다 — 가설: 권한 경계 변경을 "이번 주는 조였다/풀었다"로 한 방향으로 읽는 건 틀린 질문일 수 있고, [[에이전트-권한-경계-체크리스트]] 핵심 7("게이트가 있다"와 "버틴다"의 구분)에 "어느 방향으로 움직였는가"를 묻는 세 번째 축이 필요할지도 모른다.
