## 오늘 하나만 본다면

Claude Code 2.1.325(11/13)는 샌드박스 안에서 돌던 Bash 명령이 지금까지 프롬프트 없이 조용히 실행되던 것을, 기본적으로 일반 권한 플로우(승인 요청)를 타도록 바꿨습니다. 기존 동작을 유지하려면 조직의 가장 높은 순위 관리 설정에서 `sandbox.autoAllowBashIfSandboxed: true`를 명시적으로 켜야 합니다. 같은 릴리스가 격리된 워크트리에서 `git bisect run`·`git maintenance register|start`·`scalar` 설정 명령을 거부하고, 추가 디렉터리의 `.claude` 설정·스킬·훅에 대한 샌드박스 쓰기도 막았습니다. [[에이전트-권한-경계-체크리스트]] 핵심 7("게이트가 '있다'와 게이트가 '실제로 버틴다'를 구분한다")이 지적한 간극 — 샌드박스가 있다는 사실만으로 안전하다고 느끼는 착시 — 를 벤더가 기본값 전환으로 직접 좁힌 사례입니다. 같은 릴리스 계열인 2.1.321(11/9)에서도 MCP OAuth 토큰이 리다이렉트된 다른 호스트로 새던 결함, `cp`/`mv`가 디렉터리에 쓸 때 deny 규칙을 피하던 결함, 복합 명령이 권한 검사를 우회하던 틈 등 핵심 3(검사-실행 사이 틈)에 해당하는 수정이 한 릴리스에 여러 건 몰렸습니다.

## anthropic

### Claude Fable 5.2 · Claude Mythos 5.2 공개 — 기본 Fable 모델 교체 (11/9)
동일한 하나의 모델을 안전장치 수준으로 나눈 두 버전입니다. Fable 5.2는 사이버·생물 안전장치를 갖춰 전 사용자에게 공개되고, Mythos 5.2는 Cyber/Life Sciences Verification Program 심사를 통과한 조직에만 제공됩니다. 가격은 입력 $8/출력 $40 (Mtok, 패스트 모드는 2배)이며, Anthropic은 FrontierSWE v2(에이전트형 코딩)에서 69.9%로 Opus 5.5의 62.3%를 앞섰다고 주장합니다. Claude Code 2.1.321부터 기존에 선택해 둔 Fable 5.1이 유료 플랜에서 자동으로 `fable`(5.2)로 옮겨집니다.

- 출처: [Introducing Claude Fable 5.2 and Claude Mythos 5.2](https://www.anthropic.com/news/claude-fable-and-mythos-5-2) · 2026-11-09
- 신뢰도: 높음 (1차 출처, 공식 발표 원문 직접 확인. 벤치마크 수치는 벤더 자체 측정이라 별도 검증 전까지는 그 전제로 읽어야 함)
- 왜 중요한가: 기존 모델 선택이 사용자 조작 없이 새 모델로 자동 이동한다는 점이 이 vault의 예약 실행([[secbrain-site]])에도 직접 영향을 줍니다 — 어떤 Claude 모델이 daily-brief를 쓰는지가 사용자 모르게 바뀔 수 있다는 뜻입니다.

### Claude Code 2.1.321 — MCP OAuth 토큰 유출, Bash 권한 우회 다수 수정 (11/9)
"오늘 하나만 본다면"에서 다룬 변경입니다. MCP 서버가 OAuth 요청을 다른 호스트로 리다이렉트할 때 refresh token 같은 비밀이 함께 새던 결함, 읽기 전용으로 분류된 Bash 명령이 샌드박스 밖에서 프롬프트 없이 실행되던 결함, `cp`/`mv`가 디렉터리에 파일을 쓸 때 deny 규칙과 보호 파일 프롬프트를 피하던 결함을 한 릴리스에서 함께 고쳤습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-09
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 3(검사-실행 사이 틈)이 상정하는 결함이 한 릴리스에 여럿 몰린 사례로, 체크리스트 근거 목록의 2026-08-07·2026-08-29 패턴이 이어지고 있습니다.

### Claude Code 2.1.325 — 샌드박스 Bash 기본 동작 전환, 격리 워크트리 보호 강화 (11/13)
"오늘 하나만 본다면"에서 다룬 변경입니다. 샌드박스 Bash 명령이 기본적으로 승인 플로우를 타도록 바뀌었고, 격리 워크트리에서 `git bisect run`·`git maintenance register|start`·`scalar` 설정이 거부되며, 추가 디렉터리의 `.claude` 폴더에 대한 샌드박스 쓰기도 막혔습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-13
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 7의 정의 그대로 "게이트가 있다"에서 "게이트가 기본값으로 실제로 버틴다"로 넘어간 변경입니다.
