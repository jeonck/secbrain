## 오늘 하나만 본다면

Claude Code 2.1.328(11/19, 오늘 릴리스)은 Amazon Bedrock·Google Cloud Agent Platform·Microsoft Foundry·Claude apps gateway에서 Claude Opus 4.6·Sonnet 4.6용 "auto mode"를 추가했고, **권한 모드를 지정하지 않은 대화형 세션은 이제 이 auto mode로 시작**합니다. [[에이전트-권한-경계-체크리스트]] 핵심 7("게이트가 '있다'와 게이트가 '실제로 버틴다'를 구분한다")이 짚는 지점이 지난 11/13(2.1.325, [[2026-11-16-brief]])에는 "기본값이 더 조심스러워지는" 방향으로 움직였는데, 이번엔 "지정하지 않으면 자동 모드로 시작"하는 반대 방향입니다. 같은 릴리스가 `mcp_tool` 훅에도 `onFailure: "block"`(호출 실패 시 액션 차단)을 추가하고 정책 플러그인의 `allowManagedModsOnly`를 지원하는 등 승인 게이트 자체는 더 촘촘해졌지만, 그것과 "기본 시작 모드가 느슨해졌다"는 별개 축입니다. 정확히 어떤 상황에서 auto mode가 무엇을 자동 승인하는지는 체인지로그 요약만으로 단정하기 어려워, 이 vault의 예약 파이프라인([[secbrain-site]])에 영향이 있는지는 공식 문서로 재확인이 필요합니다 — "확인하지 못한 것"에 남깁니다.

## anthropic

### Claude Code 2.1.328 — 대화형 세션 기본 시작 모드가 auto mode로 (11/19)
"오늘 하나만 본다면"에서 다룬 변경입니다. 같은 릴리스에서 `mcp_tool` 훅의 `onFailure: "block"` 지원, 정책 플러그인 `allowManagedModsOnly`(관리자 설정이 항상 우선), self-hosted runner의 세션 큐·포기 사유 메트릭 추가가 함께 들어갔습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-19
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 7이 추적해 온 "기본값이 실제로 무엇을 허용하는가"의 가장 최근 사례. 11/13(조이기)과 11/19(느슨해지기)가 같은 메이저 버전 계열에서 반대 방향으로 움직였다는 점을 기록해 둡니다.

### Claude Code 2.1.327 — GitHub 앱 설치 확인창, MCP 토큰 stdin 입력 (11/17)
`/install-github-app`이 저장소를 바꾸기 전에 확인을 요구하게 됐습니다(되돌리기 어려운 액션 앞 승인, 핵심 6). `claude mcp add-json <name> -`로 서버 JSON을 표준입력으로 받아 토큰이 명령줄 히스토리에 남지 않게 하는 옵션도 추가됐습니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-17
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 6(비가역 액션 앞 승인)에 해당하는 사례가 또 하나 추가됐습니다.

### Claude Code 2.1.326 — agent teams 켠 상태에서 Code Mode 지원 (11/16)
agent teams가 켜져 있을 때도 Code Mode를 켤 수 있게 됐고, 이미 Code Mode를 켜둔 경우 teams가 활성화된 세션이 자동으로 Code Mode로 시작합니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-16
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: Anthropic 자체 제품 안에서 멀티 에이전트 조율(`agents` 관심사)과 권한·실행 모드(`anthropic` 관심사)가 같은 설정으로 묶이기 시작했다는 신호입니다.

## devtools

### GitHub Copilot CLI 1.0.110 — 에이전트가 sudo/git/ssh 비밀번호 프롬프트에 직접 응답 (11/12)
`/experimental on`으로 켜는 실험적 옵션으로, 에이전트가 실행한 명령이 git·ssh·sudo 비밀번호를 물으면 마스킹된 대화창으로 대신 응답할 수 있게 됐습니다. 기본값은 꺼짐(opt-in)입니다.

- 출처: [GitHub Copilot CLI 릴리스](https://github.com/github/copilot-cli/releases) · 2026-11-12
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 페이지 직접 확인)
- 왜 중요한가: [[에이전트-권한-경계-체크리스트]] 핵심 7이 추적하는 "기본값 완화" 계열이지만 이번엔 opt-in이라는 점이 2026-10-11 Copilot CLI Assisted Permissions(화면에 보이는 명령 자동 승인, 기본값 완화)와 다릅니다. 그래도 에이전트가 자격 증명 입력을 대신한다는 것 자체는 권한 경계상 새로운 범주라 지켜볼 항목입니다.

### GitHub Copilot CLI 1.0.112~113 — MCP 미신뢰 폴더 경고, 관리자용 Browser Use 킬스위치 (11/13~11/17)
1.0.112는 워크스페이스가 미신뢰 상태라 MCP 설정이 건너뛰어질 때 경고를 띄우고, 조직 정책이 MCP 서버를 막으면 내장 GitHub MCP 서버도 비활성화합니다. 1.0.113은 관리형 `features.browserUse` 설정으로 관리자가 실행 중인 세션에서도 내장 Browser Use를 끌 수 있게 했습니다.

- 출처: [GitHub Copilot CLI 릴리스](https://github.com/github/copilot-cli/releases) · 2026-11-13~2026-11-17
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 페이지 직접 확인)
- 왜 중요한가: 실행 중인 세션에도 적용되는 관리자 킬스위치는 [[에이전트-권한-경계-체크리스트]] 핵심 5("경보가 울리면 멈춘다")를 조직 차원에서 강제하는 메커니즘에 해당합니다.

### Zed 1.28.1 — Git 자동 fetch, 에이전트 읽기 도구 길이 제한 (11/11)
Git 자동 fetch(기본 꺼짐), Git Graph "Refs" 컬럼 크기 조절, 에이전트의 `read_file` 도구가 2,000자 넘는 줄을 자르는 변경 등이 포함됐습니다.

- 출처: [Zed 1.28.1 릴리스 노트](https://zed.dev/releases/stable/1.28.1) · 2026-11-11
- 신뢰도: 높음 (1차 출처, 공식 릴리스 페이지 직접 확인)
- 왜 중요한가: 로컬 우선 에디터의 에이전트 기능(읽기 도구 제한)이 계속 세분화되고 있다는 점만 가볍게 기록합니다 — 이 vault의 정책과 직접 관련은 없습니다.

## 확인하지 못한 것

**agents** — CrewAI([[2026-11-16-brief]]에서 다룸) 이후 LangGraph·Microsoft Agent Framework·OpenAI Agents SDK에서 11/12~11/19 사이 날짜가 명확한 새 릴리스를 찾지 못했습니다. 검색 결과 대부분이 비교 블로그여서 1차 출처가 없었습니다. "Red Hat AI 에이전트 오케스트레이션" 관련 보도는 단일 저품질 아웃렛(emergent.sh)만 다뤄 제외했습니다.

**pkm** — Obsidian·Logseq·Notion·Tana·Heptabase·Capacities·Anytype 모두 11/12~11/19 사이 공식 출처에서 날짜가 명확한 새 항목을 찾지 못했습니다. 검색 결과가 서로 버전·날짜가 충돌하는 비교 블로그뿐이라 제외했습니다.

**Claude Code 2.1.328의 "auto mode" 정확한 동작** — 체인지로그 원문이 어떤 조건에서 무엇을 자동 승인하는지까지는 설명하지 않습니다. 공식 문서(`/docs/en/...`)로 재확인 전까지는 "권한 모드 미지정 시 기본값이 auto로 바뀌었다"는 사실까지만 확인된 것으로 둡니다.
