## 오늘 하나만 본다면

Claude Code 2.1.329(11/19, 1차 출처 체인지로그 직접 확인)는 `/tasks`에 이번 세션의 예약 작업, `/loop` wakeup, 목표, 현재 대화의 fork까지 모두 올리고, 헤더·푸터의 집계 숫자를 셸·모니터·MCP 호출·에이전트·워크플로·예약 작업을 아우르는 하나의 숫자로 바꿨습니다. `/code-review`도 타겟 없이 실행하면 대부분 모델에서 기본 브랜치 대비 전체 브랜치를 리뷰하도록 바뀌었고, auto mode가 `git status`를 덜 호출하도록 조정됐습니다. 이 브리프 자체가 "예약 실행"으로 돌고, [[secbrain-site]] 파이프라인이 Actions 트리거로 Claude Code를 예약·실행시키는 구조라서, "지금 떠 있는 예약·fork·루프가 한눈에 보이는가"는 이 vault 운영에 직접 걸리는 가시성 문제입니다. 다만 `/tasks` UI 변경 자체가 vault 쪽 Actions 워크플로의 동작을 바꾸는 것은 아니라서, 체인지로그 원문 확인 수준에서 "참고할 만한 운영 편의 변화"로만 남깁니다.

## anthropic

### Claude Code 2.1.329 — `/tasks`에 예약 작업·loop wakeup·fork 통합, `/code-review` 기본값이 전체 브랜치로 (11/19)
"오늘 하나만 본다면"에서 다룬 변경입니다. 같은 릴리스에서 다중 커밋 브랜치에서 `/code-review`가 diff를 잃어버리던 버그도 고쳤고, Windows 시작 시간과 장시간 세션의 메모리 사용도 개선됐습니다(91건의 버그 수정 포함).

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-19
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 원문 직접 확인)
- 왜 중요한가: [[secbrain-site]]의 예약·이슈 트리거 파이프라인과 같은 축의 기능(예약 작업·세션 가시성)이 Claude Code 본체에도 들어왔다는 신호입니다.

### Claude Developer Platform — 텍스트 워터마크가 Opus 4.6·Opus 4.5·Sonnet 4.5·Haiku 4.5까지 확대 (11/16)
공식 릴리스 노트 기준으로, 지원 플랫폼에서 생성된 텍스트에 Anthropic 워터마크가 붙는 모델 목록이 늘었습니다. `temperature`·`top_p`·`top_k`를 기본값과 다르게 설정하면 워터마크가 빠질 수 있습니다.

- 출처: [Claude API 릴리스 노트](https://platform.claude.com/docs/en/release-notes/api) · 2026-11-16
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트 직접 확인)
- 왜 중요한가: 이 vault가 생성하는 노트·브리프 텍스트 자체가 워터마크 대상 모델로 만들어질 가능성이 있어 참고용으로 남깁니다. 직접적인 액션은 없습니다.

## agents

### CrewAI 1.15.42 — Knowledge 기본 백엔드가 로컬 Qdrant로, ChromaDB는 선택 extra로 (11/18)

- 출처: [CrewAI GitHub Releases](https://github.com/crewAIInc/crewAI/releases) · 2026-11-18
- 신뢰도: 높음 (1차 출처, 공식 GitHub 릴리스 페이지 직접 확인)
- 왜 중요한가: 에이전트 프레임워크의 기본 벡터 스토어가 바뀌는 것은 RAG·지식 계층 설계([[cog-architecture]])에 조용히 영향을 주는 종류의 변화라 기록해 둡니다.
