Cognition이 11/17 Devin Bots를 출시했습니다 — 매니저 역할의 지속 실행 에이전트가 목표를 쪼개 여러 Devin 코딩 세션을 띄우고 진행을 추적하다, 사람 승인이 필요한 결정만 올려보내는 구조입니다. QA Bot이 버그를 찾아 Developer Bot에게 넘기는 식으로 역할이 분리된 봇들이 협업한다고 설명합니다. 이 vault의 [[cog-architecture]]가 다루는 "리드는 판단, 워커는 실행" 구도, [[에이전트-권한-경계-체크리스트]]가 요구하는 역할별 권한 분리와 같은 결의 설계가 상용 코딩 에이전트 제품에서도 그대로 나타난 사례라 기록해 둘 만합니다. 다만 "베타 테스터가 메시지당 PR을 4.5배 더 많이 머지했다"는 수치는 비교 기준·샘플 크기가 공개되지 않아 이번 브리프에는 올리지 않았습니다.

## agents

### Cognition Devin Bots — 매니저 에이전트가 여러 Devin 코딩 에이전트 팀을 감독 (11/17)
매니저 에이전트가 큰 목표를 작업 단위로 나눠 여러 Devin 코딩 세션을 동시에 띄우고, 진행 상황을 추적하다 사람 승인이 필요한 지점에서 멈춥니다. OpenAI·Anthropic의 범용 상시 실행 에이전트(Dots·Duet)와 달리 코딩 전용으로 설계됐다는 점을 Cognition이 직접 차별점으로 내세웁니다.

- 출처: [Fortune — Cognition bets on Devin Bots](https://fortune.com/2026/11/17/exclusive-cognition-bets-on-devin-bots-coding-agents-in-challenge-to-anthropics-duet-and-openais-dots/) · 2026-11-17
- 신뢰도: 중간 (Fortune 단독 인터뷰를 다수 매체가 재인용, Cognition 공식 블로그 글은 직접 확인하지 못함)
- 왜 중요한가: [[cog-architecture]]의 리드/워커 분리, [[에이전트-권한-경계-체크리스트]]의 역할별 권한 경계와 같은 설계가 상용 제품에서 독립적으로 재발견된 사례입니다.

## anthropic

### Claude Code 2.1.330 — 예약 작업·`/loop` 세션 유지 기간 7일 → 30일, 위험 `rm` 승인 요구 (11/20)
조직 관리 콘솔에 로그인하면 조직 설정·클라우드 게이트웨이가 자동 적용되고, VSCode에 `/fork`·`/workflows`가 추가됐습니다. `rm`이 루트나 홈 폴더를 대상으로 하면 이제 승인을 요구합니다.

- 출처: [Claude Code 변경 로그](https://code.claude.com/docs/en/changelog) · 2026-11-20
- 신뢰도: 높음 (1차 출처, 공식 체인지로그 직접 확인)
- 왜 중요한가: 여기서 늘어난 건 Claude Code 세션 안의 `/loop`·예약 작업 유지 기간입니다 — 이 저장소의 실제 예약 실행은 Claude Code 내부 스케줄이 아니라 `.github/workflows/scheduled.yml`의 GitHub Actions cron이 매번 새 세션을 띄우는 구조([[secbrain-site]])라서, 이 변경이 이 vault의 파이프라인 동작을 바꾸지는 않습니다. 참고용으로만 남깁니다.

### Claude 앱 — Linked billing(베타) 출시, 앱 사용량을 조직이 직접 결제 (11/17)
Claude 조직이 연동된 앱의 Claude 사용료를 자신의 조직 계정으로 직접 지불할 수 있는 베타 기능입니다. 요청마다 `billing_policy`로 비용 부담 주체를 정하고, Claude Console에서 앱별 지출 한도를 설정하거나 연결을 해제할 수 있습니다.

- 출처: [Claude API 릴리스 노트](https://platform.claude.com/docs/en/release-notes/api) · 2026-11-17
- 신뢰도: 높음 (1차 출처, 공식 릴리스 노트 직접 확인)
- 왜 중요한가: 이 vault는 자체 API 키·조직 결제 구조를 쓰지 않아 직접 해당되지는 않지만, Claude API를 쓰는 서드파티 앱을 평가할 일이 생기면 참고할 변경입니다.
