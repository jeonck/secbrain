# 🧠 secbrain

**Markdown + Git + Claude.** 데이터베이스도, 서버도, 구독 결제도 없습니다. 브레인의 상태 전부가 이 저장소 안의 `.md` 파일입니다.

🌐 **https://jeonck.github.io/secbrain/**

---

## 이게 뭔가

노트를 폴더 안에만 두면 결국 안 열어 보게 됩니다. 그래서 두 가지를 붙였습니다.

1. **정적 사이트** — vault의 마크다운을 대시보드·그래프·검색·태스크 보드로 발행합니다.
2. **온디맨드 에이전트** — 사이트의 버튼이 GitHub 이슈를 열면, Actions에서 Claude가 실행되어 노트를 만들고 커밋합니다.

## 어떻게 도는가

```
사이트에서 "브레인덤프" 클릭
   ↓  (브라우저에 토큰 0개 — 그냥 이슈 열기 링크입니다)
GitHub 이슈 생성  ·  라벨: braindump
   ↓
Actions: 소유자 확인 → 스킬 라우팅 → Claude Code 실행 (OAuth 토큰은 러너 시크릿에만)
   ↓
.md 커밋 & 푸시  →  이슈에 결과 코멘트 후 자동 닫힘
   ↓
Pages 워크플로 재빌드  →  사이트에 반영
```

**정적 호스팅의 제약을 우회하는 지점이 여기입니다.** GitHub Pages는 백엔드를 돌릴 수 없고, 브라우저에 API 키를 두는 건 공개 저장소에서 위험합니다. 그래서 브라우저는 아무 비밀도 들지 않습니다 — 트리거만 보내고, 실제 실행은 시크릿을 가진 러너에서 일어납니다.

## 폴더

| 폴더 | 용도 |
|---|---|
| `00-inbox/` | 미분류 캡처 |
| `01-projects/` | 끝이 있는 일 |
| `02-areas/` | 계속 유지하는 영역 |
| `03-resources/` | 참고 자료·프레임워크 |
| `04-archive/` | 종료·보관 |
| `05-daily/` | 일지와 브리프 |
| `06-templates/` | 노트 템플릿 |
| `07-answers/` | 질문에 인용과 함께 답한 노트 |

`.claude/skills/` 아래가 이 브레인의 동작 전부입니다 — 코드가 아니라 마크다운 지시문입니다.

## 스킬

| 스킬 | 하는 일 | 트리거 |
|---|---|---|
| `braindump` | 엉킨 생각을 도메인별로 쪼개 배치 | 이슈 · 로컬 |
| `daily-brief` | 관심사 기반 뉴스 브리프 (출처 필수·7일 신선도·신뢰도) | 이슈 · 매일 06:00 KST |
| `weekly-review` | 한 주 노트를 교차 분석해 패턴 추출 | 이슈 · 일요일 07:00 KST |
| `consolidate` | 흩어진 노트를 재사용 프레임워크로 승격 | 이슈 · 매월 1일 08:00 KST |
| `ask` | vault를 근거로 질문에 답하고 인용을 담 | 이슈 · 로컬 |

## 검색

두 단계입니다.

1. **사이트 검색 (⌘K)** — BM25 랭킹. 한글은 문자 바이그램으로 색인해서 조사·띄어쓰기가 달라도 걸립니다(`에이전트비용` → `에이전트 비용`). 즉답이지만 어휘 검색이라 `cost routing` ↔ `비용 라우팅` 같은 언어 교차는 못 잇습니다.
2. **`ask` 스킬** — 그 한계를 메웁니다. 개념을 여러 표기로 넓혀 검색하고, 걸린 노트를 전부 읽고, 인용과 함께 답합니다. 답변은 `07-answers/`에 노트로 남아 근거 노트에 백링크를 만듭니다. 1~3분 걸립니다.

## 쓰는 법

**사이트에서** — 우상단 `✏️ 브레인덤프` → 원하는 요청 선택 → 이슈 작성. 몇 분 뒤 사이트에 반영됩니다.

**로컬 Claude Code에서** — 저장소를 열고 그냥 말하면 됩니다.

```
브레인덤프 할게
데일리 브리프 줘
위클리 리뷰
```

**Obsidian에서** — 이 폴더를 vault로 열면 `[[링크]]`가 그대로 동작합니다.

## 정직하게

이건 "자기진화" 시스템이 아닙니다. 가중치를 학습하지 않습니다. **파일 위에서 도는 예약된 반성 루프**입니다.
다만 루프는 실재하고, 보통 무너지는 부분인 유지보수를 에이전트가 맡습니다.

구조는 [Roan Brasil Monteiro의 COG](https://github.com/huytieu/COG-second-brain) 글에서 가져왔고, 발행·트리거 계층을 얹었습니다.
